# 算法题集

按算法模型和具体题型整理，共 8 个模块、72 个专题、385 条题目记录。四个题集合并后有 374 条记录，另保留背包专题中的 11 道补充题。

每篇专题先用表格汇总全部题目，再按“算法模型 → 具体题型 → 题目与思路”展开。同一题型的题目放在表格同一行，正文保留状态设计、解题步骤、复杂度和边界条件。

## 数据与维护

[题集数据](题集数据.json) 保存题号、标题、链接、来源、CodeTop 排名和主归属文件。调整题目或标签时同步更新该文件。

在仓库根目录运行以下命令，可检查题集覆盖、页首表格与正文对应关系、来源标签、唯一归属以及本地链接和标题锚点：

```sh
node scripts/validate-algorithm-notes.mjs
```

校验逻辑见[题集校验脚本](../../scripts/validate-algorithm-notes.mjs)。
