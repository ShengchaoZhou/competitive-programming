# 前缀和与差分

前缀和用于在数组或矩阵不再变化时快速回答区间求和；差分用于集中记录多次区间增量，并在最后一次性还原修改后的数组或矩阵。

## [AcWing 795. 前缀和](https://www.acwing.com/problem/content/797/)

### 题目描述

给出一个长度为 $n$ 的整数序列和 $m$ 个询问。每个询问指定两个下标 $l,r$，需要计算原序列第 $l$ 个数到第 $r$ 个数（两端均包含）的元素之和。序列下标从 $1$ 开始。

**输入**

第一行包含 $n$ 和 $m$；第二行包含序列中的 $n$ 个整数；随后 $m$ 行每行包含一组询问 $l,r$。

**输出**

对每个询问输出一行，表示对应区间的元素和。

**数据范围**

- $1 \leq n,m \leq 100000$。
- $1 \leq l \leq r \leq n$。
- 序列元素的值在 $[-1000,1000]$ 内。

**输入样例**

```text
5 3
2 1 3 6 4
1 2
1 3
2 4
```

**输出样例**

```text
3
6
10
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();

        long[] prefix = new long[n + 1];
        for (int i = 1; i <= n; i++) {
            prefix[i] = prefix[i - 1] + scanner.nextInt();
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < m; i++) {
            int left = scanner.nextInt();
            int right = scanner.nextInt();
            answer.append(prefix[right] - prefix[left - 1]).append('\n');
        }
        System.out.print(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：预处理 $O(n)$，每次询问 $O(1)$，总计 $O(n+m)$。
- 空间复杂度：$O(n)$。

## [AcWing 796. 子矩阵的和](https://www.acwing.com/problem/content/798/)

### 题目描述

给出一个 $n$ 行 $m$ 列的整数矩阵和 $q$ 个询问。每个询问以左上角坐标 $(x_1,y_1)$ 和右下角坐标 $(x_2,y_2)$ 指定一个子矩阵，需要输出其中所有元素的和。矩阵坐标从 $1$ 开始。

**输入**

第一行包含 $n,m,q$；接下来 $n$ 行每行包含 $m$ 个整数，表示矩阵；随后 $q$ 行每行包含 $x_1,y_1,x_2,y_2$。

**输出**

对每个询问输出一行，表示指定子矩阵的元素和。

**数据范围**

- $1 \leq n,m \leq 1000$。
- $1 \leq q \leq 200000$。
- $1 \leq x_1 \leq x_2 \leq n$，$1 \leq y_1 \leq y_2 \leq m$。
- 矩阵元素的值在 $[-1000,1000]$ 内。

**输入样例**

```text
3 4 3
1 7 2 4
3 6 2 8
2 1 2 3
1 1 2 2
2 1 3 4
1 3 3 4
```

**输出样例**

```text
17
27
21
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();
        int q = scanner.nextInt();

        long[][] prefix = new long[n + 1][m + 1];
        for (int row = 1; row <= n; row++) {
            for (int column = 1; column <= m; column++) {
                long value = scanner.nextInt();
                prefix[row][column] = value
                        + prefix[row - 1][column]
                        + prefix[row][column - 1]
                        - prefix[row - 1][column - 1];
            }
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < q; i++) {
            int x1 = scanner.nextInt();
            int y1 = scanner.nextInt();
            int x2 = scanner.nextInt();
            int y2 = scanner.nextInt();

            long sum = prefix[x2][y2]
                    - prefix[x1 - 1][y2]
                    - prefix[x2][y1 - 1]
                    + prefix[x1 - 1][y1 - 1];
            answer.append(sum).append('\n');
        }
        System.out.print(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：预处理 $O(nm)$，每次询问 $O(1)$，总计 $O(nm+q)$。
- 空间复杂度：$O(nm)$。

## [AcWing 797. 差分](https://www.acwing.com/problem/content/799/)

### 题目描述

给出一个长度为 $n$ 的整数序列以及 $m$ 次操作。每次操作给出 $l,r,c$，把下标区间 $[l,r]$ 内的每个元素都增加 $c$。输出全部操作完成后的序列，序列下标从 $1$ 开始。

**输入**

第一行包含 $n,m$；第二行包含序列中的 $n$ 个整数；随后 $m$ 行每行包含一次操作 $l,r,c$。

**输出**

输出一行共 $n$ 个整数，表示执行全部操作后的序列。

**数据范围**

- $1 \leq n,m \leq 100000$。
- $1 \leq l \leq r \leq n$。
- $c$ 与原序列元素的值均在 $[-1000,1000]$ 内。

**输入样例**

```text
6 3
1 2 2 1 2 1
1 3 1
3 5 1
1 6 1
```

**输出样例**

```text
3 4 5 3 4 2
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();

        long[] difference = new long[n + 2];
        long previous = 0;
        for (int i = 1; i <= n; i++) {
            long current = scanner.nextInt();
            difference[i] = current - previous;
            previous = current;
        }

        for (int i = 0; i < m; i++) {
            int left = scanner.nextInt();
            int right = scanner.nextInt();
            int increment = scanner.nextInt();
            difference[left] += increment;
            difference[right + 1] -= increment;
        }

        StringBuilder answer = new StringBuilder();
        long current = 0;
        for (int i = 1; i <= n; i++) {
            current += difference[i];
            if (i > 1) answer.append(' ');
            answer.append(current);
        }
        answer.append('\n');
        System.out.print(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：构造差分数组、处理操作并还原结果共 $O(n+m)$。
- 空间复杂度：$O(n)$。

## [AcWing 798. 差分矩阵](https://www.acwing.com/problem/content/800/)

### 题目描述

给出一个 $n$ 行 $m$ 列的整数矩阵以及 $q$ 次操作。每次操作用左上角 $(x_1,y_1)$、右下角 $(x_2,y_2)$ 和增量 $c$ 指定一个子矩阵，把该子矩阵中的每个元素都增加 $c$。输出全部操作完成后的矩阵，坐标从 $1$ 开始。

**输入**

第一行包含 $n,m,q$；接下来 $n$ 行每行包含 $m$ 个矩阵元素；随后 $q$ 行每行包含一次操作 $x_1,y_1,x_2,y_2,c$。

**输出**

输出 $n$ 行，每行 $m$ 个整数，表示执行全部操作后的矩阵。

**数据范围**

- $1 \leq n,m \leq 1000$。
- $1 \leq q \leq 100000$。
- $1 \leq x_1 \leq x_2 \leq n$，$1 \leq y_1 \leq y_2 \leq m$。
- $c$ 与原矩阵元素的值均在 $[-1000,1000]$ 内。

**输入样例**

```text
3 4 3
1 2 2 1
3 2 2 1
1 1 1 1
1 1 2 2 1
1 3 2 3 2
3 1 3 4 1
```

**输出样例**

```text
2 3 4 1
4 3 4 1
2 2 2 2
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {

    private static void add(
            long[][] difference,
            int x1,
            int y1,
            int x2,
            int y2,
            long increment
    ) {
        difference[x1][y1] += increment;
        difference[x1][y2 + 1] -= increment;
        difference[x2 + 1][y1] -= increment;
        difference[x2 + 1][y2 + 1] += increment;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();
        int q = scanner.nextInt();

        long[][] difference = new long[n + 2][m + 2];
        for (int row = 1; row <= n; row++) {
            for (int column = 1; column <= m; column++) {
                add(difference, row, column, row, column, scanner.nextInt());
            }
        }

        for (int i = 0; i < q; i++) {
            int x1 = scanner.nextInt();
            int y1 = scanner.nextInt();
            int x2 = scanner.nextInt();
            int y2 = scanner.nextInt();
            int increment = scanner.nextInt();
            add(difference, x1, y1, x2, y2, increment);
        }

        StringBuilder answer = new StringBuilder();
        for (int row = 1; row <= n; row++) {
            for (int column = 1; column <= m; column++) {
                difference[row][column] += difference[row - 1][column]
                        + difference[row][column - 1]
                        - difference[row - 1][column - 1];
                if (column > 1) answer.append(' ');
                answer.append(difference[row][column]);
            }
            answer.append('\n');
        }
        System.out.print(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：初始化、处理操作并还原矩阵共 $O(nm+q)$。
- 空间复杂度：$O(nm)$。
