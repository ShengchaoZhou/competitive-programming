# 归并排序

归并排序用于稳定地排序一个序列；在合并两个有序区间时，还可以高效统计跨区间的元素关系，例如逆序对数量。

## [AcWing 787. 归并排序](https://www.acwing.com/problem/content/789/)

### 题目描述

给定一个长度为 `n` 的整数数列，使用归并排序将数列按从小到大的顺序排列，并输出排序结果。

**输入格式**

- 第一行是整数 `n`，表示数列长度。
- 第二行包含 `n` 个整数，表示待排序的数列。

**输出格式**

输出一行 `n` 个整数，相邻整数之间用空格分隔，表示升序排列后的数列。

**数据范围**

- `1 ≤ n ≤ 100000`
- 数列中的每个整数都在 `[1, 10^9]` 内。

**输入样例**

```text
5
3 1 2 4 5
```

**输出样例**

```text
1 2 3 4 5
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] numbers = new int[n];
        int[] temporary = new int[n];

        for (int i = 0; i < n; i++) {
            numbers[i] = scanner.nextInt();
        }

        mergeSort(numbers, temporary, 0, n - 1);

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) {
                answer.append(' ');
            }
            answer.append(numbers[i]);
        }
        System.out.println(answer);
    }

    private static void mergeSort(int[] numbers, int[] temporary, int left, int right) {
        if (left >= right) {
            return;
        }

        int middle = left + (right - left) / 2;
        mergeSort(numbers, temporary, left, middle);
        mergeSort(numbers, temporary, middle + 1, right);

        int i = left;
        int j = middle + 1;
        int index = left;

        while (i <= middle && j <= right) {
            if (numbers[i] <= numbers[j]) {
                temporary[index++] = numbers[i++];
            } else {
                temporary[index++] = numbers[j++];
            }
        }

        while (i <= middle) {
            temporary[index++] = numbers[i++];
        }
        while (j <= right) {
            temporary[index++] = numbers[j++];
        }

        System.arraycopy(temporary, left, numbers, left, right - left + 1);
    }

}
```

### 时空复杂度

- 时间复杂度：$O(n \log n)$。
- 空间复杂度：$O(n)$，用于临时数组；递归调用栈另占 $O(\log n)$ 空间，总体仍为 $O(n)$。

## [AcWing 788. 逆序对的数量](https://www.acwing.com/problem/content/790/)

### 题目描述

给定一个长度为 `n` 的整数数列。若下标满足 `i < j`，同时元素满足 `a[i] > a[j]`，则 `(i, j)` 构成一个逆序对。计算整个数列中逆序对的总数。

**输入格式**

- 第一行是整数 `n`，表示数列长度。
- 第二行包含 `n` 个整数，表示给定数列。

**输出格式**

输出一个整数，表示逆序对总数。

**数据范围**

- `1 ≤ n ≤ 100000`
- 数列中的每个整数都在 `[1, 10^9]` 内。

**输入样例**

```text
6
2 3 4 5 6 1
```

**输出样例**

```text
5
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] numbers = new int[n];
        int[] temporary = new int[n];

        for (int i = 0; i < n; i++) {
            numbers[i] = scanner.nextInt();
        }

        System.out.println(countInversions(numbers, temporary, 0, n - 1));
    }

    private static long countInversions(
            int[] numbers, int[] temporary, int left, int right) {
        if (left >= right) {
            return 0L;
        }

        int middle = left + (right - left) / 2;
        long count = countInversions(numbers, temporary, left, middle)
                + countInversions(numbers, temporary, middle + 1, right);

        int i = left;
        int j = middle + 1;
        int index = left;

        while (i <= middle && j <= right) {
            if (numbers[i] <= numbers[j]) {
                temporary[index++] = numbers[i++];
            } else {
                temporary[index++] = numbers[j++];
                count += middle - i + 1L;
            }
        }

        while (i <= middle) {
            temporary[index++] = numbers[i++];
        }
        while (j <= right) {
            temporary[index++] = numbers[j++];
        }

        System.arraycopy(temporary, left, numbers, left, right - left + 1);
        return count;
    }

}
```

### 时空复杂度

- 时间复杂度：$O(n \log n)$。
- 空间复杂度：$O(n)$，用于临时数组；递归调用栈另占 $O(\log n)$ 空间，总体仍为 $O(n)$。
