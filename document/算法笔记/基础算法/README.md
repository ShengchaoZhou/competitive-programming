# 基础算法

本模块整理 11 个专题、84 道题，覆盖排序、查找、区间维护和数组操作。保留 AcWing 原有专题，并按解题模型补充四个题集中的相关题目。

| 专题 | 主要内容 | 题目数 |
| --- | --- | --- |
| [快速排序](快速排序.md) | 分区排序、快速选择、第 k 个与前 k 个 | 5 |
| [归并排序](归并排序.md) | 有序合并、逆序对计数 | 4 |
| [二分](二分.md) | 边界查找、旋转数组、二维查找、答案二分与值域选择 | 14 |
| [高精度](高精度.md) | 竖式加减乘除、字符串数值运算与不同进制 | 8 |
| [前缀和与差分](前缀和与差分.md) | 区间求和、区间修改、前缀状态计数与左右累积 | 6 |
| [双指针](双指针.md) | 对向扫描、原地写入、序列匹配与多指针划分 | 15 |
| [滑动窗口](滑动窗口.md) | 定长计数、无重复约束、最短覆盖与字符种类约束 | 8 |
| [位运算](位运算.md) | 二进制计数、异或抵消、按位统计与位掩码 | 6 |
| [离散化](离散化.md) | 稀疏坐标压缩、映射与区间查询 | 1 |
| [区间合并](区间合并.md) | 合并、插入与连续段摘要 | 4 |
| [数组与矩阵](数组与矩阵.md) | 原地标记、排列变换、旋转、模拟与矩阵遍历 | 13 |

窗口内的极值维护见[单调队列](../数据结构/单调队列.md)；通过选择或删除区间满足约束的题目见[贪心区间问题](../贪心/区间问题.md)。
