# 二分

二分用于在具有单调性或二段性的搜索空间中定位边界或近似答案，既能查找有序数组中的位置，也能逼近连续实数范围内的解。

## [AcWing 789. 数的范围](https://www.acwing.com/problem/content/791/)

### 题目描述

给定一个长度为 `n` 的非递减整数数组和 `q` 次查询。每次给出整数 `k`，需要输出 `k` 在数组中第一次和最后一次出现的位置；数组下标从 `0` 开始。如果 `k` 不在数组中，则输出 `-1 -1`。

**输入格式**

- 第一行包含两个整数 `n` 和 `q`，分别表示数组长度和查询次数。
- 第二行包含 `n` 个按非递减顺序排列的整数。
- 接下来 `q` 行，每行包含一个待查询的整数 `k`。

**输出格式**

对每次查询输出一行两个整数，依次表示目标值第一次和最后一次出现的下标；不存在时输出 `-1 -1`。

**数据范围**

- `1 ≤ n ≤ 100000`
- `1 ≤ q ≤ 10000`
- 数组元素和查询值均在 `[1, 10000]` 内。

**输入样例**

```text
6 3
1 2 2 3 3 4
3
4
5
```

**输出样例**

```text
3 4
5 5
-1 -1
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int n = scanner.nextInt();
        int queryCount = scanner.nextInt();
        int[] numbers = new int[n];

        for (int i = 0; i < n; i++) {
            numbers[i] = scanner.nextInt();
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < queryCount; i++) {
            int target = scanner.nextInt();
            int first = lowerBound(numbers, target);

            if (first == numbers.length || numbers[first] != target) {
                answer.append("-1 -1\n");
            } else {
                int last = upperBound(numbers, target) - 1;
                answer.append(first).append(' ').append(last).append('\n');
            }
        }

        System.out.print(answer);
    }

    private static int lowerBound(int[] numbers, int target) {
        int left = 0;
        int right = numbers.length;

        while (left < right) {
            int middle = left + (right - left) / 2;
            if (numbers[middle] >= target) {
                right = middle;
            } else {
                left = middle + 1;
            }
        }
        return left;
    }

    private static int upperBound(int[] numbers, int target) {
        int left = 0;
        int right = numbers.length;

        while (left < right) {
            int middle = left + (right - left) / 2;
            if (numbers[middle] > target) {
                right = middle;
            } else {
                left = middle + 1;
            }
        }
        return left;
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int sign = 1;
            if (c == '-') {
                sign = -1;
                c = read();
            }

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value * sign;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：每次查询为 $O(\log n)$，全部 `q` 次查询为 $O(q \log n)$。
- 空间复杂度：$O(n)$，用于保存输入数组；二分查找本身只需 $O(1)$ 额外空间。

## [AcWing 790. 数的三次方根](https://www.acwing.com/problem/content/792/)

### 题目描述

给定一个浮点数 `n`，求它的实数三次方根，并将结果保留 `6` 位小数。

**输入格式**

输入一行，包含一个浮点数 `n`。

**输出格式**

输出一行，包含 `n` 的三次方根，结果保留 `6` 位小数。

**数据范围**

- `-10000 ≤ n ≤ 10000`

**输入样例**

```text
1000.00
```

**输出样例**

```text
10.000000
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;
import java.util.Locale;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        double number = scanner.nextDouble();
        double left = -10000.0;
        double right = 10000.0;

        for (int i = 0; i < 100; i++) {
            double middle = (left + right) / 2.0;
            if (middle * middle * middle >= number) {
                right = middle;
            } else {
                left = middle;
            }
        }

        System.out.printf(Locale.US, "%.6f%n", (left + right) / 2.0);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 12];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private String next() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            StringBuilder token = new StringBuilder();
            while (c > ' ') {
                token.append((char) c);
                c = read();
            }
            return token.toString();
        }

        private double nextDouble() throws IOException {
            return Double.parseDouble(next());
        }
    }
}
```

### 时空复杂度

- 时间复杂度：二分到误差不超过 $\varepsilon$ 时为 $O\!\left(\log\frac{R-L}{\varepsilon}\right)$；代码固定执行 `100` 次，因此在本题中也可视为 $O(1)$。
- 空间复杂度：$O(1)$。
