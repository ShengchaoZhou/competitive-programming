# 快速排序

快速排序用于把一组可比较的数据按指定顺序排列；同样的分区操作还可以只保留包含目标位置的一侧，从而在线性平均时间内寻找第 `k` 小的元素。

## [AcWing 785. 快速排序](https://www.acwing.com/problem/content/787/)

### 题目描述

给定一个包含 `n` 个整数的数列，使用快速排序将所有元素按从小到大的顺序排列，并输出排序后的数列。

**输入格式**

- 第一行是整数 `n`，表示数列长度。
- 第二行是 `n` 个整数，表示待排序的数列。

**输出格式**

输出一行 `n` 个整数，相邻整数之间用空格分隔，表示升序排列后的数列。

**数据范围**

- `1 ≤ n ≤ 100000`
- 数列中的每个整数都在 `[1, 10^9]` 内。

**输入样例**

```text
5
3 1 2 4 5
```

**输出样例**

```text
1 2 3 4 5
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] numbers = new int[n];

        for (int i = 0; i < n; i++) {
            numbers[i] = scanner.nextInt();
        }

        quickSort(numbers, 0, n - 1);

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) {
                answer.append(' ');
            }
            answer.append(numbers[i]);
        }
        System.out.println(answer);
    }

    private static void quickSort(int[] numbers, int left, int right) {
        if (left >= right) {
            return;
        }

        int pivot = numbers[left + (right - left) / 2];
        int i = left - 1;
        int j = right + 1;

        while (i < j) {
            do {
                i++;
            } while (numbers[i] < pivot);

            do {
                j--;
            } while (numbers[j] > pivot);

            if (i < j) {
                int temp = numbers[i];
                numbers[i] = numbers[j];
                numbers[j] = temp;
            }
        }

        quickSort(numbers, left, j);
        quickSort(numbers, j + 1, right);
    }

}
```

### 时空复杂度

- 时间复杂度：平均为 $O(n \log n)$，最坏为 $O(n^2)$。
- 空间复杂度：平均为 $O(\log n)$，最坏为 $O(n)$，主要来自递归调用栈。

## [AcWing 786. 第 k 个数](https://www.acwing.com/problem/content/788/)

### 题目描述

给定一个长度为 `n` 的整数数列和整数 `k`，使用快速选择算法，求这个数列按升序排列后位于第 `k` 个位置的数。这里的 `k` 从 `1` 开始计数。

**输入格式**

- 第一行包含两个整数 `n` 和 `k`。
- 第二行包含 `n` 个整数，表示给定数列。

**输出格式**

输出一个整数，表示数列中的第 `k` 小元素。

**数据范围**

- `1 ≤ n ≤ 100000`
- `1 ≤ k ≤ n`
- 数列中的每个整数都在 `[1, 10^9]` 内。

**输入样例**

```text
5 3
2 4 1 5 3
```

**输出样例**

```text
3
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int k = scanner.nextInt();
        int[] numbers = new int[n];

        for (int i = 0; i < n; i++) {
            numbers[i] = scanner.nextInt();
        }

        System.out.println(quickSelect(numbers, k - 1));
    }

    private static int quickSelect(int[] numbers, int target) {
        int left = 0;
        int right = numbers.length - 1;

        while (left < right) {
            int pivot = numbers[left + (right - left) / 2];
            int i = left - 1;
            int j = right + 1;

            while (i < j) {
                do {
                    i++;
                } while (numbers[i] < pivot);

                do {
                    j--;
                } while (numbers[j] > pivot);

                if (i < j) {
                    int temp = numbers[i];
                    numbers[i] = numbers[j];
                    numbers[j] = temp;
                }
            }

            if (target <= j) {
                right = j;
            } else {
                left = j + 1;
            }
        }

        return numbers[left];
    }

}
```

### 时空复杂度

- 时间复杂度：平均为 $O(n)$，最坏为 $O(n^2)$。
- 空间复杂度：$O(1)$；代码使用循环缩小待查区间，没有递归调用栈。
