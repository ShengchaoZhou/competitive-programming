# 双指针

双指针通过让两个位置索引按条件单向移动，解决连续区间维护、两个有序序列配对以及子序列匹配等问题。

## [AcWing 799. 最长连续不重复子序列](https://www.acwing.com/problem/content/801/)

### 题目描述

给定一个长度为 $n$ 的整数序列，请找出其中不含重复数字的最长连续子序列，并输出它的长度。

#### 输入格式

第一行包含一个整数 $n$，表示序列长度。

第二行包含 $n$ 个整数 $a_1,a_2,\ldots,a_n$，表示给定序列。

#### 输出格式

输出一个整数，表示最长的不含重复数字的连续子序列长度。

#### 数据范围

- $1 \le n \le 10^5$
- $0 \le a_i \le 10^5$

#### 输入样例

```text
5
1 2 2 3 5
```

#### 输出样例

```text
3
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int n = scanner.nextInt();
        int[] numbers = new int[n];
        int[] frequency = new int[100001];

        for (int i = 0; i < n; i++) {
            numbers[i] = scanner.nextInt();
        }

        int answer = 0;
        for (int left = 0, right = 0; right < n; right++) {
            frequency[numbers[right]]++;
            while (frequency[numbers[right]] > 1) {
                frequency[numbers[left]]--;
                left++;
            }
            answer = Math.max(answer, right - left + 1);
        }

        System.out.println(answer);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int sign = 1;
            if (c == '-') {
                sign = -1;
                c = read();
            }

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value * sign;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n)$。左右指针都只会从左向右移动一次。
- 空间复杂度：$O(n+V)$，其中 $V=10^5+1$，用于保存输入序列和数字出现次数。

## [AcWing 800. 数组元素的目标和](https://www.acwing.com/problem/content/802/)

### 题目描述

给定两个严格升序数组 $A$、$B$ 和目标值 $x$，数组下标从 $0$ 开始。请找到满足 $A[i]+B[j]=x$ 的一对下标 $(i,j)$。题目保证答案唯一。

#### 输入格式

第一行包含三个整数 $n,m,x$，分别表示数组 $A$ 的长度、数组 $B$ 的长度和目标值。

第二行包含 $n$ 个整数，表示数组 $A$。

第三行包含 $m$ 个整数，表示数组 $B$。

#### 输出格式

输出两个整数 $i$ 和 $j$，表示所求的两个数组下标。

#### 数据范围

- $n,m \le 10^5$
- 同一个数组中的元素互不相同
- $1 \le A_i,B_i \le 10^9$

#### 输入样例

```text
4 5 6
1 2 4 7
3 4 6 8 9
```

#### 输出样例

```text
1 1
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int n = scanner.nextInt();
        int m = scanner.nextInt();
        long target = scanner.nextLong();

        long[] a = new long[n];
        long[] b = new long[m];
        for (int i = 0; i < n; i++) {
            a[i] = scanner.nextLong();
        }
        for (int i = 0; i < m; i++) {
            b[i] = scanner.nextLong();
        }

        int i = 0;
        int j = m - 1;
        while (i < n && j >= 0) {
            long sum = a[i] + b[j];
            if (sum == target) {
                System.out.println(i + " " + j);
                return;
            }
            if (sum < target) {
                i++;
            } else {
                j--;
            }
        }
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        long nextLong() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int sign = 1;
            if (c == '-') {
                sign = -1;
                c = read();
            }

            long value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value * sign;
        }

        int nextInt() throws IOException {
            return (int) nextLong();
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n+m)$。两个指针最多分别移动 $n$ 次和 $m$ 次。
- 空间复杂度：$O(n+m)$，用于保存两个输入数组。

## [AcWing 2816. 判断子序列](https://www.acwing.com/problem/content/2818/)

### 题目描述

给定长度为 $n$ 的整数序列 $a$ 和长度为 $m$ 的整数序列 $b$，判断能否从 $b$ 中删除若干元素（也可以不删除），在不改变剩余元素相对顺序的前提下得到 $a$。

#### 输入格式

第一行包含两个整数 $n$ 和 $m$。

第二行包含 $n$ 个整数，表示序列 $a$。

第三行包含 $m$ 个整数，表示序列 $b$。

#### 输出格式

如果 $a$ 是 $b$ 的子序列，输出 `Yes`；否则输出 `No`。

#### 数据范围

- $1 \le n \le m \le 10^5$
- $-10^9 \le a_i,b_i \le 10^9$

#### 输入样例

```text
3 5
1 3 5
1 2 3 4 5
```

#### 输出样例

```text
Yes
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int n = scanner.nextInt();
        int m = scanner.nextInt();

        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = scanner.nextInt();
        }

        int matched = 0;
        for (int j = 0; j < m; j++) {
            int current = scanner.nextInt();
            if (matched < n && a[matched] == current) {
                matched++;
            }
        }

        System.out.println(matched == n ? "Yes" : "No");
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int sign = 1;
            if (c == '-') {
                sign = -1;
                c = read();
            }

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value * sign;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n+m)$，包括读取序列 $a$ 和扫描序列 $b$。
- 空间复杂度：$O(n)$，用于保存待匹配的序列 $a$。
