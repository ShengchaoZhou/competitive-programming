# 滑动窗口

滑动窗口维护一段连续区间及其统计量，通过移动左右边界减少重复枚举。窗口能否单向收缩，取决于约束是否具有相应单调性。

## 可变长度窗口

右端扩张加入元素，必要时移动左端恢复约束。每个元素至多进出窗口一次时，维护成本通常为 O(n)。

### 无重复的最长窗口

维护窗口中每个值的频次，出现重复时持续收缩；也可记录最近出现位置并直接跳转左端，但左端不能后退。

- [AcWing 799. 最长连续不重复子序列](https://www.acwing.com/problem/content/801/) （AcWing基础课）：用频次数组或哈希表维护最长不重复连续区间。
- [LeetCode 3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/) （Hot100/面试150/CodeTop200）：维护无重复字符窗口，注意子串必须连续。

### 最短满足条件的窗口

扩张到满足条件后，尽可能收缩并更新最短答案。正整数和随扩张不减，才能直接这样处理；覆盖字符则需维护字符需求与已满足种类。

- [LeetCode 209. 长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/) （面试150/CodeTop200）：数组元素为正数，窗口和达到 target 后尽量收缩。
- [LeetCode 76. 最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/) （Hot100/面试150/CodeTop200）：维护目标字符需求的缺口，在覆盖全部需求时缩短窗口。

### 允许有限次违约的最长窗口

把不满足原条件的元素数量作为窗口代价，超过预算就收缩。窗口始终满足代价上限后，更新最大长度。

- [LeetCode 1004. 最大连续1的个数 III](https://leetcode.cn/problems/max-consecutive-ones-iii/) （CodeTop200）：维护窗口中 0 的数量，最多允许 k 个 0 被翻转。

### 枚举目标字符种类

“每种字符至少出现 k 次”不能直接用普通窗口判断扩张或收缩方向。小写字母种类有限时，可枚举窗口中允许的不同字符数，并同时维护达到 k 次的种类数，复杂度 O(26n)。

- [LeetCode 395. 至少有 K 个重复字符的最长子串](https://leetcode.cn/problems/longest-substring-with-at-least-k-repeating-characters/) （CodeTop200）：固定目标种类数后滑动窗口，只有实际种类数与达标种类数都满足条件才更新答案。

## 固定长度窗口

窗口长度确定后，每次移入一个元素、移出一个元素，并维护频次或其他可增量更新的信息。

### 字符排列匹配

排列关系等价于各字符频次相等。将窗口长度固定为模式长度，用频次差或差异数量判断是否匹配。

- [LeetCode 438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/) （Hot100）：找到每个长度为 p.length 的异位词窗口起点。

### 等长单词拼接

所有单词长度一致时，可按单词长度划分若干个起始偏移。每个偏移下以单词为单位滑动，维护出现次数，遇到未知单词时重置。

- [LeetCode 30. 串联所有单词的子串](https://leetcode.cn/problems/substring-with-concatenation-of-all-words/) （面试150）：对每个单词长度偏移独立滑窗，重复单词必须按需求次数计数。
