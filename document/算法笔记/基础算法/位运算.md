# 位运算

位运算直接处理整数的二进制位，适合完成二进制状态检查、提取和计数等操作。

## [AcWing 801. 二进制中 1 的个数](https://www.acwing.com/problem/content/803/)

### 题目描述

给定一个长度为 $n$ 的非负整数序列，分别统计每个整数的二进制表示中有多少个 $1$。

#### 输入格式

第一行包含一个整数 $n$，表示序列长度。

第二行包含 $n$ 个整数，表示给定序列。

#### 输出格式

输出一行 $n$ 个整数，第 $i$ 个结果表示第 $i$ 个输入整数的二进制表示中 $1$ 的数量。

#### 数据范围

- $1 \le n \le 10^5$
- $0 \le a_i \le 10^9$

#### 输入样例

```text
5
1 2 3 4 5
```

#### 输出样例

```text
1 1 2 1 2
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        for (int i = 0; i < n; i++) {
            int value = scanner.nextInt();
            int count = 0;
            while (value != 0) {
                value -= value & -value;
                count++;
            }

            if (i > 0) {
                answer.append(' ');
            }
            answer.append(count);
        }

        System.out.println(answer);
    }

}
```

### 时空复杂度

- 时间复杂度：$O\!\left(\sum_{i=1}^{n}\operatorname{popcount}(a_i)\right)$，最坏可写作 $O(n\log M)$，其中 $M$ 是序列中的最大值。
- 空间复杂度：核心计算使用 $O(1)$ 额外空间；计入用于批量输出的 `StringBuilder` 后为 $O(n)$。
