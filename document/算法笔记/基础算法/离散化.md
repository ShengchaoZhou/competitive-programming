# 离散化

离散化把取值范围很大但实际出现数量有限的坐标映射为连续下标，从而可以使用数组和前缀和等结构处理这些坐标。

## [AcWing 802. 区间和](https://www.acwing.com/problem/content/804/)

### 题目描述

一条无限长的整数数轴初始处处为 $0$。先执行 $n$ 次加法操作，每次把坐标 $x$ 上的数增加 $c$；随后回答 $m$ 次询问，每次求闭区间 $[l,r]$ 内所有坐标上数值的总和。

#### 输入格式

第一行包含两个整数 $n$ 和 $m$，分别表示加法操作数和询问数。

接下来 $n$ 行，每行包含两个整数 $x$ 和 $c$，表示将坐标 $x$ 上的数增加 $c$。

再接下来 $m$ 行，每行包含两个整数 $l$ 和 $r$，表示一次区间求和询问。

#### 输出格式

输出 $m$ 行，每行一个整数，依次表示各个询问区间内的数值总和。

#### 数据范围

- $1 \le n,m \le 10^5$
- $-10^9 \le x \le 10^9$
- $-10^9 \le l \le r \le 10^9$
- $-10^4 \le c \le 10^4$

#### 输入样例

```text
3 3
1 2
3 6
7 5
1 3
4 6
7 8
```

#### 输出样例

```text
8
0
5
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;
import java.util.Arrays;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int n = scanner.nextInt();
        int m = scanner.nextInt();

        int[] updatePosition = new int[n];
        int[] updateValue = new int[n];
        int[] queryLeft = new int[m];
        int[] queryRight = new int[m];
        int[] coordinates = new int[n + 2 * m];
        int coordinateCount = 0;

        for (int i = 0; i < n; i++) {
            updatePosition[i] = scanner.nextInt();
            updateValue[i] = scanner.nextInt();
            coordinates[coordinateCount++] = updatePosition[i];
        }

        for (int i = 0; i < m; i++) {
            queryLeft[i] = scanner.nextInt();
            queryRight[i] = scanner.nextInt();
            coordinates[coordinateCount++] = queryLeft[i];
            coordinates[coordinateCount++] = queryRight[i];
        }

        Arrays.sort(coordinates, 0, coordinateCount);
        int uniqueCount = 0;
        for (int i = 0; i < coordinateCount; i++) {
            if (i == 0 || coordinates[i] != coordinates[i - 1]) {
                coordinates[uniqueCount++] = coordinates[i];
            }
        }

        long[] values = new long[uniqueCount + 1];
        for (int i = 0; i < n; i++) {
            int index = lowerBound(coordinates, uniqueCount, updatePosition[i]) + 1;
            values[index] += updateValue[i];
        }

        long[] prefixSum = new long[uniqueCount + 1];
        for (int i = 1; i <= uniqueCount; i++) {
            prefixSum[i] = prefixSum[i - 1] + values[i];
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < m; i++) {
            int leftIndex = lowerBound(coordinates, uniqueCount, queryLeft[i]) + 1;
            int rightIndex = lowerBound(coordinates, uniqueCount, queryRight[i]) + 1;
            answer.append(prefixSum[rightIndex] - prefixSum[leftIndex - 1]).append('\n');
        }
        System.out.print(answer);
    }

    private static int lowerBound(int[] values, int size, int target) {
        int left = 0;
        int right = size;
        while (left < right) {
            int middle = left + (right - left) / 2;
            if (values[middle] >= target) {
                right = middle;
            } else {
                left = middle + 1;
            }
        }
        return left;
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int sign = 1;
            if (c == '-') {
                sign = -1;
                c = read();
            }

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value * sign;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(K\log K+(n+m)\log K)$，其中 $K\le n+2m$ 是收集到的坐标数量，可简写为 $O((n+m)\log(n+m))$。
- 空间复杂度：$O(n+m)$，用于保存操作、询问、离散坐标和前缀和。
