# 高精度

高精度算法用于完成位数超过 Java 基本整数类型表示范围的整数加、减、乘、除运算。

## [AcWing 791. 高精度加法](https://www.acwing.com/problem/content/793/)

### 题目描述

给出两个不含前导零的正整数，计算并输出它们的和。两个整数都可能非常长，无法直接存入 `long`。

**输入**

输入共两行，每行一个正整数。

**输出**

输出一行，表示两个整数的和。

**数据范围**

- 每个整数的长度均在 $[1, 100000]$ 内。

**输入样例**

```text
12
23
```

**输出样例**

```text
35
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static String add(String a, String b) {
        int i = a.length() - 1;
        int j = b.length() - 1;
        int carry = 0;
        StringBuilder reversed = new StringBuilder(Math.max(a.length(), b.length()) + 1);

        while (i >= 0 || j >= 0 || carry != 0) {
            int sum = carry;
            if (i >= 0) sum += a.charAt(i--) - '0';
            if (j >= 0) sum += b.charAt(j--) - '0';
            reversed.append(sum % 10);
            carry = sum / 10;
        }

        return reversed.reverse().toString();
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String a = scanner.next();
        String b = scanner.next();

        System.out.println(add(a, b));
    }
}
```

### 时空复杂度

- 时间复杂度：$O(\max(n,m))$，其中 $n$、$m$ 分别是两个整数的位数。
- 空间复杂度：$O(\max(n,m))$，用于保存计算结果。

## [AcWing 792. 高精度减法](https://www.acwing.com/problem/content/794/)

### 题目描述

给出两个不含前导零的正整数，计算第一个整数减去第二个整数的结果。结果可能是负数，且两个整数都可能超过 `long` 的范围。

**输入**

输入共两行，每行一个正整数；第一行是被减数，第二行是减数。

**输出**

输出一行，表示两个整数之差。

**数据范围**

- 每个整数的长度均在 $[1, 100000]$ 内。

**输入样例**

```text
32
11
```

**输出样例**

```text
21
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static int compare(String a, String b) {
        if (a.length() != b.length()) {
            return Integer.compare(a.length(), b.length());
        }
        return a.compareTo(b);
    }

    // 调用时保证 a >= b。
    private static String subtract(String a, String b) {
        int i = a.length() - 1;
        int j = b.length() - 1;
        int borrow = 0;
        StringBuilder reversed = new StringBuilder(a.length());

        while (i >= 0) {
            int value = (a.charAt(i--) - '0') - borrow;
            if (j >= 0) value -= b.charAt(j--) - '0';

            if (value < 0) {
                value += 10;
                borrow = 1;
            } else {
                borrow = 0;
            }
            reversed.append(value);
        }

        while (reversed.length() > 1 && reversed.charAt(reversed.length() - 1) == '0') {
            reversed.deleteCharAt(reversed.length() - 1);
        }
        return reversed.reverse().toString();
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String a = scanner.next();
        String b = scanner.next();

        int order = compare(a, b);
        String answer;
        if (order == 0) {
            answer = "0";
        } else if (order > 0) {
            answer = subtract(a, b);
        } else {
            answer = "-" + subtract(b, a);
        }

        System.out.println(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(\max(n,m))$。
- 空间复杂度：$O(\max(n,m))$，用于保存计算结果。

## [AcWing 793. 高精度乘法](https://www.acwing.com/problem/content/795/)

### 题目描述

给出两个不含前导零的非负整数 $A$ 和 $B$。$A$ 可能有十万位，而 $B$ 是一个较小的整数；计算并输出 $A \times B$。

**输入**

第一行输入整数 $A$，第二行输入整数 $B$。

**输出**

输出一行，表示 $A \times B$ 的值。

**数据范围**

- $1 \leq A$ 的长度 $\leq 100000$。
- $0 \leq B \leq 10000$。

**输入样例**

```text
2
3
```

**输出样例**

```text
6
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static String multiply(String a, int b) {
        if (b == 0 || a.equals("0")) return "0";

        int carry = 0;
        StringBuilder reversed = new StringBuilder(a.length() + 5);

        for (int i = a.length() - 1; i >= 0; i--) {
            int product = (a.charAt(i) - '0') * b + carry;
            reversed.append(product % 10);
            carry = product / 10;
        }
        while (carry != 0) {
            reversed.append(carry % 10);
            carry /= 10;
        }

        return reversed.reverse().toString();
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String a = scanner.next();
        int b = scanner.nextInt();

        System.out.println(multiply(a, b));
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n)$，其中 $n$ 是 $A$ 的位数。
- 空间复杂度：$O(n)$，用于保存乘积。

## [AcWing 794. 高精度除法](https://www.acwing.com/problem/content/796/)

### 题目描述

给出两个正整数 $A$ 和 $B$。$A$ 可能有十万位，$B$ 是一个较小的整数；计算整数除法 $A \div B$ 的商与余数。

**输入**

第一行输入被除数 $A$，第二行输入除数 $B$。

**输出**

输出共两行：第一行是整数商，第二行是余数。

**数据范围**

- $1 \leq A$ 的长度 $\leq 100000$。
- $1 \leq B \leq 10000$。

**输入样例**

```text
7
2
```

**输出样例**

```text
3
1
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String a = scanner.next();
        int b = scanner.nextInt();

        int remainder = 0;
        StringBuilder quotient = new StringBuilder(a.length());
        for (int i = 0; i < a.length(); i++) {
            int current = remainder * 10 + (a.charAt(i) - '0');
            int digit = current / b;
            remainder = current % b;
            if (digit != 0 || quotient.length() != 0) {
                quotient.append(digit);
            }
        }
        if (quotient.length() == 0) quotient.append('0');

        System.out.println(quotient);
        System.out.println(remainder);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n)$，其中 $n$ 是 $A$ 的位数。
- 空间复杂度：$O(n)$，用于保存商。
