# 区间合并

区间合并用于把彼此重叠或端点相接的区间归并成若干互不相交的区间。

## [AcWing 803. 区间合并](https://www.acwing.com/problem/content/805/)

### 题目描述

给定 $n$ 个闭区间 $[l_i,r_i]$，将所有存在交集的区间反复合并，并输出最终剩余的区间数量。两个区间只在端点处相交时，也视为有交集；例如 $[1,3]$ 与 $[2,6]$ 会合并为 $[1,6]$。

#### 输入格式

第一行包含一个整数 $n$，表示区间数量。

接下来 $n$ 行，每行包含两个整数 $l_i$ 和 $r_i$，表示一个闭区间。

#### 输出格式

输出一个整数，表示所有相交区间合并完成后的区间数量。

#### 数据范围

- $1 \le n \le 10^5$
- $-10^9 \le l_i \le r_i \le 10^9$

#### 输入样例

```text
5
1 2
2 4
5 6
7 8
7 9
```

#### 输出样例

```text
3
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[][] intervals = new int[n][2];

        for (int i = 0; i < n; i++) {
            intervals[i][0] = scanner.nextInt();
            intervals[i][1] = scanner.nextInt();
        }

        Arrays.sort(intervals, (first, second) -> {
            int byLeft = Integer.compare(first[0], second[0]);
            return byLeft != 0 ? byLeft : Integer.compare(first[1], second[1]);
        });

        int mergedCount = 1;
        int currentRight = intervals[0][1];
        for (int i = 1; i < n; i++) {
            if (intervals[i][0] > currentRight) {
                mergedCount++;
                currentRight = intervals[i][1];
            } else {
                currentRight = Math.max(currentRight, intervals[i][1]);
            }
        }

        System.out.println(mergedCount);
    }

}
```

### 时空复杂度

- 时间复杂度：$O(n\log n)$，主要开销来自按左端点排序；排序后的扫描为 $O(n)$。
- 空间复杂度：$O(n)$，用于保存全部区间以及 Java 对对象数组排序时所需的辅助空间。
