# 区间问题

区间贪心通过端点排序、维护当前边界或最早结束时间，求选点、选择、分组、覆盖与分段的最优方案。先确认端点相遇是否算冲突，再确定严格或非严格不等号。

## 右端点贪心

按右端点从小到大排序，优先处理最早结束的区间。选择当前最早的可行结束位置，为后续区间保留尽可能多的空间；交换论证可将任意最优解的首个决策替换为该选择而不使结果变差。排序加扫描的时间复杂度为 $O(n\log n)$。

### 最少选点覆盖所有区间

维护上次选中的点 `p`，若当前闭区间左端点大于 `p`，则在当前右端点选新点。若左端点等于 `p`，该区间已经被覆盖。每次新选点都对应一个此前无法覆盖的区间，因此不能再减少点数。

- [AcWing 905. 区间选点](https://www.acwing.com/problem/content/907/) （AcWing基础课）：所有区间均为闭区间，在最早结束区间的右端点选点。
- [LeetCode 452. 用最少数量的箭引爆气球](https://leetcode.cn/problems/minimum-number-of-arrows-to-burst-balloons/) （面试150）：一支箭对应一个选点，相接端点可以共用一支箭；坐标可能接近整数边界，排序比较应使用比较函数，避免相减溢出。

### 最多选择不相交区间

每次选择最早结束且与已选区间不冲突的区间，随后更新已选区间的右边界。闭区间要求 `left > previousRight`；若题意允许端点相接，则改为 `left >= previousRight`。

- [AcWing 908. 最大不相交区间数量](https://www.acwing.com/problem/content/910/) （AcWing基础课）：两个区间共用端点也算相交，必须使用严格大于的兼容条件。

## 区间分组

按左端点排序，用小根堆保存每个已开组最后一个区间的右端点。当前区间能接到最早结束的组时，弹出该组末端并放入新末端；否则新增一组。若最早结束的组都无法复用，则所有组都与当前区间重叠，新增组是必要的。

### 最少并行资源

该过程的时间复杂度为 $O(n\log n)$，堆空间为 $O(n)$。上述实现为每个组始终保留一个末端，最终堆大小就是所需组数；若改成弹出所有已结束区间、仅维护正在占用的资源，则必须记录堆大小的最大值。

- [AcWing 906. 区间分组](https://www.acwing.com/problem/content/908/) （AcWing基础课）：闭区间端点重合时不能同组，只有 `earliestEnd < left` 才能复用。
- [LeetCode 253. 会议室 II](https://leetcode.cn/problems/meeting-rooms-ii/) （CodeTop200）：会议在结束时刻可以接下一场，复用条件为 `earliestEnd <= start`，答案等于同时进行的会议数量峰值。

## 区间覆盖

按左端点排序。维护已经连续覆盖到的位置 `r`，在所有 `left <= r` 的候选中选择右端点最远的一个，把覆盖范围尽可能向右延伸。每轮消耗一个区间，并丢弃不比它覆盖更远的候选。

### 最少区间覆盖目标

若当前没有可接上的区间，或目标尚未覆盖且边界无法前进，则无解。排序后每个候选只扫描一次，总时间为 $O(n\log n)$，保存区间需要 $O(n)$ 空间。目标为单个点时，也必须先检查是否有候选区间包含该点。

- [AcWing 907. 区间覆盖](https://www.acwing.com/problem/content/909/) （AcWing基础课）：从目标左端点开始扩展，达到目标右端点即结束；闭区间首尾相接不会产生覆盖空隙。

## 边界闭合分段

要求同一类元素不能出现在多个段中时，当前段至少要覆盖该段内每个元素的最后一次出现位置。扫描并不断扩大段末端，只有到达这个末端时才能安全切分。

### 每类元素只属于一段

记录每个字符的最后位置，扫描时执行 `end = max(end, last[s[i]])`；`i == end` 时立刻切段，能够得到最多的合法段。时间复杂度为 $O(n)$，额外空间为 $O(|\Sigma|)$，其中 `Σ` 为字符集合。

- [LeetCode 763. 划分字母区间](https://leetcode.cn/problems/partition-labels/) （Hot100）：用字符最后位置约束分段边界，输出每个最早闭合段的长度。
