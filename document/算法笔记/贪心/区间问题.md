# 区间问题

区间贪心用于在若干数轴区间中求最少选点数、最多不相交区间数、最少分组数或覆盖目标区间所需的最少区间数。

## [AcWing 905. 区间选点](https://www.acwing.com/problem/content/907/)

### 题目描述

数轴上有 $N$ 个闭区间 $[a_i,b_i]$。请选出尽量少的点，使每个给定区间内都至少有一个被选中的点，并求所需点数的最小值。区间两端点也属于该区间。

**输入格式**

- 第一行包含一个整数 $N$，表示区间数量。
- 接下来 $N$ 行，每行包含两个整数 $a_i$ 和 $b_i$，表示一个闭区间。

**输出格式**

输出一个整数，表示使所有区间都包含被选点所需的最少点数。

**数据范围**

- $1 \le N \le 10^5$
- $-10^9 \le a_i \le b_i \le 10^9$

**输入样例**

```text
3
-1 1
2 4
3 5
```

**输出样例**

```text
2
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int intervalCount = scanner.nextInt();
        int[][] intervals = new int[intervalCount][2];

        for (int i = 0; i < intervalCount; i++) {
            intervals[i][0] = scanner.nextInt();
            intervals[i][1] = scanner.nextInt();
        }

        Arrays.sort(intervals, (first, second) -> {
            int byRight = Integer.compare(first[1], second[1]);
            return byRight != 0 ? byRight : Integer.compare(first[0], second[0]);
        });

        int selectedPoint = Integer.MIN_VALUE;
        int answer = 0;
        for (int[] interval : intervals) {
            if (interval[0] > selectedPoint) {
                selectedPoint = interval[1];
                answer++;
            }
        }

        System.out.println(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(N\log N)$，排序后只需线性扫描一次。
- 空间复杂度：$O(N)$，用于保存所有区间及 Java 对象数组排序的辅助空间。

## [AcWing 908. 最大不相交区间数量](https://www.acwing.com/problem/content/910/)

### 题目描述

数轴上有 $N$ 个闭区间 $[a_i,b_i]$。请从中选出尽量多的区间，使任意两个被选区间都没有交集，并求最多可选多少个。两个闭区间只共享一个端点时仍视为相交，不能同时选取。

**输入格式**

- 第一行包含一个整数 $N$，表示区间数量。
- 接下来 $N$ 行，每行包含两个整数 $a_i$ 和 $b_i$，表示一个闭区间。

**输出格式**

输出一个整数，表示可选取的两两不相交区间的最大数量。

**数据范围**

- $1 \le N \le 10^5$
- $-10^9 \le a_i \le b_i \le 10^9$

**输入样例**

```text
3
-1 1
2 4
3 5
```

**输出样例**

```text
2
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int intervalCount = scanner.nextInt();
        int[][] intervals = new int[intervalCount][2];

        for (int i = 0; i < intervalCount; i++) {
            intervals[i][0] = scanner.nextInt();
            intervals[i][1] = scanner.nextInt();
        }

        Arrays.sort(intervals, (first, second) -> {
            int byRight = Integer.compare(first[1], second[1]);
            return byRight != 0 ? byRight : Integer.compare(first[0], second[0]);
        });

        int previousRight = Integer.MIN_VALUE;
        int answer = 0;
        for (int[] interval : intervals) {
            if (interval[0] > previousRight) {
                previousRight = interval[1];
                answer++;
            }
        }

        System.out.println(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(N\log N)$，主要开销来自按右端点排序。
- 空间复杂度：$O(N)$，用于保存所有区间及 Java 对象数组排序的辅助空间。

## [AcWing 906. 区间分组](https://www.acwing.com/problem/content/908/)

### 题目描述

给定 $N$ 个闭区间 $[a_i,b_i]$，需要将它们全部分到若干组中，使每一组内的区间两两没有交集，求最少需要多少组。两个区间只在端点处相遇时也算有交集，不能放入同一组。

**输入格式**

- 第一行包含一个整数 $N$，表示区间数量。
- 接下来 $N$ 行，每行包含两个整数 $a_i$ 和 $b_i$，表示一个闭区间。

**输出格式**

输出一个整数，表示满足组内区间两两不相交时所需的最少组数。

**数据范围**

- $1 \le N \le 10^5$
- $-10^9 \le a_i \le b_i \le 10^9$

**输入样例**

```text
3
-1 1
2 4
3 5
```

**输出样例**

```text
2
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int intervalCount = scanner.nextInt();
        int[][] intervals = new int[intervalCount][2];

        for (int i = 0; i < intervalCount; i++) {
            intervals[i][0] = scanner.nextInt();
            intervals[i][1] = scanner.nextInt();
        }

        Arrays.sort(intervals, (first, second) -> {
            int byLeft = Integer.compare(first[0], second[0]);
            return byLeft != 0 ? byLeft : Integer.compare(first[1], second[1]);
        });

        PriorityQueue<Integer> groupRightEnds = new PriorityQueue<>();
        for (int[] interval : intervals) {
            if (!groupRightEnds.isEmpty() && groupRightEnds.peek() < interval[0]) {
                groupRightEnds.poll();
            }
            groupRightEnds.offer(interval[1]);
        }

        System.out.println(groupRightEnds.size());
    }
}
```

### 时空复杂度

- 时间复杂度：$O(N\log N)$，排序和每次小根堆操作均为对数级。
- 空间复杂度：$O(N)$，用于保存区间和各组当前的右端点。

## [AcWing 907. 区间覆盖](https://www.acwing.com/problem/content/909/)

### 题目描述

给定一个需要覆盖的闭区间 $[s,t]$ 以及 $N$ 个候选闭区间 $[a_i,b_i]$。请从候选区间中选出尽量少的区间，使它们的并集完全覆盖 $[s,t]$；如果无法完全覆盖，则输出 $-1$。

**输入格式**

- 第一行包含两个整数 $s$ 和 $t$，表示目标闭区间的左、右端点。
- 第二行包含一个整数 $N$，表示候选区间数量。
- 接下来 $N$ 行，每行包含两个整数 $a_i$ 和 $b_i$，表示一个候选闭区间。

**输出格式**

输出完全覆盖目标区间所需的最少候选区间数；如果不存在可行方案，输出 $-1$。

**数据范围**

- $1 \le N \le 10^5$
- $-10^9 \le a_i \le b_i \le 10^9$
- $-10^9 \le s \le t \le 10^9$

**输入样例**

```text
1 5
3
-1 3
2 4
3 5
```

**输出样例**

```text
2
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int targetLeft = scanner.nextInt();
        int targetRight = scanner.nextInt();
        int intervalCount = scanner.nextInt();
        int[][] intervals = new int[intervalCount][2];

        for (int i = 0; i < intervalCount; i++) {
            intervals[i][0] = scanner.nextInt();
            intervals[i][1] = scanner.nextInt();
        }

        Arrays.sort(intervals, (first, second) -> {
            int byLeft = Integer.compare(first[0], second[0]);
            return byLeft != 0 ? byLeft : Integer.compare(second[1], first[1]);
        });

        int currentLeft = targetLeft;
        int index = 0;
        int selectedCount = 0;
        int answer = -1;

        while (true) {
            int farthestRight = Integer.MIN_VALUE;
            while (index < intervalCount && intervals[index][0] <= currentLeft) {
                farthestRight = Math.max(farthestRight, intervals[index][1]);
                index++;
            }

            if (farthestRight < currentLeft) {
                break;
            }

            selectedCount++;
            if (farthestRight >= targetRight) {
                answer = selectedCount;
                break;
            }

            if (farthestRight == currentLeft) {
                break;
            }
            currentLeft = farthestRight;
        }

        System.out.println(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(N\log N)$，排序后每个候选区间最多扫描一次。
- 空间复杂度：$O(N)$，用于保存所有候选区间及 Java 对象数组排序的辅助空间。
