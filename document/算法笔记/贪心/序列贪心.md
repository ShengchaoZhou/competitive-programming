# 序列贪心

序列贪心利用扫描过程中可维护的边界、余额或局部约束，逐步作出不会损失最优解的选择。不同模型依赖不同的不变量，不能把所有局部最优都直接当作全局最优。

## 可达边界扩展

数组元素表示从当前位置最多向右跳几步。在所有已知可达的位置中，维护最远能到达的下标 `farthest`。只有当前下标本身可达时，才能用 `i + nums[i]` 扩展这个边界。

### 判断能否到达终点

从左到右扫描，若 `i > farthest`，说明前面的所有位置都无法跨越此处，后续位置也无法到达。否则更新最远边界；一旦覆盖末尾即可成功。时间复杂度为 $O(n)$，额外空间为 $O(1)$。

- [LeetCode 55. 跳跃游戏](https://leetcode.cn/problems/jump-game/) （Hot100/面试150/CodeTop200）：检查是否存在可达路径，只维护当前最远可达位置，不必枚举具体跳跃方案。

### 最少跳跃次数

将相同跳跃次数能够覆盖的位置视为一层。`end` 记录当前层右边界，扫描本层时维护下一层最远边界；走到 `end` 才增加一次跳跃并更新层边界。这相当于压缩了层次搜索，时间为 $O(n)$，空间为 $O(1)$。

- [LeetCode 45. 跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/) （Hot100/面试150/CodeTop200）：题目保证可达，只扫描到倒数第二个位置，避免到终点后再多计一次跳跃；单元素数组答案为 `0`。推广到不保证可达时，应检查边界是否无法继续前进。

## 环形余额

令 `delta[i] = gas[i] - cost[i]`，一圈总余额为负时必定无解。扫描中维护候选起点到当前位置的余额，若在 `i` 首次变负，则候选区间内任意一点出发都无法通过 `i`，可把起点直接移到 `i + 1` 并清空局部余额。

### 可行出发点

每次失败都排除一整段起点；总余额非负时，最后保留的候选可以完成一圈。时间复杂度为 $O(n)$，额外空间为 $O(1)$，不必逐个起点模拟整个环。

- [LeetCode 134. 加油站](https://leetcode.cn/problems/gas-station/) （面试150/CodeTop200）：同时累计全局总余额与当前候选的局部余额，最后先检查全局是否非负，再返回候选起点。

## 双向约束

每个位置至少分配一个单位，若它比相邻位置的评分高，分配量也必须更多。左侧约束与右侧约束可分别处理，再对两侧要求取最大值。

### 相邻大小决定最小分配

从左到右，评分上升时令 `left[i] = left[i-1] + 1`，否则重置为 `1`；从右到左同理维护右侧所需数量。每个位置取两侧下界的最大值，这既满足全部约束，也逐点达到可行最小值。时间复杂度为 $O(n)$，用一个数组保存左侧要求时空间为 $O(n)$。

- [LeetCode 135. 分发糖果](https://leetcode.cn/problems/candy/) （面试150/CodeTop200）：相同评分没有糖果相等或递增的要求；第二遍应取两侧要求的最大值，不能简单覆盖第一遍结果。

## 可行状态区间

含通配符的括号序列中，用 `[low, high]` 表示当前前缀可能剩余的未匹配左括号数量范围。普通左括号使两端加一，普通右括号使两端减一，通配符可作左括号、右括号或空串，使范围向两侧扩展。

### 含通配符的括号匹配

每步若 `high < 0`，表示即使最大限度解释为左括号也无法匹配当前前缀，立即无效；将 `low` 截断到 `0`，丢弃非法的负状态。最终 `low == 0` 才说明存在完全匹配的解释。时间复杂度为 $O(n)$，空间为 $O(1)$。

- [LeetCode 678. 有效的括号字符串](https://leetcode.cn/problems/valid-parenthesis-string/) （CodeTop200）：`*` 同时允许三种解释，维护可行数量范围即可；只比较总括号数量会忽略前缀顺序限制。
