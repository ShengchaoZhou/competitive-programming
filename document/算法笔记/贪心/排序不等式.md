# 排序不等式

排序不等式用于通过调整任务顺序，使按位置产生的加权等待代价最小。

## [AcWing 913. 排队打水](https://www.acwing.com/problem/content/915/)

### 题目描述

有 `n` 个人要在同一个水龙头前排队打水，第 `i` 个人装满水桶需要 `t[i]` 单位时间。一个人的等待时间是排在他前面的所有人的打水时间之和，第一个人的等待时间为 `0`。

请安排排队顺序，求所有人等待时间之和的最小值。

**输入格式**

- 第一行包含整数 `n`，表示打水的人数。
- 第二行包含 `n` 个整数，第 `i` 个整数 `t[i]` 表示第 `i` 个人打水所需的时间。

**输出格式**

输出一个整数，表示所有人等待时间之和的最小值。

**数据范围**

- `1 ≤ n ≤ 10^5`
- `1 ≤ t[i] ≤ 10^4`

**输入样例**

```text
7
3 6 1 4 2 5 7
```

**输出样例**

```text
56
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] times = new int[n];

        for (int i = 0; i < n; i++) {
            times[i] = scanner.nextInt();
        }

        Arrays.sort(times);

        long answer = 0;
        for (int i = 0; i < n; i++) {
            answer += (long) times[i] * (n - i - 1);
        }

        System.out.println(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n\log n)$。
- 空间复杂度：$O(n)$，用于保存所有人的打水时间。
