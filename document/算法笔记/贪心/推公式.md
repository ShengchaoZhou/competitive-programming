# 推公式

推公式类贪心用于根据目标函数推导元素的排列规则，从而使全局的最坏代价尽可能小。

## [AcWing 125. 耍杂技的牛](https://www.acwing.com/problem/content/127/)

### 题目描述

`N` 头奶牛要通过彼此站在对方身上组成一个竖直堆叠。第 `i` 头牛的重量为 `W[i]`，强壮程度为 `S[i]`。对于堆叠中的某头牛，它的风险值等于位于它上方的所有牛的总重量减去它自身的强壮程度。可以任意安排奶牛从上到下的顺序，求所有奶牛风险值中的最大值最小能够是多少。

**输入格式**

- 第一行包含整数 `N`，表示奶牛数量。
- 接下来 `N` 行，每行包含两个整数 `W[i]` 和 `S[i]`，分别表示一头牛的重量和强壮程度。

**输出格式**

输出一个整数，表示所有排列中能取到的最小最大风险值。

**数据范围**

- `1 ≤ N ≤ 50000`
- `1 ≤ W[i] ≤ 10000`
- `1 ≤ S[i] ≤ 1000000000`

**输入样例**

```text
3
10 3
2 5
3 3
```

**输出样例**

```text
2
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;
import java.util.Arrays;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int n = scanner.nextInt();
        Cow[] cows = new Cow[n];

        for (int i = 0; i < n; i++) {
            cows[i] = new Cow(scanner.nextInt(), scanner.nextInt());
        }

        Arrays.sort(cows, (first, second) -> Long.compare(
                (long) first.weight + first.strength,
                (long) second.weight + second.strength
        ));

        long weightAbove = 0;
        long minimumMaximumRisk = Long.MIN_VALUE;

        for (Cow cow : cows) {
            minimumMaximumRisk = Math.max(
                    minimumMaximumRisk,
                    weightAbove - cow.strength
            );
            weightAbove += cow.weight;
        }

        System.out.println(minimumMaximumRisk);
    }

    private static class Cow {
        private final int weight;
        private final int strength;

        private Cow(int weight, int strength) {
            this.weight = weight;
            this.strength = strength;
        }
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) return -1;
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(N\log N)$，主要开销来自对奶牛排序。
- 空间复杂度：$O(N)$，用于存储奶牛数据及 Java 对象排序所需的辅助空间。
