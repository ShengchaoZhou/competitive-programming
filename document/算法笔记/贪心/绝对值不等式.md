# 绝对值不等式

绝对值不等式用于在数轴上选择一个位置，使它到所有给定位置的距离之和最小。

## [AcWing 104. 货仓选址](https://www.acwing.com/problem/content/106/)

### 题目描述

一条数轴上有 `N` 家商店，第 `i` 家商店的坐标为 `A[i]`。现在要在数轴上建立一座货仓，每天需要从货仓向每家商店运送一车商品。求货仓到所有商店的距离之和能够取到的最小值。

**输入格式**

- 第一行包含整数 `N`，表示商店数量。
- 第二行包含 `N` 个整数 `A[1]` 到 `A[N]`，表示各家商店的坐标。

**输出格式**

输出一个整数，表示货仓到所有商店的最小距离之和。

**数据范围**

- `1 ≤ N ≤ 100000`
- `0 ≤ A[i] ≤ 40000`

**输入样例**

```text
4
6 2 9 1
```

**输出样例**

```text
12
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] positions = new int[n];

        for (int i = 0; i < n; i++) {
            positions[i] = scanner.nextInt();
        }

        Arrays.sort(positions);
        int warehouse = positions[n / 2];
        long minimumDistance = 0;

        for (int position : positions) {
            minimumDistance += Math.abs((long) position - warehouse);
        }

        System.out.println(minimumDistance);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(N\log N)$，主要开销来自坐标排序。
- 空间复杂度：$O(N)$，用于存储所有商店坐标。
