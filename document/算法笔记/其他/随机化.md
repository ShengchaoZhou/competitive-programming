# 随机化

随机化题的重点是证明输出分布满足要求，而不只是让结果看起来随机。常用模型包括拒绝采样、等概率洗牌，以及把权重映射为整数区间。

## 拒绝采样

若底层随机函数的独立调用各自等概率，可将多个结果组合成更大的等概率样本空间。只接受其中大小为目标范围整数倍的一段，对其取余映射；丢弃剩余样本并重新抽取，保证各输出拥有相同数量的原像。

### 用小范围随机数构造新分布

两次 `rand7()` 构成 `x = (a - 1) * 7 + b`，使 `x` 在 `1..49` 等概率分布。接受 `x <= 40` 并返回 `(x - 1) % 10 + 1`，其余重试。每个结果恰好对应四个被接受样本。

- [LeetCode 470. 用 Rand7() 实现 Rand10()](https://leetcode.cn/problems/implement-rand10-using-rand7/) （CodeTop200）：接受率为 `40/49`，该基础方案平均调用 `rand7()` 的次数为 `2 × 49/40 = 2.45`，期望时间和额外空间均为 $O(1)$；重试次数没有确定的最坏上限。直接对 `1..49` 取模会产生偏差。

## Fisher-Yates 洗牌

从数组末尾向前遍历位置 `i`，在闭区间 `[0, i]` 中均匀抽取下标 `j`，交换两个位置，然后固定位置 `i`。每次只从尚未固定的元素中选择，所有排列的生成概率均为 $1/n!$。

### 等概率生成排列

每轮从整个数组抽取交换对象通常不能保证均匀分布，抽样范围必须随已固定部分缩小。洗牌时间为 $O(n)$，原地交换使用 $O(1)$ 工作空间；若需要恢复原始状态，则另存一份初始数组。

- [LeetCode 384. 打乱数组](https://leetcode.cn/problems/shuffle-an-array/) （CodeTop200）：保留不可被洗牌过程修改的原数组副本，`reset` 返回其内容，`shuffle` 使用 Fisher-Yates。返回数组时注意副本与内部状态的引用关系，防止调用方意外修改保存的初始序列。

## 权重区间采样

对正权重求前缀和 `prefix[i]`，总权重为 `W`。在整数区间 `[1, W]` 中均匀抽取 `r`，返回第一个满足 `prefix[i] >= r` 的下标；每个下标对应恰好 `w[i]` 个整数，因此概率是 `w[i] / W`。

### 按权重随机选择下标

前缀和严格递增，可以二分查找目标区间。预处理时间与空间均为 $O(n)$，每次采样为 $O(\log n)$；总权重使用足够宽的类型，随机整数的上下界要和二分条件保持一致。

- [LeetCode 528. 按权重随机选择](https://leetcode.cn/problems/random-pick-with-weight/) （CodeTop200）：将每个下标的权重转为前缀区间长度，抽取均匀整数后查找第一个不小于它的前缀和，无需按权重复制元素。
