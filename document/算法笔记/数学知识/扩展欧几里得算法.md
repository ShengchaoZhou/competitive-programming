# 扩展欧几里得算法

扩展欧几里得算法在计算最大公约数的同时，求出裴蜀等式的一组整数系数，并可据此判断和求解线性同余方程。

| 算法类型 | 题型 | 题目与题集标记 |
| --- | --- | --- |
| [裴蜀等式](#裴蜀等式) | 求整数系数 | [AcWing 877. 扩展欧几里得算法](https://www.acwing.com/problem/content/879/) （AcWing基础课） |
| [线性同余方程](#线性同余方程) | 判断有解并构造一组解 | [AcWing 878. 线性同余方程](https://www.acwing.com/problem/content/880/) （AcWing基础课） |

## 裴蜀等式

对正整数 `a、b`，总能找到整数 `x、y` 使 $ax+by=\gcd(a,b)$。若递归得到 $bx'+(a\bmod b)y'=d$，则当前层的系数为：

$$x=y',\qquad y=x'-\lfloor a/b\rfloor y'$$

`b = 0` 时取 `x = 1、y = 0`。时间复杂度为 $O(\log\min(a,b))$；递归需要同阶栈空间，迭代维护系数可降至 $O(1)$ 额外空间。

### 求整数系数

系数允许为负数，且通常不唯一；若已有一组解，则 $x+k(b/d),\ y-k(a/d)$ 仍满足等式。中间系数更新涉及乘法，使用足够宽的整数类型。

- [AcWing 877. 扩展欧几里得算法](https://www.acwing.com/problem/content/879/) （AcWing基础课）：输出任意一组满足裴蜀等式的系数，无需把它们限制为非负数。

## 线性同余方程

将 $ax\equiv b\pmod m$ 写成 $ax+my=b$。设 $d=\gcd(a,m)$，方程有解当且仅当 `d` 整除 `b`。若扩展欧几里得得到 $ax_0+my_0=d$，一组解为 $x=x_0(b/d)$。

### 判断有解并构造一组解

所有解以 `m / d` 为周期，可将结果规范到 `[0, m/d)`；程序语言中的余数可能为负，需要使用 `(x % mod + mod) % mod`。每组计算时间复杂度为 $O(\log\min(a,m))$，计算缩放系数时注意乘法溢出。

- [AcWing 878. 线性同余方程](https://www.acwing.com/problem/content/880/) （AcWing基础课）：先判断整除条件，再缩放裴蜀系数并按周期化简；当 `b = 1` 时便是一般模数下的逆元问题。
