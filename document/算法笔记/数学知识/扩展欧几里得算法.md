# 扩展欧几里得算法

扩展欧几里得算法用于在求最大公约数的同时求出裴蜀等式的一组系数，并可进一步求解线性同余方程。

## [AcWing 877. 扩展欧几里得算法](https://www.acwing.com/problem/content/879/)

### 题目描述

给定 $n$ 对正整数 $a_i,b_i$，对每一对数求一组整数 $x_i,y_i$，使 $a_ix_i+b_iy_i=\gcd(a_i,b_i)$。答案可能不唯一，输出任意一组满足条件的整数即可。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含两个整数 $a_i,b_i$。

**输出格式**

共输出 $n$ 行，第 $i$ 行包含一组满足条件的整数 $x_i,y_i$。

**数据范围**

- $1\le n\le 10^5$
- $1\le a_i,b_i\le 2\times 10^9$

**输入样例**

```text
2
4 6
8 18
```

**输出样例**

```text
-1 1
-2 1
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int queryCount = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        while (queryCount-- > 0) {
            long a = scanner.nextLong();
            long b = scanner.nextLong();
            ExtendedGcdResult result = extendedGcd(a, b);
            answer.append(result.x).append(' ').append(result.y).append('\n');
        }

        System.out.print(answer);
    }

    private static ExtendedGcdResult extendedGcd(long a, long b) {
        long oldR = a;
        long r = b;
        long oldX = 1;
        long x = 0;
        long oldY = 0;
        long y = 1;

        while (r != 0) {
            long quotient = oldR / r;

            long nextR = oldR - quotient * r;
            oldR = r;
            r = nextR;

            long nextX = oldX - quotient * x;
            oldX = x;
            x = nextX;

            long nextY = oldY - quotient * y;
            oldY = y;
            y = nextY;
        }

        return new ExtendedGcdResult(oldR, oldX, oldY);
    }

    private static class ExtendedGcdResult {
        private final long gcd;
        private final long x;
        private final long y;

        private ExtendedGcdResult(long gcd, long x, long y) {
            this.gcd = gcd;
            this.x = x;
            this.y = y;
        }
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            return (int) nextLong();
        }

        private long nextLong() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            long value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：每组数据为 $O(\log\min(a_i,b_i))$。
- 空间复杂度：$O(1)$，不计输出缓冲区。

## [AcWing 878. 线性同余方程](https://www.acwing.com/problem/content/880/)

### 题目描述

给定 $n$ 组整数 $a_i,b_i,m_i$，对每组数据求一个整数 $x_i$，使 $a_ix_i\equiv b_i\pmod{m_i}$。若不存在满足条件的整数，则输出 `impossible`；若存在多组解，输出任意一组即可，且输出值必须位于 `int` 范围内。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含三个整数 $a_i,b_i,m_i$。

**输出格式**

共输出 $n$ 行。对于每组数据，若有解则输出一个满足条件的整数，否则输出 `impossible`。

**数据范围**

- $1\le n\le 10^5$
- $1\le a_i,b_i,m_i\le 2\times 10^9$

**输入样例**

```text
2
2 3 6
4 3 5
```

**输出样例**

```text
impossible
-3
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int queryCount = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        while (queryCount-- > 0) {
            long a = scanner.nextLong();
            long b = scanner.nextLong();
            long modulus = scanner.nextLong();
            ExtendedGcdResult result = extendedGcd(a, modulus);

            if (b % result.gcd != 0) {
                answer.append("impossible\n");
            } else {
                long solution = result.x * (b / result.gcd) % modulus;
                answer.append(solution).append('\n');
            }
        }

        System.out.print(answer);
    }

    private static ExtendedGcdResult extendedGcd(long a, long b) {
        long oldR = a;
        long r = b;
        long oldX = 1;
        long x = 0;
        long oldY = 0;
        long y = 1;

        while (r != 0) {
            long quotient = oldR / r;

            long nextR = oldR - quotient * r;
            oldR = r;
            r = nextR;

            long nextX = oldX - quotient * x;
            oldX = x;
            x = nextX;

            long nextY = oldY - quotient * y;
            oldY = y;
            y = nextY;
        }

        return new ExtendedGcdResult(oldR, oldX, oldY);
    }

    private static class ExtendedGcdResult {
        private final long gcd;
        private final long x;
        private final long y;

        private ExtendedGcdResult(long gcd, long x, long y) {
            this.gcd = gcd;
            this.x = x;
            this.y = y;
        }
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            return (int) nextLong();
        }

        private long nextLong() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            long value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：每组数据为 $O(\log\min(a_i,m_i))$。
- 空间复杂度：$O(1)$，不计输出缓冲区。
