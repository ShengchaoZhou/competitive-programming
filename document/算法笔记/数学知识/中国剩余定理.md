# 中国剩余定理

中国剩余定理及其扩展形式用于合并多个模数可以不互质的同余方程，并判断方程组是否存在公共解。

## [AcWing 204. 表达整数的奇怪方式](https://www.acwing.com/problem/content/206/)

### 题目描述

给定 $n$ 组整数 $a_i,m_i$，求满足 $x\equiv m_i\pmod{a_i}$（$1\le i\le n$）的最小非负整数 $x$。各个模数不保证两两互质；如果不存在公共解，则输出 $-1$。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，第 $i$ 行包含两个整数 $a_i,m_i$。

**输出格式**

若方程组有解，输出满足所有同余式的最小非负整数；否则输出 $-1$。若解存在，数据保证答案位于 64 位有符号整数范围内。

**数据范围**

- $1\le n\le 25$
- $1\le a_i\le 2^{31}-1$
- $0\le m_i<a_i$

**输入样例**

```text
2
8 7
11 9
```

**输出样例**

```text
31
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int equationCount = scanner.nextInt();
        java.math.BigInteger currentModulus = java.math.BigInteger.valueOf(scanner.nextLong());
        java.math.BigInteger currentRemainder = java.math.BigInteger.valueOf(scanner.nextLong());
        boolean hasSolution = true;

        for (int i = 1; i < equationCount; i++) {
            java.math.BigInteger nextModulus = java.math.BigInteger.valueOf(scanner.nextLong());
            java.math.BigInteger nextRemainder = java.math.BigInteger.valueOf(scanner.nextLong());

            if (!hasSolution) {
                continue;
            }

            java.math.BigInteger gcd = currentModulus.gcd(nextModulus);
            java.math.BigInteger difference = nextRemainder.subtract(currentRemainder);
            if (!difference.mod(gcd).equals(java.math.BigInteger.ZERO)) {
                hasSolution = false;
                continue;
            }

            java.math.BigInteger stepModulus = nextModulus.divide(gcd);
            java.math.BigInteger step = java.math.BigInteger.ZERO;
            if (!stepModulus.equals(java.math.BigInteger.ONE)) {
                java.math.BigInteger reducedCurrent = currentModulus.divide(gcd).mod(stepModulus);
                java.math.BigInteger inverse = reducedCurrent.modInverse(stepModulus);
                step = difference.divide(gcd).mod(stepModulus)
                        .multiply(inverse).mod(stepModulus);
            }

            currentRemainder = currentRemainder.add(currentModulus.multiply(step));
            currentModulus = currentModulus.divide(gcd).multiply(nextModulus);
            currentRemainder = currentRemainder.mod(currentModulus);
        }

        System.out.println(hasSolution ? currentRemainder : -1);
    }
}
```

### 时空复杂度

- 时间复杂度：需要合并 $n-1$ 次同余方程，每次执行大整数最大公约数、逆元和乘法运算；若忽略大整数位数带来的常数，约为 $O\!\left(\sum_{i=2}^{n}\log\min(M_i,a_i)\right)$。
- 空间复杂度：$O(\log L)$，其中 $L=\operatorname{lcm}(a_1,a_2,\ldots,a_n)$，用于保存合并过程中的大整数。
