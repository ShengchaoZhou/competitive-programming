# 快速幂

快速幂用于在对数时间内计算大指数幂的模值，也可以结合费马小定理求质数模意义下的乘法逆元。

## [AcWing 875. 快速幂](https://www.acwing.com/problem/content/877/)

### 题目描述

给定 $n$ 组整数 $a_i,b_i,p_i$，对每组数据计算 $a_i^{b_i}\bmod p_i$。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含三个整数 $a_i,b_i,p_i$。

**输出格式**

共输出 $n$ 行，第 $i$ 行输出 $a_i^{b_i}\bmod p_i$ 的值。

**数据范围**

- $1\le n\le 10^5$
- $1\le a_i,b_i,p_i\le 2\times 10^9$

**输入样例**

```text
2
3 2 5
4 3 9
```

**输出样例**

```text
4
1
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int queryCount = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        while (queryCount-- > 0) {
            long base = scanner.nextLong();
            long exponent = scanner.nextLong();
            long modulus = scanner.nextLong();
            answer.append(modPow(base, exponent, modulus)).append('\n');
        }

        System.out.print(answer);
    }

    private static long modPow(long base, long exponent, long modulus) {
        long result = 1 % modulus;
        base %= modulus;

        while (exponent > 0) {
            if ((exponent & 1) == 1) {
                result = result * base % modulus;
            }
            base = base * base % modulus;
            exponent >>= 1;
        }
        return result;
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            return (int) nextLong();
        }

        private long nextLong() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            long value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：每组数据为 $O(\log b_i)$。
- 空间复杂度：$O(1)$，不计输出缓冲区。

## [AcWing 876. 快速幂求逆元](https://www.acwing.com/problem/content/878/)

### 题目描述

给定 $n$ 组整数 $a_i,p_i$，其中 $p_i$ 保证为质数。求 $a_i$ 在模 $p_i$ 意义下位于 $0\sim p_i-1$ 的乘法逆元；若逆元不存在，则输出 `impossible`。乘法逆元 $x$ 满足 $a_i x\equiv1\pmod{p_i}$。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含两个整数 $a_i,p_i$。

**输出格式**

共输出 $n$ 行。若逆元存在，则输出该逆元；否则输出 `impossible`。

**数据范围**

- $1\le n\le 10^5$
- $1\le a_i,p_i\le 2\times 10^9$
- $p_i$ 是质数。

**输入样例**

```text
3
4 3
8 5
6 3
```

**输出样例**

```text
1
2
impossible
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int queryCount = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        while (queryCount-- > 0) {
            long value = scanner.nextLong();
            long primeModulus = scanner.nextLong();

            if (value % primeModulus == 0) {
                answer.append("impossible\n");
            } else {
                answer.append(modPow(value, primeModulus - 2, primeModulus)).append('\n');
            }
        }

        System.out.print(answer);
    }

    private static long modPow(long base, long exponent, long modulus) {
        long result = 1 % modulus;
        base %= modulus;

        while (exponent > 0) {
            if ((exponent & 1) == 1) {
                result = result * base % modulus;
            }
            base = base * base % modulus;
            exponent >>= 1;
        }
        return result;
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            return (int) nextLong();
        }

        private long nextLong() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            long value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：每组数据为 $O(\log p_i)$。
- 空间复杂度：$O(1)$，不计输出缓冲区。
