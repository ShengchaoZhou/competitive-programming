# 质数

质数相关算法用于判断一个整数是否为质数、分解质因数，以及统计一个区间内的质数数量。

## [AcWing 866. 试除法判定质数](https://www.acwing.com/problem/content/868/)

### 题目描述

给定 $n$ 个正整数 $a_i$，逐一判断每个数是否为质数。质数是大于 $1$ 且仅有 $1$ 和自身两个正约数的整数。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含一个正整数 $a_i$。

**输出格式**

共输出 $n$ 行。若第 $i$ 个数是质数，则第 $i$ 行输出 `Yes`，否则输出 `No`。

**数据范围**

- $1\le n\le 100$
- $1\le a_i\le 2\times 10^9$

**输入样例**

```text
2
2
6
```

**输出样例**

```text
Yes
No
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int queryCount = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        while (queryCount-- > 0) {
            int value = scanner.nextInt();
            answer.append(isPrime(value) ? "Yes" : "No").append('\n');
        }

        System.out.print(answer);
    }

    private static boolean isPrime(int value) {
        if (value < 2) {
            return false;
        }
        for (int divisor = 2; divisor <= value / divisor; divisor++) {
            if (value % divisor == 0) {
                return false;
            }
        }
        return true;
    }
}
```

### 时空复杂度

- 时间复杂度：判断 $a_i$ 需要 $O(\sqrt{a_i})$，全部数据共为 $O\!\left(\sum_{i=1}^{n}\sqrt{a_i}\right)$。
- 空间复杂度：$O(1)$，不计输出缓冲区。

## [AcWing 867. 分解质因数](https://www.acwing.com/problem/content/869/)

### 题目描述

给定 $n$ 个正整数 $a_i$，将每个数分解成若干质因数的乘积，并按照质因数从小到大的顺序输出每个质因数及其指数。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含一个正整数 $a_i$。

**输出格式**

对于每个 $a_i$，按照质因数递增顺序输出若干行，每行包含质因数和它的指数；一个数的分解结果输出完毕后，再输出一个空行。

**数据范围**

- $1\le n\le 100$
- $2\le a_i\le 2\times 10^9$

**输入样例**

```text
2
6
8
```

**输出样例**

```text
2 1
3 1

2 3
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int queryCount = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        while (queryCount-- > 0) {
            int value = scanner.nextInt();
            for (int factor = 2; factor <= value / factor; factor++) {
                if (value % factor != 0) {
                    continue;
                }

                int exponent = 0;
                while (value % factor == 0) {
                    value /= factor;
                    exponent++;
                }
                answer.append(factor).append(' ').append(exponent).append('\n');
            }
            if (value > 1) {
                answer.append(value).append(" 1\n");
            }
            answer.append('\n');
        }

        System.out.print(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：分解 $a_i$ 最坏需要 $O(\sqrt{a_i})$，全部数据共为 $O\!\left(\sum_{i=1}^{n}\sqrt{a_i}\right)$。
- 空间复杂度：$O(1)$，不计输出缓冲区。

## [AcWing 868. 筛质数](https://www.acwing.com/problem/content/870/)

### 题目描述

给定一个正整数 $n$，求 $1\sim n$ 中质数的个数。

**输入格式**

输入一行，包含整数 $n$。

**输出格式**

输出一个整数，表示 $1\sim n$ 中质数的数量。

**数据范围**

- $1\le n\le 10^6$

**输入样例**

```text
8
```

**输出样例**

```text
4
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int[] primes = new int[n + 1];
        boolean[] composite = new boolean[n + 1];
        int primeCount = 0;

        for (int value = 2; value <= n; value++) {
            if (!composite[value]) {
                primes[primeCount++] = value;
            }
            for (int i = 0; i < primeCount && primes[i] <= n / value; i++) {
                int prime = primes[i];
                composite[value * prime] = true;
                if (value % prime == 0) {
                    break;
                }
            }
        }

        System.out.println(primeCount);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n)$，线性筛保证每个合数只会被它的最小质因数筛掉一次。
- 空间复杂度：$O(n)$，用于保存质数表和合数标记。
