# 求组合数

求组合数算法用于根据参数规模和是否取模，快速计算从 $a$ 个不同元素中选取 $b$ 个元素的方案数 $C_a^b$。

## [AcWing 885. 求组合数 I](https://www.acwing.com/problem/content/887/)

### 题目描述

给定 $n$ 组询问，每组给出整数 $a$ 和 $b$，请计算 $C_a^b$ 对 $10^9+7$ 取模后的结果。

**输入格式**

- 第一行包含整数 $n$，表示询问数量。
- 接下来 $n$ 行，每行包含两个整数 $a$ 和 $b$。

**输出格式**

每组询问输出一行，表示 $C_a^b\bmod (10^9+7)$ 的值。

**数据范围**

- $1\le n\le 10000$
- $1\le b\le a\le 2000$

**输入样例**

```text
3
3 1
5 3
2 2
```

**输出样例**

```text
3
10
1
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static final int MOD = 1_000_000_007;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int queryCount = scanner.nextInt();
        int[] a = new int[queryCount];
        int[] b = new int[queryCount];
        int maximumA = 0;

        for (int i = 0; i < queryCount; i++) {
            a[i] = scanner.nextInt();
            b[i] = scanner.nextInt();
            maximumA = Math.max(maximumA, a[i]);
        }

        int[][] combination = new int[maximumA + 1][];
        for (int i = 0; i <= maximumA; i++) {
            combination[i] = new int[i + 1];
            combination[i][0] = combination[i][i] = 1;
            for (int j = 1; j < i; j++) {
                combination[i][j] = (int) (
                        (combination[i - 1][j - 1] + (long) combination[i - 1][j]) % MOD);
            }
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < queryCount; i++) {
            answer.append(combination[a[i]][b[i]]).append('\n');
        }
        System.out.print(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：记所有询问中最大的 $a$ 为 $A$，预处理为 $O(A^2)$，回答询问为 $O(n)$。
- 空间复杂度：$O(A^2+n)$。

## [AcWing 886. 求组合数 II](https://www.acwing.com/problem/content/888/)

### 题目描述

给定 $n$ 组询问，每组给出整数 $a$ 和 $b$，请计算 $C_a^b$ 对 $10^9+7$ 取模后的结果。

**输入格式**

- 第一行包含整数 $n$，表示询问数量。
- 接下来 $n$ 行，每行包含两个整数 $a$ 和 $b$。

**输出格式**

每组询问输出一行，表示 $C_a^b\bmod (10^9+7)$ 的值。

**数据范围**

- $1\le n\le 10000$
- $1\le b\le a\le 10^5$

**输入样例**

```text
3
3 1
5 3
2 2
```

**输出样例**

```text
3
10
1
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static final long MOD = 1_000_000_007L;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int queryCount = scanner.nextInt();
        int[] a = new int[queryCount];
        int[] b = new int[queryCount];
        int maximumA = 0;

        for (int i = 0; i < queryCount; i++) {
            a[i] = scanner.nextInt();
            b[i] = scanner.nextInt();
            maximumA = Math.max(maximumA, a[i]);
        }

        long[] factorial = new long[maximumA + 1];
        long[] inverseFactorial = new long[maximumA + 1];
        factorial[0] = 1;
        for (int i = 1; i <= maximumA; i++) {
            factorial[i] = factorial[i - 1] * i % MOD;
        }

        inverseFactorial[maximumA] = power(factorial[maximumA], MOD - 2);
        for (int i = maximumA; i >= 1; i--) {
            inverseFactorial[i - 1] = inverseFactorial[i] * i % MOD;
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < queryCount; i++) {
            long result = factorial[a[i]] * inverseFactorial[b[i]] % MOD;
            result = result * inverseFactorial[a[i] - b[i]] % MOD;
            answer.append(result).append('\n');
        }
        System.out.print(answer);
    }

    private static long power(long base, long exponent) {
        long result = 1;
        while (exponent > 0) {
            if ((exponent & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exponent >>= 1;
        }
        return result;
    }
}
```

### 时空复杂度

- 时间复杂度：记所有询问中最大的 $a$ 为 $A$，预处理为 $O(A+\log MOD)$，回答全部询问为 $O(n)$。
- 空间复杂度：$O(A+n)$。

## [AcWing 887. 求组合数 III](https://www.acwing.com/problem/content/889/)

### 题目描述

给定 $n$ 组询问，每组给出整数 $a$、$b$ 和质数 $p$，请计算 $C_a^b$ 对 $p$ 取模后的结果。

**输入格式**

- 第一行包含整数 $n$，表示询问数量。
- 接下来 $n$ 行，每行包含三个整数 $a$、$b$ 和 $p$。

**输出格式**

每组询问输出一行，表示 $C_a^b\bmod p$ 的值。

**数据范围**

- $1\le n\le 20$
- $1\le b\le a\le 10^{18}$
- $1\le p\le 10^5$，且 $p$ 为质数。

**输入样例**

```text
3
5 3 7
3 1 5
6 4 13
```

**输出样例**

```text
3
3
2
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int queryCount = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        for (int i = 0; i < queryCount; i++) {
            long a = scanner.nextLong();
            long b = scanner.nextLong();
            long prime = scanner.nextLong();
            answer.append(lucas(a, b, prime)).append('\n');
        }
        System.out.print(answer);
    }

    private static long lucas(long a, long b, long prime) {
        if (b == 0) return 1;
        long lowDigit = combination(a % prime, b % prime, prime);
        return lowDigit * lucas(a / prime, b / prime, prime) % prime;
    }

    private static long combination(long a, long b, long prime) {
        if (b > a) return 0;
        b = Math.min(b, a - b);

        long numerator = 1;
        long denominator = 1;
        for (long i = 1; i <= b; i++) {
            numerator = numerator * (a - i + 1) % prime;
            denominator = denominator * i % prime;
        }
        return numerator * power(denominator, prime - 2, prime) % prime;
    }

    private static long power(long base, long exponent, long modulus) {
        long result = 1;
        while (exponent > 0) {
            if ((exponent & 1) == 1) result = result * base % modulus;
            base = base * base % modulus;
            exponent >>= 1;
        }
        return result;
    }
}
```

### 时空复杂度

- 时间复杂度：每组询问按 $p$ 进制递归，最坏为 $O(p\log_p a)$。
- 空间复杂度：递归栈为 $O(\log_p a)$。

## [AcWing 888. 求组合数 IV](https://www.acwing.com/problem/content/890/)

### 题目描述

输入整数 $a$ 和 $b$，求组合数 $C_a^b$ 的精确值。结果可能非常大，不能对其取模。

**输入格式**

一行包含两个整数 $a$ 和 $b$。

**输出格式**

输出一行，表示 $C_a^b$ 的精确值。

**数据范围**

- $1\le b\le a\le 5000$

**输入样例**

```text
5 3
```

**输出样例**

```text
10
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int a = scanner.nextInt();
        int b = scanner.nextInt();
        int[] primes = getPrimes(a);

        List<Integer> digits = new ArrayList<>();
        digits.add(1);

        for (int prime : primes) {
            int exponent = exponentInFactorial(a, prime)
                    - exponentInFactorial(b, prime)
                    - exponentInFactorial(a - b, prime);
            for (int i = 0; i < exponent; i++) {
                multiply(digits, prime);
            }
        }

        StringBuilder answer = new StringBuilder(digits.size());
        for (int i = digits.size() - 1; i >= 0; i--) {
            answer.append(digits.get(i));
        }
        System.out.println(answer);
    }

    private static int[] getPrimes(int limit) {
        int[] primes = new int[limit + 1];
        boolean[] composite = new boolean[limit + 1];
        int count = 0;

        for (int number = 2; number <= limit; number++) {
            if (!composite[number]) primes[count++] = number;
            for (int i = 0; i < count; i++) {
                int prime = primes[i];
                long product = (long) prime * number;
                if (product > limit) break;
                composite[(int) product] = true;
                if (number % prime == 0) break;
            }
        }

        int[] result = new int[count];
        System.arraycopy(primes, 0, result, 0, count);
        return result;
    }

    private static int exponentInFactorial(int number, int prime) {
        int exponent = 0;
        while (number > 0) {
            number /= prime;
            exponent += number;
        }
        return exponent;
    }

    private static void multiply(List<Integer> digits, int factor) {
        int carry = 0;
        for (int i = 0; i < digits.size(); i++) {
            int value = digits.get(i) * factor + carry;
            digits.set(i, value % 10);
            carry = value / 10;
        }
        while (carry > 0) {
            digits.add(carry % 10);
            carry /= 10;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：设答案的十进制位数为 $D$，筛质数为 $O(a)$，高精度连乘最坏为 $O(aD)$。
- 空间复杂度：$O(a+D)$。

## [AcWing 889. 满足条件的01序列](https://www.acwing.com/problem/content/891/)

### 题目描述

给定 $n$ 个 `0` 和 $n$ 个 `1`，将它们排列成一个长度为 $2n$ 的序列。求所有排列中，满足任意前缀内 `0` 的数量都不少于 `1` 的数量的序列个数，答案对 $10^9+7$ 取模。

**输入格式**

一行包含整数 $n$。

**输出格式**

输出一个整数，表示满足条件的序列数量。

**数据范围**

- $1\le n\le 10^5$

**输入样例**

```text
3
```

**输出样例**

```text
5
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static final long MOD = 1_000_000_007L;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int limit = n * 2;

        long[] factorial = new long[limit + 1];
        long[] inverseFactorial = new long[limit + 1];
        factorial[0] = 1;
        for (int i = 1; i <= limit; i++) {
            factorial[i] = factorial[i - 1] * i % MOD;
        }

        inverseFactorial[limit] = power(factorial[limit], MOD - 2);
        for (int i = limit; i >= 1; i--) {
            inverseFactorial[i - 1] = inverseFactorial[i] * i % MOD;
        }

        long centralCombination = factorial[limit] * inverseFactorial[n] % MOD;
        centralCombination = centralCombination * inverseFactorial[n] % MOD;
        long answer = centralCombination * power(n + 1L, MOD - 2) % MOD;
        System.out.println(answer);
    }

    private static long power(long base, long exponent) {
        long result = 1;
        while (exponent > 0) {
            if ((exponent & 1) == 1) result = result * base % MOD;
            base = base * base % MOD;
            exponent >>= 1;
        }
        return result;
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n+\log MOD)$。
- 空间复杂度：$O(n)$。
