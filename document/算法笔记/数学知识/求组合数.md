# 求组合数

组合数 $C_a^b$ 表示从 `a` 个不同元素中选出 `b` 个元素的方案数。选择算法时，先看参数规模、是否要求精确值，以及模数是否为质数。

## 递推与预处理

组合数满足 $C_a^b=C_{a-1}^{b-1}+C_{a-1}^b$，边界为 $C_a^0=C_a^a=1$。另一种表达式是 $C_a^b=a!/(b!(a-b)!)$；模意义下必须用合法逆元代替除法。

### 小范围多次询问

按行预处理杨辉三角，时间和空间复杂度均为 $O(A^2)$，其中 `A` 是最大上参数，随后每次查询为 $O(1)$。此方法只用加法，对任意正整数模数均适用；若只求某一行，可将空间压缩为 $O(A)$，每行倒序更新。

- [AcWing 885. 求组合数 I](https://www.acwing.com/problem/content/887/) （AcWing基础课）：上参数不超过 `2000`，二维递推预处理即可支持大量询问。

### 阶乘与逆阶乘

当模数 `p` 为质数且 `A < p` 时，预处理 `fact[i] = i! mod p`，通过一次快速幂求 `invFact[A]`，再逆序递推出其余逆阶乘。查询使用 `fact[a] * invFact[b] * invFact[a-b]`，逐次取模。

预处理时间复杂度为 $O(A+\log p)$，空间复杂度为 $O(A)$，查询为 $O(1)$。若 `A >= p`，阶乘可能为 `0` 而没有逆元，不能直接套用该公式。

- [AcWing 886. 求组合数 II](https://www.acwing.com/problem/content/888/) （AcWing基础课）：参数达到 `10^5`，使用阶乘与逆阶乘预处理，避免二次方规模的表格。

## Lucas 定理

模数 `p` 为质数时，将 `a、b` 按 `p` 进制逐位拆分：

$$C_a^b\equiv C_{a\bmod p}^{b\bmod p}\,C_{\lfloor a/p\rfloor}^{\lfloor b/p\rfloor}\pmod p$$

任意一位的下参数大于上参数时，该位组合数为 `0`，整个结果也为 `0`。大参数只以除法逐渐缩小，无需开设与 `a` 大小相同的数组。

### 大参数与小质数模数

每一位都变成小于 `p` 的组合数。可用逐项乘法与逆元计算，最坏时间约为 $O(p\log_p a)$；同一模数下多次查询时，可预处理 `0..p-1` 的阶乘与逆阶乘，将预处理后的单次查询降至 $O(\log_p a)$。

- [AcWing 887. 求组合数 III](https://www.acwing.com/problem/content/889/) （AcWing基础课）：`a、b` 可达 `10^18`，而质数模数较小，适合按 `p` 进制拆解。

## 质因数分解与高精度

要求精确值时，不能取模，也不宜先计算三个巨大的阶乘再相除。用勒让德公式统计质数 `p` 在阶乘中的指数：

$$v_p(n!)=\sum_{k\ge1}\left\lfloor\frac{n}{p^k}\right\rfloor$$

于是 `p` 在组合数中的指数为 $v_p(a!)-v_p(b!)-v_p((a-b)!)$。可反复令 `n /= p` 并累加，避免显式构造溢出的 `p^k`。

### 输出精确组合数

筛出不超过 `a` 的质数，求各质数指数，再用高精度数连乘这些质因子。设结果十进制位数为 `D`，逐因子乘法实现的保守时间上界为 $O(aD+a)$，空间复杂度为 $O(a+D)$。

- [AcWing 888. 求组合数 IV](https://www.acwing.com/problem/content/890/) （AcWing基础课）：输出完整组合数，使用高精度乘法或 `BigInteger` 保存精确整数。

## 卡特兰数

长度为 `2n` 的序列中，两类元素各有 `n` 个，且任意前缀第一类数量不少于第二类时，方案数是卡特兰数：

$$\operatorname{Cat}_n=C_{2n}^{n}-C_{2n}^{n-1}=\frac1{n+1}C_{2n}^{n}$$

它也描述合法括号序列等前缀平衡结构。式中的普通除法在取模后必须改为逆元，前提是 `n + 1` 与模数互质。

### 前缀平衡序列计数

把 `0` 看成向上一步、`1` 看成向下一步，就得到不能跌到基准线以下的路径。使用阶乘和逆阶乘计算时，需保证质数模数大于 `2n`；题目范围内预处理时间为 $O(n+\log p)$，空间为 $O(n)$。

- [AcWing 889. 满足条件的01序列](https://www.acwing.com/problem/content/891/) （AcWing基础课）：任意前缀的 `0` 不少于 `1`，直接对应第 `n` 个卡特兰数。
