# 博弈论

博弈论用于通过 Nim 异或和与 SG 函数判断公平组合游戏在双方都采取最优策略时的先手胜负。

## [AcWing 891. Nim游戏](https://www.acwing.com/problem/content/893/)

### 题目描述

给定 $n$ 堆石子，两位玩家轮流操作。每次可以任选一堆，从中拿走任意正整数个石子，也可以将这一堆全部拿完。无法继续操作的人失败。请判断双方都采用最优策略时，先手是否必胜。

**输入格式**

- 第一行包含整数 $n$，表示石子堆数。
- 第二行包含 $n$ 个整数，其中第 $i$ 个整数表示第 $i$ 堆的石子数量。

**输出格式**

如果先手必胜，输出 `Yes`；否则输出 `No`。

**数据范围**

- $1 \le n \le 10^5$
- $1 \le$ 每堆石子数 $\le 10^9$

**输入样例**

```text
2
2 3
```

**输出样例**

```text
Yes
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int pileCount = scanner.nextInt();
        int nimSum = 0;

        for (int i = 0; i < pileCount; i++) {
            nimSum ^= scanner.nextInt();
        }

        System.out.println(nimSum != 0 ? "Yes" : "No");
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n)$，只需遍历所有石子堆并计算异或和。
- 空间复杂度：$O(1)$，只使用常数个额外变量。

## [AcWing 892. 台阶-Nim游戏](https://www.acwing.com/problem/content/894/)

### 题目描述

一座楼梯共有 $n$ 级台阶，第 $i$ 级台阶上放有 $a_i$ 个石子。两位玩家轮流操作，每次从任意一级台阶取出任意正整数个石子，并将它们放到下一级；从第一级移到地面的石子不能再移动。无法继续操作的人失败。请判断双方都采用最优策略时，先手是否必胜。

**输入格式**

- 第一行包含整数 $n$，表示台阶级数。
- 第二行包含 $n$ 个整数，其中第 $i$ 个整数表示第 $i$ 级台阶上的石子数量 $a_i$。

**输出格式**

如果先手必胜，输出 `Yes`；否则输出 `No`。

**数据范围**

- $1 \le n \le 10^5$
- $1 \le a_i \le 10^9$

**输入样例**

```text
3
2 1 3
```

**输出样例**

```text
Yes
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int stepCount = scanner.nextInt();
        int nimSum = 0;

        for (int step = 1; step <= stepCount; step++) {
            int stoneCount = scanner.nextInt();
            if ((step & 1) == 1) {
                nimSum ^= stoneCount;
            }
        }

        System.out.println(nimSum != 0 ? "Yes" : "No");
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n)$，遍历所有台阶并异或奇数级台阶上的石子数。
- 空间复杂度：$O(1)$，只使用常数个额外变量。

## [AcWing 893. 集合-Nim游戏](https://www.acwing.com/problem/content/895/)

### 题目描述

给定 $n$ 堆石子和一个由 $k$ 个不同正整数构成的集合 $S$。两位玩家轮流操作，每次任选一堆，并从中拿走恰好 $s$ 个石子，其中 $s \in S$ 且该堆至少有 $s$ 个石子。无法继续操作的人失败。请判断双方都采用最优策略时，先手是否必胜。

**输入格式**

- 第一行包含整数 $k$，表示集合 $S$ 的元素个数。
- 第二行包含 $k$ 个不同的正整数 $s_i$，表示每次允许拿走的石子数量。
- 第三行包含整数 $n$，表示石子堆数。
- 第四行包含 $n$ 个整数，其中第 $i$ 个整数表示第 $i$ 堆的石子数量 $h_i$。

**输出格式**

如果先手必胜，输出 `Yes`；否则输出 `No`。

**数据范围**

- $1 \le n,k \le 100$
- $1 \le s_i,h_i \le 10000$

**输入样例**

```text
2
2 5
3
2 4 7
```

**输出样例**

```text
Yes
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int moveCount = scanner.nextInt();
        int[] moves = new int[moveCount];
        for (int i = 0; i < moveCount; i++) {
            moves[i] = scanner.nextInt();
        }

        int pileCount = scanner.nextInt();
        int[] piles = new int[pileCount];
        int maximumPile = 0;
        for (int i = 0; i < pileCount; i++) {
            piles[i] = scanner.nextInt();
            maximumPile = Math.max(maximumPile, piles[i]);
        }

        int[] sg = new int[maximumPile + 1];
        for (int stones = 1; stones <= maximumPile; stones++) {
            boolean[] reachable = new boolean[moveCount + 1];
            for (int move : moves) {
                if (move <= stones) {
                    reachable[sg[stones - move]] = true;
                }
            }

            int mex = 0;
            while (mex < reachable.length && reachable[mex]) {
                mex++;
            }
            sg[stones] = mex;
        }

        int nimSum = 0;
        for (int pile : piles) {
            nimSum ^= sg[pile];
        }
        System.out.println(nimSum != 0 ? "Yes" : "No");
    }
}
```

### 时空复杂度

- 时间复杂度：$O(Hk+n)$，其中 $H=\max(h_i)$；计算每个石子数的 SG 值时最多检查 $k$ 种操作。
- 空间复杂度：$O(H+n+k)$，用于保存 SG 值、各堆石子数、操作集合和当前状态的可达标记。

## [AcWing 894. 拆分-Nim游戏](https://www.acwing.com/problem/content/896/)

### 题目描述

给定 $n$ 堆石子，两位玩家轮流操作。每次任选一堆大小为 $x$ 的石子，将其移除并换成两堆大小都严格小于 $x$ 的石子；新堆大小可以为 $0$，两堆石子数之和也可以大于 $x$。无法继续操作的人失败。请判断双方都采用最优策略时，先手是否必胜。

**输入格式**

- 第一行包含整数 $n$，表示石子堆数。
- 第二行包含 $n$ 个整数，其中第 $i$ 个整数表示第 $i$ 堆的石子数量 $a_i$。

**输出格式**

如果先手必胜，输出 `Yes`；否则输出 `No`。

**数据范围**

- $1 \le n,a_i \le 100$

**输入样例**

```text
2
2 3
```

**输出样例**

```text
Yes
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int pileCount = scanner.nextInt();
        int[] piles = new int[pileCount];
        int maximumPile = 0;

        for (int i = 0; i < pileCount; i++) {
            piles[i] = scanner.nextInt();
            maximumPile = Math.max(maximumPile, piles[i]);
        }

        int[] sg = new int[maximumPile + 1];
        for (int stones = 1; stones <= maximumPile; stones++) {
            Set<Integer> reachable = new HashSet<>();
            for (int firstPile = 0; firstPile < stones; firstPile++) {
                for (int secondPile = 0; secondPile <= firstPile; secondPile++) {
                    reachable.add(sg[firstPile] ^ sg[secondPile]);
                }
            }

            int mex = 0;
            while (reachable.contains(mex)) {
                mex++;
            }
            sg[stones] = mex;
        }

        int nimSum = 0;
        for (int pile : piles) {
            nimSum ^= sg[pile];
        }
        System.out.println(nimSum != 0 ? "Yes" : "No");
    }
}
```

### 时空复杂度

- 时间复杂度：$O(H^3+n)$，其中 $H=\max(a_i)$；计算大小为 $x$ 的石子堆的 SG 值需要枚举 $O(x^2)$ 种拆分方式。
- 空间复杂度：$O(H^2+n)$，用于 SG 数组、输入石子堆以及单个状态的可达 SG 值集合。
