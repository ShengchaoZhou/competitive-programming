# 博弈论

本页讨论双方可执行相同操作、无随机因素与隐藏信息、必然终止，并以无法操作者失败为规则的公平组合游戏。通过必胜必败状态、Nim 异或和与 SG 函数判断最优对弈的胜负。

## Nim 异或和

必败状态的所有合法后继均为必胜状态；必胜状态至少有一个必败后继。标准 Nim 游戏每次任选一堆取走任意正数个石子，其状态为必败当且仅当所有堆大小的异或和为 `0`。

### 任意取石子

异或和为 `0` 时，任意改变一堆都会使异或和非零；异或和非零时，可选择含最高非零位的一堆，减小它使总异或和归零。遍历所有堆即可判断胜负，时间复杂度为 $O(n)$，额外空间为 $O(1)$。

- [AcWing 891. Nim游戏](https://www.acwing.com/problem/content/893/) （AcWing基础课）：直接异或所有堆大小，非零则先手必胜。若游戏改成取最后一颗者输，需要重新分析，不能直接套用此结论。

### 相邻台阶转移

台阶从 `1` 开始编号，只计算奇数级台阶的石子异或和。奇数级向偶数级移动对应改变有效 Nim 堆；偶数级向奇数级移动后，对手可把同样数量继续移到下一级，恢复奇数级的局面。由此仍以奇数级异或和是否为 `0` 判断胜负。

- [AcWing 892. 台阶-Nim游戏](https://www.acwing.com/problem/content/894/) （AcWing基础课）：只异或第 `1、3、5…` 级的石子数，地面为第 `0` 级，移到地面的石子不再参与。时间为 $O(n)$，额外空间为 $O(1)$。

## SG 函数

令 $SG(x)=\operatorname{mex}\{SG(y):x\to y\}$，其中 `mex` 是集合中未出现的最小非负整数，无法操作的终止状态为 `0`。多个相互独立、每次只操作其中一个的子游戏，其整体 SG 值是各子游戏 SG 值的异或和；异或和为 `0` 时先手必败。

### 限定可取数量

允许取走的数量来自集合 `S` 时，$SG(x)=\operatorname{mex}\{SG(x-s):s\in S,\ s\le x\}$。按石子数递增计算或记忆化搜索，避免重复求解。同一状态最多有 `k` 个后继，因此其 SG 值不超过 `k`，可以用大小为 `k + 1` 的布尔数组求 `mex`。

- [AcWing 893. 集合-Nim游戏](https://www.acwing.com/problem/content/895/) （AcWing基础课）：预处理到最大堆高 `H`，再异或各堆的 SG 值。时间复杂度为 $O(Hk+n)$，空间为 $O(H+k+n)$，其中包括输入石子堆的存储。

### 一堆拆成两个子游戏

将大小为 `x` 的一堆替换为两堆更小的石子时，后继值为 `SG(i) ^ SG(j)`，而不是把两个值相加。枚举 `0 <= j <= i < x` 的所有合法拆分，再对这些异或值取 `mex`。

- [AcWing 894. 拆分-Nim游戏](https://www.acwing.com/problem/content/896/) （AcWing基础课）：新堆可为 `0`，且两堆之和不要求等于原堆大小；必须按照实际规则枚举。预处理到 `H` 的时间为 $O(H^3)$，单个状态的可达集合最多占 $O(H^2)$ 空间，再用 $O(n)$ 时间合并各堆结果。
