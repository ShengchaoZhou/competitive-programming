# 高斯消元

高斯消元用于通过初等行变换判断线性方程组是否有解，并在存在唯一解时求出所有未知数。

## [AcWing 883. 高斯消元解线性方程组](https://www.acwing.com/problem/content/885/)

### 题目描述

输入一个包含 $n$ 个方程、$n$ 个未知数的线性方程组，方程中的系数和常数均为实数。请判断方程组的解的情况；若存在唯一解，还需要求出每个未知数的值。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含 $n+1$ 个实数，依次表示一个方程中 $n$ 个未知数的系数以及等号右侧的常数。

**输出格式**

- 如果方程组存在唯一解，输出 $n$ 行，第 $i$ 行输出第 $i$ 个未知数的值，结果保留两位小数。
- 如果方程组存在无穷多组解，输出 `Infinite group solutions`。
- 如果方程组无解，输出 `No solution`。

**数据范围**

- $1\le n\le 100$
- 所有输入系数和常数均保留两位小数，绝对值不超过 $100$。

**输入样例**

```text
3
1.00 2.00 -1.00 -6.00
2.00 1.00 -3.00 -9.00
-1.00 -1.00 2.00 7.00
```

**输出样例**

```text
1.00
-2.00
3.00
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static final double EPSILON = 1e-8;
    private static double[][] matrix;
    private static int n;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        scanner.useLocale(Locale.US);
        n = scanner.nextInt();
        matrix = new double[n][n + 1];

        for (int row = 0; row < n; row++) {
            for (int column = 0; column <= n; column++) {
                matrix[row][column] = scanner.nextDouble();
            }
        }

        int result = eliminate();
        if (result == 1) {
            System.out.println("Infinite group solutions");
        } else if (result == 2) {
            System.out.println("No solution");
        } else {
            for (int i = 0; i < n; i++) {
                double value = matrix[i][n];
                if (Math.abs(value) < 0.0005) value = 0;
                System.out.printf(Locale.US, "%.2f%n", value);
            }
        }
    }

    private static int eliminate() {
        int pivotRow = 0;

        for (int column = 0; column < n; column++) {
            int selected = pivotRow;
            for (int row = pivotRow; row < n; row++) {
                if (Math.abs(matrix[row][column])
                        > Math.abs(matrix[selected][column])) {
                    selected = row;
                }
            }

            if (Math.abs(matrix[selected][column]) < EPSILON) {
                continue;
            }

            double[] temporary = matrix[selected];
            matrix[selected] = matrix[pivotRow];
            matrix[pivotRow] = temporary;

            for (int j = n; j >= column; j--) {
                matrix[pivotRow][j] /= matrix[pivotRow][column];
            }

            for (int row = pivotRow + 1; row < n; row++) {
                if (Math.abs(matrix[row][column]) < EPSILON) continue;
                for (int j = n; j >= column; j--) {
                    matrix[row][j] -= matrix[pivotRow][j] * matrix[row][column];
                }
            }
            pivotRow++;
        }

        if (pivotRow < n) {
            for (int row = pivotRow; row < n; row++) {
                if (Math.abs(matrix[row][n]) > EPSILON) {
                    return 2;
                }
            }
            return 1;
        }

        for (int row = n - 1; row >= 0; row--) {
            for (int column = row + 1; column < n; column++) {
                matrix[row][n] -= matrix[row][column] * matrix[column][n];
            }
        }
        return 0;
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n^3)$。
- 空间复杂度：$O(n^2)$。

## [AcWing 884. 高斯消元解异或线性方程组](https://www.acwing.com/problem/content/886/)

### 题目描述

输入一个包含 $n$ 个方程、$n$ 个未知数的异或线性方程组。所有系数、常数和未知数的取值均为 $0$ 或 $1$，方程中的加法使用按位异或。请判断方程组的解的情况；若存在唯一解，还需要求出每个未知数的值。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含 $n+1$ 个整数 $0$ 或 $1$，依次表示一个方程中 $n$ 个未知数的系数以及等号右侧的常数。

**输出格式**

- 如果方程组存在唯一解，输出 $n$ 行，第 $i$ 行输出第 $i$ 个未知数的值。
- 如果方程组存在多组解，输出 `Multiple sets of solutions`。
- 如果方程组无解，输出 `No solution`。

**数据范围**

- $1\le n\le 100$

**输入样例**

```text
3
1 1 0 1
0 1 1 0
1 0 0 1
```

**输出样例**

```text
1
0
0
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static int[][] matrix;
    private static int n;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        n = scanner.nextInt();
        matrix = new int[n][n + 1];

        for (int row = 0; row < n; row++) {
            for (int column = 0; column <= n; column++) {
                matrix[row][column] = scanner.nextInt();
            }
        }

        int result = eliminate();
        if (result == 1) {
            System.out.println("Multiple sets of solutions");
        } else if (result == 2) {
            System.out.println("No solution");
        } else {
            StringBuilder answer = new StringBuilder();
            for (int i = 0; i < n; i++) {
                answer.append(matrix[i][n]).append('\n');
            }
            System.out.print(answer);
        }
    }

    private static int eliminate() {
        int pivotRow = 0;

        for (int column = 0; column < n; column++) {
            int selected = -1;
            for (int row = pivotRow; row < n; row++) {
                if (matrix[row][column] == 1) {
                    selected = row;
                    break;
                }
            }

            if (selected == -1) continue;

            int[] temporary = matrix[selected];
            matrix[selected] = matrix[pivotRow];
            matrix[pivotRow] = temporary;

            for (int row = pivotRow + 1; row < n; row++) {
                if (matrix[row][column] == 0) continue;
                for (int j = column; j <= n; j++) {
                    matrix[row][j] ^= matrix[pivotRow][j];
                }
            }
            pivotRow++;
        }

        if (pivotRow < n) {
            for (int row = pivotRow; row < n; row++) {
                if (matrix[row][n] == 1) return 2;
            }
            return 1;
        }

        for (int row = n - 1; row >= 0; row--) {
            for (int column = row + 1; column < n; column++) {
                matrix[row][n] ^= matrix[row][column] & matrix[column][n];
            }
        }
        return 0;
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n^3)$。
- 空间复杂度：$O(n^2)$。
