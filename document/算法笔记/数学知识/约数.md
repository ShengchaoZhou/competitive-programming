# 约数

约数相关算法用于枚举一个数的所有约数、统计若干数乘积的约数个数或约数之和，以及计算两个数的最大公约数。

## [AcWing 869. 试除法求约数](https://www.acwing.com/problem/content/871/)

### 题目描述

给定 $n$ 个正整数 $a_i$，对于每个整数，按照从小到大的顺序输出它的所有正约数。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含一个整数 $a_i$。

**输出格式**

共输出 $n$ 行，第 $i$ 行按递增顺序输出 $a_i$ 的所有正约数，约数之间用空格分隔。

**数据范围**

- $1\le n\le 100$
- $2\le a_i\le 2\times 10^9$

**输入样例**

```text
2
6
8
```

**输出样例**

```text
1 2 3 6
1 2 4 8
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int queryCount = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        while (queryCount-- > 0) {
            int value = scanner.nextInt();
            List<Integer> divisors = new ArrayList<>();

            for (int divisor = 1; divisor <= value / divisor; divisor++) {
                if (value % divisor != 0) {
                    continue;
                }
                divisors.add(divisor);
                if (divisor != value / divisor) {
                    divisors.add(value / divisor);
                }
            }

            Collections.sort(divisors);
            for (int divisor : divisors) {
                answer.append(divisor).append(' ');
            }
            answer.append('\n');
        }

        System.out.print(answer);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：对每个 $a_i$，枚举因数需要 $O(\sqrt{a_i})$，设其约数个数为 $d_i$，排序需要 $O(d_i\log d_i)$。
- 空间复杂度：$O(d_i)$，用于保存当前整数的全部约数。

## [AcWing 870. 约数个数](https://www.acwing.com/problem/content/872/)

### 题目描述

给定 $n$ 个正整数 $a_i$，求这些数的乘积所拥有的正约数个数，答案对 $10^9+7$ 取模。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含一个整数 $a_i$。

**输出格式**

输出一个整数，表示所有 $a_i$ 的乘积的约数个数对 $10^9+7$ 取模后的结果。

**数据范围**

- $1\le n\le 100$
- $1\le a_i\le 2\times 10^9$

**输入样例**

```text
3
2
6
8
```

**输出样例**

```text
12
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;
import java.util.HashMap;
import java.util.Map;

public class Main {
    private static final long MOD = 1_000_000_007L;

    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int numberCount = scanner.nextInt();
        Map<Integer, Integer> totalExponents = new HashMap<>();

        while (numberCount-- > 0) {
            int value = scanner.nextInt();
            for (int factor = 2; factor <= value / factor; factor++) {
                while (value % factor == 0) {
                    totalExponents.merge(factor, 1, Integer::sum);
                    value /= factor;
                }
            }
            if (value > 1) {
                totalExponents.merge(value, 1, Integer::sum);
            }
        }

        long answer = 1;
        for (int exponent : totalExponents.values()) {
            answer = answer * (exponent + 1L) % MOD;
        }

        System.out.println(answer);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：质因数分解最坏为 $O\!\left(\sum_{i=1}^{n}\sqrt{a_i}\right)$，汇总质因数的答案还需 $O(P)$，其中 $P$ 是不同质因数的数量。
- 空间复杂度：$O(P)$，用于记录乘积中每个质因数的总指数。

## [AcWing 871. 约数之和](https://www.acwing.com/problem/content/873/)

### 题目描述

给定 $n$ 个正整数 $a_i$，求这些数的乘积的所有正约数之和，答案对 $10^9+7$ 取模。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含一个整数 $a_i$。

**输出格式**

输出一个整数，表示所有 $a_i$ 的乘积的约数之和对 $10^9+7$ 取模后的结果。

**数据范围**

- $1\le n\le 100$
- $1\le a_i\le 2\times 10^9$

**输入样例**

```text
3
2
6
8
```

**输出样例**

```text
252
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;
import java.util.HashMap;
import java.util.Map;

public class Main {
    private static final long MOD = 1_000_000_007L;

    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int numberCount = scanner.nextInt();
        Map<Integer, Integer> totalExponents = new HashMap<>();

        while (numberCount-- > 0) {
            int value = scanner.nextInt();
            for (int factor = 2; factor <= value / factor; factor++) {
                while (value % factor == 0) {
                    totalExponents.merge(factor, 1, Integer::sum);
                    value /= factor;
                }
            }
            if (value > 1) {
                totalExponents.merge(value, 1, Integer::sum);
            }
        }

        long answer = 1;
        for (Map.Entry<Integer, Integer> entry : totalExponents.entrySet()) {
            long prime = entry.getKey();
            int exponent = entry.getValue();
            long geometricSum = 1;
            long power = 1;

            for (int i = 0; i < exponent; i++) {
                power = power * prime % MOD;
                geometricSum = (geometricSum + power) % MOD;
            }
            answer = answer * geometricSum % MOD;
        }

        System.out.println(answer);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：质因数分解最坏为 $O\!\left(\sum_{i=1}^{n}\sqrt{a_i}\right)$；计算各质因数的等比和还需 $O(E)$，其中 $E$ 是所有质因数指数之和。
- 空间复杂度：$O(P)$，其中 $P$ 是不同质因数的数量。

## [AcWing 872. 最大公约数](https://www.acwing.com/problem/content/874/)

### 题目描述

给定 $n$ 对正整数 $a_i,b_i$，求每一对数的最大公约数。

**输入格式**

- 第一行包含整数 $n$。
- 接下来 $n$ 行，每行包含一对整数 $a_i,b_i$。

**输出格式**

共输出 $n$ 行，第 $i$ 行输出 $a_i$ 与 $b_i$ 的最大公约数。

**数据范围**

- $1\le n\le 10^5$
- $1\le a_i,b_i\le 2\times 10^9$

**输入样例**

```text
2
3 6
4 6
```

**输出样例**

```text
3
2
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int queryCount = scanner.nextInt();
        StringBuilder answer = new StringBuilder();

        while (queryCount-- > 0) {
            int a = scanner.nextInt();
            int b = scanner.nextInt();
            answer.append(gcd(a, b)).append('\n');
        }

        System.out.print(answer);
    }

    private static int gcd(int a, int b) {
        while (b != 0) {
            int remainder = a % b;
            a = b;
            b = remainder;
        }
        return a;
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：每组数据为 $O(\log\min(a_i,b_i))$。
- 空间复杂度：$O(1)$。
