# 约数

约数问题可从成对枚举、质因数指数或欧几里得算法入手。多个整数的乘积可能溢出时，直接汇总质因数指数，不需要先算出乘积。

## 试除法

正约数成对出现：若 `d` 整除 `x`，则 `x / d` 也是约数。只需枚举 `d <= x / d`；完全平方数的平方根只能加入一次。

### 枚举全部约数

将每对约数保存后排序即可得到递增序列。设约数个数为 `D`，时间复杂度为 $O(\sqrt{x}+D\log D)$，空间复杂度为 $O(D)$；也可以分别保存小约数和大约数，逆序拼接后省去排序。

- [AcWing 869. 试除法求约数](https://www.acwing.com/problem/content/871/) （AcWing基础课）：逐个整数输出全部正约数，同时处理成对约数去重与递增顺序。

## 质因数指数统计

设 $N=\prod p_i^{e_i}$，每个正约数对应为每个质因数独立选择一个 `0..e_i` 的指数。多个数相乘时，同一质因数的指数相加；逐个试除分解的总时间为 $O(\sum\sqrt{a_i})$，指数表使用 $O(P)$ 空间，其中 `P` 为不同质因数的数量。

### 约数个数

每个质因数有 `e_i + 1` 种指数选择，因此 $d(N)=\prod(e_i+1)$。按题目要求在连乘过程中取模；乘法应先提升到足够宽的整数类型。`N = 1` 时空乘积为 `1`。

- [AcWing 870. 约数个数](https://www.acwing.com/problem/content/872/) （AcWing基础课）：将所有输入数的质因数指数累加，再乘各个“指数加一”，无需构造原始大乘积。

### 约数之和

将每个质因数的贡献展开，得到 $\sigma(N)=\prod(1+p_i+\cdots+p_i^{e_i})$。每项等比和可从 `s = 1` 开始重复 `s = s * p + 1` 共 `e` 次计算；不要直接在模意义下除以 `p - 1`，其逆元可能不存在。除分解外，计算各项需要 $O(\sum e_i)$ 时间。

- [AcWing 871. 约数之和](https://www.acwing.com/problem/content/873/) （AcWing基础课）：先合并指数，再计算每个质因数的等比和并相乘，所有步骤按要求取模。

## 欧几里得算法

利用 $\gcd(a,b)=\gcd(b,a\bmod b)$，不断用余数替换较大的问题，直到第二个数为 `0`，此时第一个数就是最大公约数。对正整数，时间复杂度为 $O(\log\min(a,b))$，迭代实现使用 $O(1)$ 空间。

### 最大公约数

最大公约数用于约分、判断互质，也可计算 $\operatorname{lcm}(a,b)=a/\gcd(a,b)\times b$；先除后乘可降低溢出风险，但结果仍需足够宽的类型。

- [AcWing 872. 最大公约数](https://www.acwing.com/problem/content/874/) （AcWing基础课）：对每一对正整数独立执行辗转相除。
