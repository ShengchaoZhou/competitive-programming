# 欧拉函数

欧拉函数 $\varphi(n)$ 表示 `1..n` 中与 `n` 互质的整数个数，约定 $\varphi(1)=1$。单点计算依赖质因数分解，批量计算可与线性筛结合。

| 算法类型 | 题型 | 题目与题集标记 |
| --- | --- | --- |
| [质因数分解](#质因数分解) | 单个整数的互质计数 | [AcWing 873. 欧拉函数](https://www.acwing.com/problem/content/875/) （AcWing基础课） |
| [线性筛](#线性筛) | 批量计算并求和 | [AcWing 874. 筛法求欧拉函数](https://www.acwing.com/problem/content/876/) （AcWing基础课） |

## 质因数分解

若 `n` 的不同质因数为 $p_1,\ldots,p_k$，则：

$$\varphi(n)=n\prod_{i=1}^{k}\left(1-\frac1{p_i}\right)$$

每个不同质因数只贡献一次，指数大小不影响是否执行这一轮乘法。试除分解的时间复杂度为 $O(\sqrt n)$，额外空间为 $O(1)$。

### 单个整数的互质计数

初始化 `result = n`，每找到一个不同质因数 `p`，执行 `result = result / p * (p - 1)`，随后除尽该因子。先除再乘保持整数精确性；最后剩余值大于 `1` 时还要处理一次。

- [AcWing 873. 欧拉函数](https://www.acwing.com/problem/content/875/) （AcWing基础课）：分别计算每个输入整数的欧拉函数，`n = 1` 时返回 `1`。

## 线性筛

结合每个合数的最小质因数，在筛质数时同步计算欧拉函数。若 `p` 为质数，则 $\varphi(p)=p-1$；枚举质数 `p` 与已处理整数 `i` 时：

$$\varphi(ip)=\begin{cases}p\varphi(i),&p\mid i\\(p-1)\varphi(i),&p\nmid i\end{cases}$$

当 `p` 整除 `i` 时，处理完当前乘积后停止枚举，保证线性复杂度。总时间和空间均为 $O(n)$。

### 批量计算并求和

先设置 `phi[1] = 1`，筛出整个 `1..n` 范围的函数值，再累加。虽然单个函数值不超过 `n`，总和仍可能超过 `int`，应使用 `long`。

- [AcWing 874. 筛法求欧拉函数](https://www.acwing.com/problem/content/876/) （AcWing基础课）：求 $\sum_{i=1}^{n}\varphi(i)$，不要遗漏 `phi[1]`。
