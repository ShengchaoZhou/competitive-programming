# 容斥原理

容斥原理用于通过交集的奇偶次加减，计算多个存在重叠的集合之并集大小。

## [AcWing 890. 能被整除的数](https://www.acwing.com/problem/content/892/)

### 题目描述

给定整数 $n$ 和 $m$ 个互不相同的质数 $p_1,p_2,\ldots,p_m$，求 $1\sim n$ 中至少能被其中一个质数整除的整数数量。

**输入格式**

- 第一行包含两个整数 $n$ 和 $m$。
- 第二行包含 $m$ 个互不相同的质数。

**输出格式**

输出一个整数，表示满足条件的整数数量。

**数据范围**

- $1\le m\le 16$
- $1\le n,p_i\le 10^9$

**输入样例**

```text
10 2
2 3
```

**输出样例**

```text
7
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        long upperBound = scanner.nextLong();
        int primeCount = scanner.nextInt();
        long[] primes = new long[primeCount];

        for (int i = 0; i < primeCount; i++) {
            primes[i] = scanner.nextLong();
        }

        long answer = 0;
        for (int mask = 1; mask < 1 << primeCount; mask++) {
            long product = 1;
            int selectedCount = 0;
            boolean exceedsUpperBound = false;

            for (int i = 0; i < primeCount; i++) {
                if ((mask >> i & 1) == 0) continue;
                selectedCount++;
                if (product > upperBound / primes[i]) {
                    exceedsUpperBound = true;
                    break;
                }
                product *= primes[i];
            }

            if (exceedsUpperBound) continue;
            long intersectionSize = upperBound / product;
            if ((selectedCount & 1) == 1) {
                answer += intersectionSize;
            } else {
                answer -= intersectionSize;
            }
        }

        System.out.println(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(m\cdot 2^m)$。
- 空间复杂度：$O(m)$。
