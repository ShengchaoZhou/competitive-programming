# 匈牙利算法

匈牙利算法通过反复寻找增广路，求二分图中不共享端点的最大匹配边数。

## [AcWing 861. 二分图的最大匹配](https://www.acwing.com/problem/content/863/)

### 题目描述

给定一个二分图，左部包含 $n_1$ 个点，右部包含 $n_2$ 个点，共有 $m$ 条连接左右两部的边。求二分图的最大匹配数，即最多能选出多少条两两不共享端点的边。

**输入格式**

- 第一行包含三个整数 $n_1,n_2,m$。
- 接下来 $m$ 行，每行包含两个整数 $u,v$，表示左部的点 $u$ 与右部的点 $v$ 之间存在一条边。

**输出格式**

输出一个整数，表示二分图的最大匹配数。

**数据范围**

- $1\le n_1,n_2\le 500$
- $1\le u\le n_1$
- $1\le v\le n_2$
- $1\le m\le 10^5$

**输入样例**

```text
2 2 4
1 1
1 2
2 1
2 2
```

**输出样例**

```text
2
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static int[] head;
    private static int[] to;
    private static int[] next;
    private static int[] matchedLeft;
    private static boolean[] visitedRight;

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int leftCount = scanner.nextInt();
        int rightCount = scanner.nextInt();
        int edgeCount = scanner.nextInt();

        head = new int[leftCount + 1];
        to = new int[edgeCount];
        next = new int[edgeCount];
        Arrays.fill(head, -1);

        for (int edge = 0; edge < edgeCount; edge++) {
            int left = scanner.nextInt();
            to[edge] = scanner.nextInt();
            next[edge] = head[left];
            head[left] = edge;
        }

        matchedLeft = new int[rightCount + 1];
        visitedRight = new boolean[rightCount + 1];
        int answer = 0;

        for (int left = 1; left <= leftCount; left++) {
            Arrays.fill(visitedRight, false);
            if (augment(left)) {
                answer++;
            }
        }

        System.out.println(answer);
    }

    private static boolean augment(int left) {
        for (int edge = head[left]; edge != -1; edge = next[edge]) {
            int right = to[edge];
            if (visitedRight[right]) {
                continue;
            }
            visitedRight[right] = true;

            if (matchedLeft[right] == 0 || augment(matchedLeft[right])) {
                matchedLeft[right] = left;
                return true;
            }
        }
        return false;
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n_1m)$，每个左部点最多发起一次增广搜索。
- 空间复杂度：$O(n_1+n_2+m)$，用于存储邻接表、匹配状态和搜索标记。
