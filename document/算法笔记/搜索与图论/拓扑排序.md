# 拓扑排序

拓扑排序将有向无环图中的节点排成序列，使每条边的起点都出现在终点之前。它用于安排先后依赖，也可通过无法排完所有节点来判断有向环；无向图的判环条件不能直接套用。

## 有向图的依赖顺序

Kahn 算法统计每个节点的入度，将所有入度为 0 的节点入队。每弹出一个节点，就删除它的出边并降低后继入度；后继入度变为 0 时再入队。若最终处理了 n 个节点，得到一种拓扑序；否则图中存在有向环。时间为 O(n + m)。

### 输出合法处理顺序

输入若表示“a 依赖 b”，应建边 b → a，保证前置条件先出现。多个零入度节点可能产生多种答案；只有题目要求字典序最小时才需要优先队列。

- [AcWing 848. 有向图的拓扑序列](https://www.acwing.com/problem/content/850/) （AcWing基础课）：给定有向边直接统计终点入度，输出完整拓扑序；处理数不足 n 时无合法序列。
- [LeetCode 210. 课程表 II](https://leetcode.cn/problems/course-schedule-ii/) （面试150/CodeTop200）：先修关系 [a, b] 表示先学 b 再学 a，以拓扑序作为课程安排，存在环时返回空数组。

### 判断依赖是否成环

仅判断可行性时只需统计被处理节点数，不必保存完整序列。DFS 也可用未访问、当前路径中、已完成三种状态判环：只有遇到当前路径中的节点才是回边，遇到已完成节点不能直接判环。

- [LeetCode 207. 课程表](https://leetcode.cn/problems/course-schedule/) （Hot100/面试150/CodeTop200）：全部课程都能被拓扑处理时可以完成；初始化要涵盖没有先修关系的孤立课程。
- [CodeTop 补充题23. 检测循环依赖](https://mp.weixin.qq.com/s/pCRscwKqQdYYN7M1Sia7xA) （CodeTop200）：将依赖关系建成有向图，判断是否存在有向环；多个互不连通的依赖集合也要全部检查。
