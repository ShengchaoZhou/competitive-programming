# 拓扑排序

拓扑排序用于把有向无环图中的所有节点排成满足每条边先后约束的线性序列，并可同时判断图中是否存在环。

## [AcWing 848. 有向图的拓扑序列](https://www.acwing.com/problem/content/850/)

### 题目描述

给定一个包含 $n$ 个点、$m$ 条边的有向图，图中可能存在重边和自环。

如果一个由所有节点构成的序列满足：对于图中的每条有向边 $(x,y)$，节点 $x$ 都出现在节点 $y$ 之前，那么该序列称为图的拓扑序列。

输出任意一个拓扑序列；如果不存在拓扑序列，则输出 `-1`。

**输入格式**

第一行包含两个整数 $n$ 和 $m$。

接下来 $m$ 行，每行包含两个整数 $x$ 和 $y$，表示存在一条从 $x$ 指向 $y$ 的有向边。

**输出格式**

如果拓扑序列存在，输出一行包含 $n$ 个整数，表示任意一个合法拓扑序列；否则输出 `-1`。

**数据范围**

- $1 \le n,m \le 10^5$

**输入样例**

```text
3 3
1 2
2 3
1 3
```

**输出样例**

```text
1 2 3
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();
        int[] head = new int[n + 1];
        int[] to = new int[m];
        int[] next = new int[m];
        int[] inDegree = new int[n + 1];
        Arrays.fill(head, -1);

        for (int edge = 0; edge < m; edge++) {
            int from = scanner.nextInt();
            int destination = scanner.nextInt();
            to[edge] = destination;
            next[edge] = head[from];
            head[from] = edge;
            inDegree[destination]++;
        }

        int[] queue = new int[n];
        int headIndex = 0;
        int tailIndex = 0;
        for (int node = 1; node <= n; node++) {
            if (inDegree[node] == 0) {
                queue[tailIndex++] = node;
            }
        }

        while (headIndex < tailIndex) {
            int node = queue[headIndex++];
            for (int edge = head[node]; edge != -1; edge = next[edge]) {
                int neighbor = to[edge];
                if (--inDegree[neighbor] == 0) {
                    queue[tailIndex++] = neighbor;
                }
            }
        }

        if (tailIndex < n) {
            System.out.println(-1);
            return;
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (i > 0) {
                answer.append(' ');
            }
            answer.append(queue[i]);
        }
        System.out.println(answer);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n+m)$，每个节点入队一次，每条边处理一次。
- 空间复杂度：$O(n+m)$，邻接表、入度数组和队列占用线性空间。
