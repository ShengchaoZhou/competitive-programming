# 树与图的深度优先遍历

树与图的深度优先遍历用于访问连通结构中的所有节点，并在回溯阶段汇总子树大小等信息。

## [AcWing 846. 树的重心](https://www.acwing.com/problem/content/848/)

### 题目描述

给定一棵包含 $n$ 个节点的树，节点编号为 $1 \sim n$。

删除树中的某个节点后，原树会分成若干连通块。如果一个节点被删除后，剩余连通块中节点数的最大值在所有删除方案中最小，则称该节点为树的重心。

求删除树的重心后，剩余各个连通块中节点数的最大值。

**输入格式**

第一行包含整数 $n$，表示树的节点数。

接下来 $n-1$ 行，每行包含两个整数 $a$ 和 $b$，表示节点 $a$ 与节点 $b$ 之间存在一条无向边。

**输出格式**

输出一个整数，表示删除树的重心后，剩余连通块中节点数的最大值。

**数据范围**

- $1 \le n \le 10^5$

**输入样例**

```text
9
1 2
1 7
1 4
2 8
2 5
4 3
3 9
4 6
```

**输出样例**

```text
4
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;
import java.util.Arrays;

public class Main {
    private static int[] head;
    private static int[] to;
    private static int[] next;
    private static int edgeIndex;

    private static void addEdge(int from, int destination) {
        to[edgeIndex] = destination;
        next[edgeIndex] = head[from];
        head[from] = edgeIndex++;
    }

    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int n = scanner.nextInt();
        head = new int[n + 1];
        Arrays.fill(head, -1);
        to = new int[Math.max(0, 2 * (n - 1))];
        next = new int[Math.max(0, 2 * (n - 1))];

        for (int i = 0; i < n - 1; i++) {
            int a = scanner.nextInt();
            int b = scanner.nextInt();
            addEdge(a, b);
            addEdge(b, a);
        }

        int[] parent = new int[n + 1];
        int[] order = new int[n];
        int[] stack = new int[n];
        int orderSize = 0;
        int top = 0;
        parent[1] = -1;
        stack[top++] = 1;

        while (top > 0) {
            int node = stack[--top];
            order[orderSize++] = node;
            for (int edge = head[node]; edge != -1; edge = next[edge]) {
                int neighbor = to[edge];
                if (neighbor != parent[node]) {
                    parent[neighbor] = node;
                    stack[top++] = neighbor;
                }
            }
        }

        int[] subtreeSize = new int[n + 1];
        int answer = n;
        for (int i = orderSize - 1; i >= 0; i--) {
            int node = order[i];
            int size = 1;
            int largestComponent = 0;

            for (int edge = head[node]; edge != -1; edge = next[edge]) {
                int neighbor = to[edge];
                if (parent[neighbor] == node) {
                    size += subtreeSize[neighbor];
                    largestComponent = Math.max(largestComponent, subtreeSize[neighbor]);
                }
            }

            subtreeSize[node] = size;
            largestComponent = Math.max(largestComponent, n - size);
            answer = Math.min(answer, largestComponent);
        }

        System.out.println(answer);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n)$，每个节点和每条边只被常数次处理。
- 空间复杂度：$O(n)$，邻接表、父节点、遍历序列、栈和子树大小数组均为线性规模。
