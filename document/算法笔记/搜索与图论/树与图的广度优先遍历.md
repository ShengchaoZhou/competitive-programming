# 树与图的广度优先遍历

树与图的广度优先遍历用于在边权均相同的图中按层访问节点，并求起点到其他节点的最短边数。

## [AcWing 847. 图中点的层次](https://www.acwing.com/problem/content/849/)

### 题目描述

给定一个包含 $n$ 个点、$m$ 条边的有向图，图中可能存在重边和自环。所有边的长度均为 $1$，节点编号为 $1 \sim n$。

求从 $1$ 号点到 $n$ 号点的最短距离；如果无法从 $1$ 号点到达 $n$ 号点，输出 `-1`。

**输入格式**

第一行包含两个整数 $n$ 和 $m$。

接下来 $m$ 行，每行包含两个整数 $a$ 和 $b$，表示存在一条从 $a$ 指向 $b$、长度为 $1$ 的有向边。

**输出格式**

输出一个整数，表示从 $1$ 号点到 $n$ 号点的最短距离。

**数据范围**

- $1 \le n,m \le 10^5$

**输入样例**

```text
4 5
1 2
2 3
3 4
1 3
1 4
```

**输出样例**

```text
1
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();
        int[] head = new int[n + 1];
        int[] to = new int[m];
        int[] next = new int[m];
        Arrays.fill(head, -1);

        for (int edge = 0; edge < m; edge++) {
            int from = scanner.nextInt();
            int destination = scanner.nextInt();
            to[edge] = destination;
            next[edge] = head[from];
            head[from] = edge;
        }

        int[] distance = new int[n + 1];
        Arrays.fill(distance, -1);
        int[] queue = new int[n];
        int queueHead = 0;
        int queueTail = 0;
        queue[queueTail++] = 1;
        distance[1] = 0;

        while (queueHead < queueTail) {
            int node = queue[queueHead++];
            for (int edge = head[node]; edge != -1; edge = next[edge]) {
                int neighbor = to[edge];
                if (distance[neighbor] == -1) {
                    distance[neighbor] = distance[node] + 1;
                    queue[queueTail++] = neighbor;
                }
            }
        }

        System.out.println(distance[n]);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n+m)$，每个节点至多入队一次，每条边至多检查一次。
- 空间复杂度：$O(n+m)$，邻接表、距离数组和队列占用线性空间。
