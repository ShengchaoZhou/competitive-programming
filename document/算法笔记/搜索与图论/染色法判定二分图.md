# 染色法判定二分图

染色法通过尝试为无向图的相邻点分配不同颜色，判断图能否被划分为两个内部没有边的点集。

## [AcWing 860. 染色法判定二分图](https://www.acwing.com/problem/content/862/)

### 题目描述

给定一个包含 $n$ 个点和 $m$ 条边的无向图，图中可能存在重边和自环。判断该图是否为二分图。

**输入格式**

- 第一行包含两个整数 $n$ 和 $m$。
- 接下来 $m$ 行，每行包含两个整数 $u,v$，表示 $u$ 和 $v$ 之间存在一条无向边。

**输出格式**

如果给定图是二分图，输出 `Yes`；否则输出 `No`。

**数据范围**

- $1\le n,m\le 10^5$

**输入样例**

```text
4 4
1 3
1 4
2 3
2 4
```

**输出样例**

```text
Yes
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int m = scanner.nextInt();

        int[] head = new int[n + 1];
        int[] to = new int[m * 2];
        int[] next = new int[m * 2];
        Arrays.fill(head, -1);

        int edgeIndex = 0;
        for (int edge = 0; edge < m; edge++) {
            int first = scanner.nextInt();
            int second = scanner.nextInt();

            to[edgeIndex] = second;
            next[edgeIndex] = head[first];
            head[first] = edgeIndex++;

            to[edgeIndex] = first;
            next[edgeIndex] = head[second];
            head[second] = edgeIndex++;
        }

        int[] color = new int[n + 1];
        int[] queue = new int[n];
        boolean bipartite = true;

        for (int start = 1; start <= n && bipartite; start++) {
            if (color[start] != 0) {
                continue;
            }

            int front = 0;
            int back = 0;
            queue[back++] = start;
            color[start] = 1;

            while (front < back && bipartite) {
                int vertex = queue[front++];
                for (int edge = head[vertex]; edge != -1; edge = next[edge]) {
                    int neighbor = to[edge];
                    if (color[neighbor] == 0) {
                        color[neighbor] = 3 - color[vertex];
                        queue[back++] = neighbor;
                    } else if (color[neighbor] == color[vertex]) {
                        bipartite = false;
                        break;
                    }
                }
            }
        }

        System.out.println(bipartite ? "Yes" : "No");
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n+m)$，每个点与每条边只会被访问常数次。
- 空间复杂度：$O(n+m)$，用于存储邻接表、颜色和 BFS 队列。
