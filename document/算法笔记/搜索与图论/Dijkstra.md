# Dijkstra

Dijkstra 用于边权非负的单源最短路。每次确定当前距离最小的未确定节点，再用它松弛出边；非负边权保证该节点之后不会得到更短的路径。存在负权边时不能使用这一确定规则。

## 非负权单源最短路

源点距离为 0，其余为正无穷。用 dist[v] = min(dist[v], dist[u] + w) 松弛边，答案是到目标节点的距离。距离和可能超过单条边的取值范围，应选择足够大的数值类型与无穷大哨兵。

### 稠密图的朴素实现

用邻接矩阵存边，每轮扫描所有未确定节点找出距离最小者，再扫描其全部邻居。时间为 O(n² + m)，空间为 O(n²)；读入重边时保留最小权值，最小距离仍为无穷大时可结束。

- [AcWing 849. Dijkstra 求最短路 I](https://www.acwing.com/problem/content/851/) （AcWing基础课）：节点较少，适合矩阵实现；求从 1 到 n 的最短距离，目标不可达时按题意返回 -1。

### 稀疏图的堆优化实现

用邻接表存边，小根堆保存候选距离与节点。节点距离改善时加入新候选；弹出时若候选距离大于当前 dist，则丢弃过期记录。使用惰性删除时至多产生 O(m) 条候选，时间为 O((n + m) log(m + 1))，空间为 O(n + m)。

- [AcWing 850. Dijkstra 求最短路 II](https://www.acwing.com/problem/content/852/) （AcWing基础课）：边和节点规模较大，避免邻接矩阵；每条边只在其起点以有效最短距离出堆时参与松弛。
