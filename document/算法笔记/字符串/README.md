# 字符串

本模块整理字符扫描、格式解析、模式匹配、前缀结构与回文处理。涉及动态规划、滑动窗口或回溯时，可直接进入相应算法专题。

| 类别 | 专题 | 题型范围 |
| --- | --- | --- |
| 字符处理 | [字符串处理](字符串处理.md) | 公共前缀、单词边界、数值转换、版本比较、地址校验、定宽排版 |
| 回文 | [回文串](回文串.md) | 奇偶中心扩展、最长回文子串 |
| 模式匹配 | [KMP](../数据结构/KMP.md) | 前缀函数、首次或全部匹配位置 |
| 前缀结构 | [Trie](../数据结构/Trie.md) | 单词与前缀查询、通配符、网格多词搜索 |
| 子串比较 | [字符串哈希](../数据结构/哈希表.md#字符串哈希) | 子串相等查询、最长重复子串 |
| 频次与映射 | [哈希表](../数据结构/哈希表.md#集合与映射) | 异位词分组、字符覆盖、双向映射 |
| 嵌套结构 | [栈](../数据结构/栈.md#表达式与嵌套结构) | 表达式求值、字符串解码、路径规范化 |
| 动态规划 | [线性 DP](../动态规划/线性DP.md) | 公共子序列、编辑距离等序列状态转移 |
| 指针扫描 | [双指针](../基础算法/双指针.md) | 对向字符检查、子序列匹配 |
| 区间维护 | [滑动窗口](../基础算法/滑动窗口.md) | 不重复子串、字符覆盖、定长窗口计数 |
| 枚举方案 | [DFS](../搜索与图论/DFS.md) | 排列组合、分割与逐步构造 |
