# 数位统计 DP

数位统计把大范围整数按各个数位拆分，常将区间答案写成 F(r)-F(l-1)，减少对每个整数的枚举。

| [按位分类统计](#按位分类统计) | 统计各数字出现次数 | [AcWing 338. 计数问题](https://www.acwing.com/problem/content/340/) （AcWing基础课） |

## 按位分类统计

固定个位、十位等一个位置，将上界拆成高位 high、当前位 cur、低位 low，再分别计算完整循环与最后一个不完整循环的贡献。

### 统计各数字出现次数

对非零数字 d、位权 p，完整循环贡献 high*p；cur>d 时再加 p，cur==d 时再加 low+1。数字 0 必须排除前导零：high>0 时将完整循环改为 (high-1)*p，并按当前位补余量；high==0 时该位置没有合法零贡献。每个数字 O(log n)。

- [AcWing 338. 计数问题](https://www.acwing.com/problem/content/340/) （AcWing基础课）：先交换逆序端点，再用两个前缀统计之差求 0～9 的出现次数；F(0)=0 对应原题的正整数范围。
