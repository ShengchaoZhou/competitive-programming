# 树形 DP

树形 DP 先求子树状态，再将各个子树的结果合并到父节点。状态必须包含父子之间会相互限制的信息。

## 父子互斥选择

树中每个节点有收益，相邻父子不能同时选择。对于每个节点，分别保存选择与不选择两种最优结果。

### 树上的最大权独立集

选 u 时，只能取每个子节点“不选”的状态；不选 u 时，对每个子节点取两种状态的最大值。按后序处理，时间 O(n)、空间 O(n)。节点收益可能为负，因此允许不选任何节点，不能强制每棵子树都选择一人。

- [AcWing 285. 没有上司的舞会](https://www.acwing.com/problem/content/287/) （AcWing基础课）：根据直属关系找到根，分别累计选上司与不选上司时各子树的最佳贡献。
