## 01 背包

有 `n` 个物品，每个物品都会消耗一定的资源（如体积、金额或时间），并带来一定的收益。每个物品至多选择一次，需要在总资源有限的条件下，决定每个物品“选”还是“不选”，使最终结果最优。

### 求最大价值

在总资源不超过上限的前提下，求能够获得的最大收益，这是最标准的 01 背包问题。定义 `f[j]` 为容量不超过 `j` 时的最大价值。每件物品只能选一次，因此容量必须从大到小遍历。

- [AcWing 2. 01背包问题](https://www.acwing.com/problem/content/2/) （AcWing基础课）

### 求最小代价

在达到指定目标的同时，最小化选中物品的总代价。将起点初始化为 `f[0] = 0`，其余状态初始化为正无穷，转移时取最小值，避免从不可达状态转移。

- [LeetCode 2742. 给墙壁刷油漆](https://leetcode.cn/problems/painting-the-walls/)：每位付费油漆工相当于覆盖 `time[i] + 1` 面墙，求覆盖至少 `n` 面墙的最小费用。若状态表示已经覆盖的墙数，可将超过 `n` 的部分截断为 `n`。

### 物品体积和价值相同

数组中的每个元素既是选择它的“体积”，也是它对目标和的贡献，本质上是子集和问题。可以用布尔状态记录某个和是否能够达到，也可以记录不超过目标值时能组成的最大和。

- [LeetCode 416. 分割等和子集](https://leetcode.cn/problems/partition-equal-subset-sum/) （Hot100/CodeTop200）：总和为偶数时，判断能否选出总和恰好为一半的子集。
- [LeetCode 1049. 最后一块石头的重量 II](https://leetcode.cn/problems/last-stone-weight-ii/)：将石头分成总重量尽量接近的两组，求不超过总重量一半的最大子集和。

### 恰好装满背包

选中物品的总体积必须恰好等于目标容量，而不是只要不超过容量即可。只将 `f[0]` 设为合法起点；求最大值时，其余状态初始化为负无穷，求最小值时则初始化为正无穷。

- [LeetCode 2915. 和为目标值的最长子序列的长度](https://leetcode.cn/problems/length-of-the-longest-subsequence-that-sums-to-target/)：将元素值视为体积、每选一个元素的收益设为 `1`，求恰好组成目标和时的最大长度。

### 二维费用问题

每个物品同时消耗两种资源。若两种资源上限分别为 `V` 和 `M`，则用 `f[j][k]` 表示资源消耗不超过 `j` 和 `k` 时的最大价值。处理第 `i` 件物品时，状态转移为：

$$f[j][k] = \max(f[j][k],\ f[j-a_i][k-b_i] + w_i)$$

其中 `a_i`、`b_i` 是该物品消耗的两种资源，`w_i` 是其价值。`j` 从 `V` 到 `a_i` 倒序遍历，`k` 从 `M` 到 `b_i` 倒序遍历，保证每件物品至多使用一次。

- [LeetCode 474. 一和零](https://leetcode.cn/problems/ones-and-zeroes/)：字符串中 `0` 和 `1` 的数量就是两种费用，每选择一个字符串的价值为 `1`。

### 求方案数量

不再求最优值，而是统计达到某一容量或目标和的选择方案数。初始化 `f[0] = 1`，其余状态为 `0`，表示什么都不选是组成和为 `0` 的一种方案；状态转移改为 `f[j] += f[j - v_i]`。容量仍然倒序遍历，保证每件物品至多使用一次。

- [LeetCode 494. 目标和](https://leetcode.cn/problems/target-sum/) （CodeTop200）：设所有元素之和为 `sum`，统计和为 `(sum + target) / 2` 的子集数量；先排除 `abs(target) > sum` 或 `sum + target` 为奇数的情况。元素为 `0` 时，选与不选是两种不同方案，都要计入。
- [LeetCode 879. 盈利计划](https://leetcode.cn/problems/profitable-schemes/)：结合人数上限与利润下限，用二维状态计数；利润达到下限后可合并到同一个状态，答案按题目要求取模。

### 输出具体方案

除了求最优值，还需要还原被选中的物品。可以使用二维状态 `f[i][j]` 保留每一轮的决策信息，或保存不会被后续更新覆盖的前驱节点，再从最终状态向前倒推。只保留最优值的一维数组通常不足以还原完整方案；仅维护随更新覆盖的 `parent[j]`，也可能把不同物品轮次的决策混在一起。

- [AcWing 12. 背包问题求具体方案](https://www.acwing.com/problem/content/12/)：还要求输出字典序最小的最优方案，需要在价值相同时正确处理取舍。

## 完全背包

有 `n` 种物品，每种物品可以重复选择任意多次。每选一件都会消耗相应资源，可以求资源限制下的最优值，也可以判断能否恰好达到目标，或统计达到目标的方案数。

### 求最大价值

定义 `f[j]` 为容量不超过 `j` 时的最大价值，初始值均为 `0`。枚举每种物品，将容量从 `v_i` 到 `V` 正序遍历，转移为 `f[j] = max(f[j], f[j - v_i] + w_i)`。

- [AcWing 3. 完全背包问题](https://www.acwing.com/problem/content/3/) （AcWing基础课）

### 求最少物品数量

定义 `f[j]` 为恰好组成目标 `j` 所需的最少物品数量。初始化 `f[0] = 0`，其余状态为正无穷；从可达状态转移，使用 `f[j] = min(f[j], f[j - v_i] + 1)`。最后若目标仍不可达，则按题目要求返回无解标记。

- [LeetCode 322. 零钱兑换](https://leetcode.cn/problems/coin-change/) （Hot100/面试150/CodeTop200）：每种面额的硬币可以重复使用，求恰好凑出金额所需的最少硬币数。
- [LeetCode 279. 完全平方数](https://leetcode.cn/problems/perfect-squares/) （Hot100）：将不超过 `n` 的正完全平方数视为物品体积，求组成 `n` 所需的最少数量。

### 求组合数量

同一批物品只要各自的选择数量相同，就算同一种方案，不区分排列顺序。初始化 `f[0] = 1`，其余状态为 `0`；**外层枚举物品，内层正序枚举容量**，使用 `f[j] += f[j - v_i]`。例如面额 `1` 与 `2` 组成 `3` 时，`1 + 2` 和 `2 + 1` 只计一次。

- [LeetCode 518. 零钱兑换 II](https://leetcode.cn/problems/coin-change-ii/) （CodeTop200）：求恰好组成指定金额的硬币组合数。

### 求排列数量

选择顺序不同，就算不同方案。初始化 `f[0] = 1`，其余状态为 `0`；**外层从小到大枚举目标和，内层枚举最后选择的物品**，累加 `f[j - v_i]`。这里要求物品体积为正，保证转移只依赖更小的目标和。

- [LeetCode 377. 组合总和 Ⅳ](https://leetcode.cn/problems/combination-sum-iv/)：虽然题名含“组合”，题意区分选择顺序，因此按排列计数。

### 字符串拼接可行性

单词可以重复使用，但能否拼接还取决于具体字符与顺序。定义 `f[i]` 为字符串前 `i` 个字符能否被拆分，初始化 `f[0] = true`，其余状态为 `false`。从短到长枚举前缀，再枚举最后一个单词；只有单词与前缀末尾实际匹配、且此前的前缀可达时，才能转移。

- [LeetCode 139. 单词拆分](https://leetcode.cn/problems/word-break/) （Hot100/面试150/CodeTop200）：具有物品可重复使用的特征，归入完全背包的字符串变式；不能只把单词长度当作体积来判断。

## 多重背包

有 `n` 种物品，第 `i` 种最多可以选择 `s_i` 件。每种物品的选择数量介于 `0` 与 `s_i` 之间，需要在数量上限与背包容量的共同限制下求解。

### 枚举数量求最优值

定义 `f[i][j]` 为只考虑前 `i` 种物品、容量不超过 `j` 时的最大价值。枚举第 `i` 种物品选择的数量 `k`：

$$f[i][j] = \max_{0 \le k \le s_i,\; kv_i \le j}\bigl(f[i-1][j-kv_i] + kw_i\bigr)$$

压缩为一维时，按“物品种类 → 容量倒序 → 件数”的顺序遍历，保证所有候选都来自未使用当前种类的状态。时间复杂度为 $O(NVS)$，适合数量上限较小的情况。

- [AcWing 4. 多重背包问题 I](https://www.acwing.com/problem/content/4/) （AcWing基础课）

### 二进制拆分求最优值

将一种物品的 `s_i` 件拆成若干个物品包，例如 `13` 件拆成 `1、2、4、6` 件的四个包，每个包至多选择一次。包的体积与价值都乘以包内件数，再按 01 背包倒序更新容量。

拆分后的包可以表示从 `0` 到 `s_i` 的所有选择数量，使每种物品的处理次数降为 $O(\log(s_i+1))$。这种拆分适用于求最优值；不同包的组合可能表示同一件数，不能直接用于统计原问题的方案数。

- [AcWing 5. 多重背包问题 II](https://www.acwing.com/problem/content/5/) （AcWing基础课）

### 求方案数量

定义 `f[i][j]` 为使用前 `i` 种物品恰好组成目标 `j` 的方案数。初始化 `f[0][0] = 1`，其余为 `0`；枚举当前种类的选择数量，累加上一层状态：

$$f[i][j] = \sum_{k=0}^{\min(s_i,\lfloor j/v_i\rfloor)} f[i-1][j-kv_i]$$

这里同一种物品的不同个体不作区分，一种数量选择只计一次。使用上一层与当前层两个数组实现时，每处理一种物品都应清空当前层。

- [LeetCode 2585. 获得分数的方法数](https://leetcode.cn/problems/number-of-ways-to-earn-points/)：每类题目数量有限，同类型题目不可区分，求恰好得到目标分数的方案数，并按题目要求取模。

## 分组背包

物品被分成若干组，同一组内的选项互斥。标准模型要求每组至多选择一件；一些变式要求每组恰好选择一件，或者先将一整组中的合法取法转换成候选物品。

### 每组至多选一件

定义 `f[j]` 为容量不超过 `j` 时的最大价值，初始值均为 `0`。每一组先保留“不选”的结果，再枚举该组中的一件物品来更新。对体积为正的标准模型，可以按“组 → 容量倒序 → 组内物品”的顺序原地更新。

不能对组内每件物品分别执行一次完整的 01 背包更新，否则后面的物品可能叠加前面物品的结果，造成同组选中多件。

- [AcWing 9. 分组背包问题](https://www.acwing.com/problem/content/9/) （AcWing基础课）

### 每组恰好选一件，求方案数量

每组必须贡献一个选项，因此当前层不能直接继承上一层的结果。初始化 `f[0][0] = 1`，其余状态为 `0`；每组开始时清空当前层，只从上一层枚举一个选项进行转移。

- [LeetCode 1155. 掷骰子等于目标和的方法数](https://leetcode.cn/problems/number-of-dice-rolls-with-target-sum/)：将每一枚骰子视为一组，点数视为组内选项，每组恰选一个点数。不同骰子的位置有区别，答案按题目要求取模。

### 每组恰好选一件，求最接近目标的和

使用布尔状态记录处理完当前组后哪些总和可达。每一层重新初始化为不可达，再由上一层枚举组内选项。最后在所有可达和中寻找与目标值绝对差最小的一个；超过目标值的和也可能是最优答案，不能直接丢弃。

- [LeetCode 1981. 最小化目标值与所选元素的差](https://leetcode.cn/problems/minimize-the-difference-between-target-and-chosen-elements/)：每一行是一组，从每行恰好取一个数，可用各行最大值之和作为可达和的上界。

### 组内取前缀，恰好选择指定数量

同一组中只能取前若干件时，先求前缀和，将“取 `t` 件”视为一个体积为 `t`、价值为前缀和的候选物品；每组从这些候选中选择一个，也允许取 `0` 件。

若要求总共恰好取 `k` 件，定义 `f[j]` 为恰好取 `j` 件的最大价值，初始化 `f[0] = 0`，其余为负无穷，并只从可达状态转移。每组从上一层枚举取多少件，避免同一组的不同前缀被重复选择。

- [LeetCode 2218. 从栈中取出 K 个硬币的最大面值和](https://leetcode.cn/problems/maximum-value-of-k-coins-from-piles/)：每个栈是一组，选项是从栈顶取出的一个前缀，总取币数必须恰好为 `k`。
