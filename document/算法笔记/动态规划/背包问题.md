# 背包问题

背包动态规划用于在容量有限且物品选择规则不同的条件下，求不超过容量时能够获得的最大总价值。

## 01 背包

### 模型能解决的问题

有 `n` 个物品，每个物品都会消耗一定的资源（如体积、金额或时间），并带来一定的收益。每个物品至多选择一次，需要在总资源有限的条件下，决定每个物品“选”还是“不选”，使最终结果最优。

识别 01 背包的关键是：**每个物品只有选或不选两种状态，且不能重复选择。**

### 常见题型

**求最大价值**

在总资源不超过上限的前提下，求能够获得的最大收益，这是最标准的 01 背包问题。定义 `f[j]` 为容量不超过 `j` 时的最大价值。每件物品只能选一次，因此容量必须从大到小遍历。

代表题目：[AcWing 2. 01背包问题](https://www.acwing.com/problem/content/2/)，本文下方给出完整题解。

**求最小代价**

在达到指定目标的同时，最小化选中物品的总代价。将起点初始化为 `f[0] = 0`，其余状态初始化为正无穷，转移时取最小值，避免从不可达状态转移。

代表题目：[LeetCode 2742. 给墙壁刷油漆](https://leetcode.cn/problems/painting-the-walls/)，可转换为求“至少装满”背包所需的最小代价。

**物品体积和价值相同**

数组中的每个元素既是选择它的“体积”，也是它对目标和的贡献，本质上是子集和问题。可以用布尔状态记录某个和是否能够达到，也可以记录不超过目标值时能组成的最大和。

代表题目：[LeetCode 416. 分割等和子集](https://leetcode.cn/problems/partition-equal-subset-sum/)、[LeetCode 1049. 最后一块石头的重量 II](https://leetcode.cn/problems/last-stone-weight-ii/)。

**恰好装满背包**

选中物品的总体积必须恰好等于目标容量，而不是只要不超过容量即可。只将 `f[0]` 设为合法起点；求最大值时，其余状态初始化为负无穷，求最小值时则初始化为正无穷。

代表题目：[LeetCode 2915. 和为目标值的最长子序列的长度](https://leetcode.cn/problems/length-of-the-longest-subsequence-that-sums-to-target/)。

**二维费用问题**

每个物品同时消耗两种资源。若两种资源上限分别为 `V` 和 `M`，则用 `f[j][k]` 表示资源消耗不超过 `j` 和 `k` 时的最大价值。处理第 `i` 件物品时，状态转移为：

$$f[j][k] = \max(f[j][k],\ f[j-a_i][k-b_i] + w_i)$$

其中 `a_i`、`b_i` 是该物品消耗的两种资源，`w_i` 是其价值。`j` 从 `V` 到 `a_i` 倒序遍历，`k` 从 `M` 到 `b_i` 倒序遍历，保证每件物品至多使用一次。

代表题目：[LeetCode 474. 一和零](https://leetcode.cn/problems/ones-and-zeroes/)，字符串中 `0` 和 `1` 的数量就是两种费用，每选择一个字符串的价值为 `1`。

**求方案数量**

不再求最优值，而是统计达到某一容量或目标和的选择方案数。初始化 `f[0] = 1`，表示什么都不选是组成和为 `0` 的一种方案；状态转移改为 `f[j] += f[j - v_i]`。

代表题目：[LeetCode 494. 目标和](https://leetcode.cn/problems/target-sum/)、[LeetCode 879. 盈利计划](https://leetcode.cn/problems/profitable-schemes/)。后者还结合了二维费用和利润下限。

**输出具体方案**

除了求最优值，还需要还原被选中的物品。可以使用二维状态 `f[i][j]` 保留每一轮的决策信息，或额外记录状态的前驱，再从最终状态向前倒推。只保留最优值的一维数组通常不足以还原完整方案。

代表题目：[AcWing 12. 背包问题求具体方案](https://www.acwing.com/problem/content/12/)。

### 经典例题

#### [AcWing 2. 01背包问题](https://www.acwing.com/problem/content/2/)

##### 题目描述

有一个容量为 `V` 的背包和 `N` 件物品，每件物品至多选择一次；第 `i` 件物品的体积为 `v_i`，价值为 `w_i`，求所选物品总体积不超过 `V` 时能够得到的最大总价值。

**输入格式**

- 第一行包含两个整数 `N` 和 `V`，分别表示物品数量和背包容量。
- 接下来 `N` 行，每行包含两个整数 `v_i` 和 `w_i`，分别表示第 `i` 件物品的体积和价值。

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N, V ≤ 1000`
- `0 < v_i, w_i ≤ 1000`

**输入样例**

```text
4 5
1 2
2 4
3 4
4 5
```

**输出样例**

```text
8
```

##### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int itemCount = scanner.nextInt();
        int capacity = scanner.nextInt();
        int[] best = new int[capacity + 1];

        for (int i = 0; i < itemCount; i++) {
            int volume = scanner.nextInt();
            int value = scanner.nextInt();

            for (int current = capacity; current >= volume; current--) {
                best[current] = Math.max(best[current], best[current - volume] + value);
            }
        }

        System.out.println(best[capacity]);
    }

}
```

##### 时空复杂度

- 时间复杂度：$O(NV)$。
- 空间复杂度：$O(V)$。

## [AcWing 3. 完全背包问题](https://www.acwing.com/problem/content/3/)

### 题目描述

有一个容量为 `V` 的背包和 `N` 种物品，每种物品都可以选择任意多件；第 `i` 种物品的体积为 `v_i`，价值为 `w_i`，求所选物品总体积不超过 `V` 时能够得到的最大总价值。

**输入格式**

- 第一行包含两个整数 `N` 和 `V`，分别表示物品种数和背包容量。
- 接下来 `N` 行，每行包含两个整数 `v_i` 和 `w_i`，分别表示第 `i` 种物品单件的体积和价值。

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N, V ≤ 1000`
- `0 < v_i, w_i ≤ 1000`

**输入样例**

```text
4 5
1 2
2 4
3 4
4 5
```

**输出样例**

```text
10
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int typeCount = scanner.nextInt();

        for (int i = 0; i < typeCount; i++) {
            int volume = scanner.nextInt();
            int value = scanner.nextInt();

                best[current] = Math.max(best[current], best[current - volume] + value);
            }
        }

        System.out.println(best[capacity]);
    }

}
```

## [AcWing 4. 多重背包问题 I](https://www.acwing.com/problem/content/4/)

### 题目描述

有一个容量为 `V` 的背包和 `N` 种物品，第 `i` 种物品最多可以选择 `s_i` 件，每件体积为 `v_i`、价值为 `w_i`；求所选物品总体积不超过 `V` 时能够得到的最大总价值。

**输入格式**

- 第一行包含两个整数 `N` 和 `V`，分别表示物品种数和背包容量。
- 接下来 `N` 行，每行包含三个整数 `v_i`、`w_i` 和 `s_i`，分别表示第 `i` 种物品单件的体积、价值和可用数量。

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N, V ≤ 100`
- `0 < v_i, w_i, s_i ≤ 100`

**输入样例**

```text
4 5
1 2 3
2 4 1
3 4 3
4 5 2
```

**输出样例**

```text
10
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int typeCount = scanner.nextInt();
        int capacity = scanner.nextInt();
        int[] best = new int[capacity + 1];

        for (int i = 0; i < typeCount; i++) {
            int volume = scanner.nextInt();
            int value = scanner.nextInt();
            int available = scanner.nextInt();

            for (int current = capacity; current >= volume; current--) {
                for (int count = 1; count <= available && count * volume <= current; count++) {
                    best[current] = Math.max(
                            best[current],
                            best[current - count * volume] + count * value
                    );
                }
            }
        }

        System.out.println(best[capacity]);
    }

}
```

### 时空复杂度

- 时间复杂度：$O(NVS)$，其中 `S` 是单种物品数量上限。
- 空间复杂度：$O(V)$。

## [AcWing 5. 多重背包问题 II](https://www.acwing.com/problem/content/5/)

### 题目描述

有一个容量为 `V` 的背包和 `N` 种物品，第 `i` 种物品最多可以选择 `s_i` 件，每件体积为 `v_i`、价值为 `w_i`；求所选物品总体积不超过 `V` 时能够得到的最大总价值。

**输入格式**

- 第一行包含两个整数 `N` 和 `V`，分别表示物品种数和背包容量。
- 接下来 `N` 行，每行包含三个整数 `v_i`、`w_i` 和 `s_i`，分别表示第 `i` 种物品单件的体积、价值和可用数量。

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N ≤ 1000`
- `0 < V ≤ 2000`
- `0 < v_i, w_i, s_i ≤ 2000`

本题要求使用多重背包的二进制优化方法。

**输入样例**

```text
4 5
1 2 3
2 4 1
3 4 3
4 5 2
```

**输出样例**

```text
10
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int typeCount = scanner.nextInt();
        int capacity = scanner.nextInt();
        int[] best = new int[capacity + 1];

        for (int i = 0; i < typeCount; i++) {
            int unitVolume = scanner.nextInt();
            int unitValue = scanner.nextInt();
            int remaining = scanner.nextInt();

            for (int bundleSize = 1; remaining > 0; bundleSize <<= 1) {
                int used = Math.min(bundleSize, remaining);
                int bundleVolume = used * unitVolume;
                int bundleValue = used * unitValue;

                for (int current = capacity; current >= bundleVolume; current--) {
                    best[current] = Math.max(
                            best[current],
                            best[current - bundleVolume] + bundleValue
                    );
                }
                remaining -= used;
            }
        }

        System.out.println(best[capacity]);
    }

}
```

### 时空复杂度

- 时间复杂度：$O\!\left(V\sum_{i=1}^{N}\log(s_i+1)\right)$，最坏可写为 $O(NV\log S)$，其中 `S` 是单种物品数量上限。
- 空间复杂度：$O(V)$。

## [AcWing 9. 分组背包问题](https://www.acwing.com/problem/content/9/)

### 题目描述

有一个容量为 `V` 的背包和 `N` 组物品，每组内有若干件物品，同一组至多选择一件；第 `i` 组第 `j` 件物品的体积为 `v_ij`、价值为 `w_ij`，求所选物品总体积不超过 `V` 时能够得到的最大总价值。

**输入格式**

- 第一行包含两个整数 `N` 和 `V`，分别表示物品组数和背包容量。
- 随后依次给出 `N` 组数据：每组第一行包含整数 `S_i`，表示该组的物品数量；接下来 `S_i` 行，每行包含两个整数 `v_ij` 和 `w_ij`，分别表示该件物品的体积和价值。

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N, V ≤ 100`
- `0 < S_i ≤ 100`
- `0 < v_ij, w_ij ≤ 100`

**输入样例**

```text
3 5
2
1 2
2 4
1
3 4
1
4 5
```

**输出样例**

```text
8
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int groupCount = scanner.nextInt();
        int capacity = scanner.nextInt();
        int[] best = new int[capacity + 1];

        for (int group = 0; group < groupCount; group++) {
            int itemCount = scanner.nextInt();
            int[] volumes = new int[itemCount];
            int[] values = new int[itemCount];

            for (int i = 0; i < itemCount; i++) {
                volumes[i] = scanner.nextInt();
                values[i] = scanner.nextInt();
            }

            for (int current = capacity; current >= 0; current--) {
                for (int i = 0; i < itemCount; i++) {
                    if (volumes[i] <= current) {
                        best[current] = Math.max(
                                best[current],
                                best[current - volumes[i]] + values[i]
                        );
                    }
                }
            }
        }

        System.out.println(best[capacity]);
    }

}
```

### 时空复杂度

- 时间复杂度：$O\!\left(V\sum_{i=1}^{N}S_i\right)$，最坏可写为 $O(NVS)$，其中 `S` 是单组物品数量上限。
- 空间复杂度：$O(V+S)$。
