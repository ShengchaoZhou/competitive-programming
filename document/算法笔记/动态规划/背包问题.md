# 背包问题

背包动态规划用于在容量有限且物品选择规则不同的条件下，求不超过容量时能够获得的最大总价值。

## [AcWing 2. 01背包问题](https://www.acwing.com/problem/content/2/)

### 题目描述

有一个容量为 `V` 的背包和 `N` 件物品，每件物品至多选择一次；第 `i` 件物品的体积为 `v_i`，价值为 `w_i`，求所选物品总体积不超过 `V` 时能够得到的最大总价值。

**输入格式**

- 第一行包含两个整数 `N` 和 `V`，分别表示物品数量和背包容量。
- 接下来 `N` 行，每行包含两个整数 `v_i` 和 `w_i`，分别表示第 `i` 件物品的体积和价值。

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N, V ≤ 1000`
- `0 < v_i, w_i ≤ 1000`

**输入样例**

```text
4 5
1 2
2 4
3 4
4 5
```

**输出样例**

```text
8
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int itemCount = scanner.nextInt();
        int capacity = scanner.nextInt();
        int[] best = new int[capacity + 1];

        for (int i = 0; i < itemCount; i++) {
            int volume = scanner.nextInt();
            int value = scanner.nextInt();

            for (int current = capacity; current >= volume; current--) {
                best[current] = Math.max(best[current], best[current - volume] + value);
            }
        }

        System.out.println(best[capacity]);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(NV)$。
- 空间复杂度：$O(V)$。

## [AcWing 3. 完全背包问题](https://www.acwing.com/problem/content/3/)

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N, V ≤ 1000`
- `0 < v_i, w_i ≤ 1000`

**输入样例**

```text
4 5
1 2
2 4
3 4
4 5
```

**输出样例**

```text
10
```

## [AcWing 4. 多重背包问题 I](https://www.acwing.com/problem/content/4/)

### 题目描述

有一个容量为 `V` 的背包和 `N` 种物品，第 `i` 种物品最多可以选择 `s_i` 件，每件体积为 `v_i`、价值为 `w_i`；求所选物品总体积不超过 `V` 时能够得到的最大总价值。

**输入格式**

- 第一行包含两个整数 `N` 和 `V`，分别表示物品种数和背包容量。
- 接下来 `N` 行，每行包含三个整数 `v_i`、`w_i` 和 `s_i`，分别表示第 `i` 种物品单件的体积、价值和可用数量。

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N, V ≤ 100`
- `0 < v_i, w_i, s_i ≤ 100`

**输入样例**

```text
4 5
1 2 3
2 4 1
3 4 3
4 5 2
```

**输出样例**

```text
10
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int typeCount = scanner.nextInt();
        int capacity = scanner.nextInt();
        int[] best = new int[capacity + 1];

        for (int i = 0; i < typeCount; i++) {
            int volume = scanner.nextInt();
            int value = scanner.nextInt();
            int available = scanner.nextInt();

            for (int current = capacity; current >= volume; current--) {
                for (int count = 1; count <= available && count * volume <= current; count++) {
                    best[current] = Math.max(
                            best[current],
                            best[current - count * volume] + count * value
                    );
                }
            }
        }

        System.out.println(best[capacity]);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(NVS)$，其中 `S` 是单种物品数量上限。
- 空间复杂度：$O(V)$。

## [AcWing 5. 多重背包问题 II](https://www.acwing.com/problem/content/5/)

### 题目描述

有一个容量为 `V` 的背包和 `N` 种物品，第 `i` 种物品最多可以选择 `s_i` 件，每件体积为 `v_i`、价值为 `w_i`；求所选物品总体积不超过 `V` 时能够得到的最大总价值。

**输入格式**

- 第一行包含两个整数 `N` 和 `V`，分别表示物品种数和背包容量。
- 接下来 `N` 行，每行包含三个整数 `v_i`、`w_i` 和 `s_i`，分别表示第 `i` 种物品单件的体积、价值和可用数量。

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N ≤ 1000`
- `0 < V ≤ 2000`
- `0 < v_i, w_i, s_i ≤ 2000`

本题要求使用多重背包的二进制优化方法。

**输入样例**

```text
4 5
1 2 3
2 4 1
3 4 3
4 5 2
```

**输出样例**

```text
10
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int typeCount = scanner.nextInt();
        int capacity = scanner.nextInt();
        int[] best = new int[capacity + 1];

        for (int i = 0; i < typeCount; i++) {
            int unitVolume = scanner.nextInt();
            int unitValue = scanner.nextInt();
            int remaining = scanner.nextInt();

            for (int bundleSize = 1; remaining > 0; bundleSize <<= 1) {
                int used = Math.min(bundleSize, remaining);
                int bundleVolume = used * unitVolume;
                int bundleValue = used * unitValue;

                for (int current = capacity; current >= bundleVolume; current--) {
                    best[current] = Math.max(
                            best[current],
                            best[current - bundleVolume] + bundleValue
                    );
                }
                remaining -= used;
            }
        }

        System.out.println(best[capacity]);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O\!\left(V\sum_{i=1}^{N}\log(s_i+1)\right)$，最坏可写为 $O(NV\log S)$，其中 `S` 是单种物品数量上限。
- 空间复杂度：$O(V)$。

## [AcWing 9. 分组背包问题](https://www.acwing.com/problem/content/9/)

### 题目描述

有一个容量为 `V` 的背包和 `N` 组物品，每组内有若干件物品，同一组至多选择一件；第 `i` 组第 `j` 件物品的体积为 `v_ij`、价值为 `w_ij`，求所选物品总体积不超过 `V` 时能够得到的最大总价值。

**输入格式**

- 第一行包含两个整数 `N` 和 `V`，分别表示物品组数和背包容量。
- 随后依次给出 `N` 组数据：每组第一行包含整数 `S_i`，表示该组的物品数量；接下来 `S_i` 行，每行包含两个整数 `v_ij` 和 `w_ij`，分别表示该件物品的体积和价值。

**输出格式**

输出一个整数，表示能够获得的最大总价值。

**数据范围**

- `0 < N, V ≤ 100`
- `0 < S_i ≤ 100`
- `0 < v_ij, w_ij ≤ 100`

**输入样例**

```text
3 5
2
1 2
2 4
1
3 4
1
4 5
```

**输出样例**

```text
8
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int groupCount = scanner.nextInt();
        int capacity = scanner.nextInt();
        int[] best = new int[capacity + 1];

        for (int group = 0; group < groupCount; group++) {
            int itemCount = scanner.nextInt();
            int[] volumes = new int[itemCount];
            int[] values = new int[itemCount];

            for (int i = 0; i < itemCount; i++) {
                volumes[i] = scanner.nextInt();
                values[i] = scanner.nextInt();
            }

            for (int current = capacity; current >= 0; current--) {
                for (int i = 0; i < itemCount; i++) {
                    if (volumes[i] <= current) {
                        best[current] = Math.max(
                                best[current],
                                best[current - volumes[i]] + values[i]
                        );
                    }
                }
            }
        }

        System.out.println(best[capacity]);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O\!\left(V\sum_{i=1}^{N}S_i\right)$，最坏可写为 $O(NVS)$，其中 `S` 是单组物品数量上限。
- 空间复杂度：$O(V+S)$。
