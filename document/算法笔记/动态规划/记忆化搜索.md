# 记忆化搜索

记忆化搜索用于在有重复子问题的搜索中缓存已计算状态，避免重复遍历并快速得到每个状态的结果。

## [AcWing 901. 滑雪](https://www.acwing.com/problem/content/903/)

### 题目描述

给定一个 $R$ 行 $C$ 列的高度矩阵，表示一片矩形滑雪场。滑雪者可以从任意格子出发，每次向上、下、左、右的相邻格子移动，但只能滑向严格更低的位置。请求一条合法滑雪路线最多能经过多少个格子。

**输入格式**

- 第一行包含两个整数 `R` 和 `C`。
- 接下来 `R` 行，每行包含 `C` 个整数，表示滑雪场各个格子的高度。

**输出格式**

输出一个整数，表示最长合法滑雪路线经过的格子数。

**数据范围**

- $1 \le R,C \le 300$
- $0 \le \text{格子高度} \le 10000$

**输入样例**

```text
5 5
1 2 3 4 5
16 17 18 19 6
15 24 25 20 7
14 23 22 21 8
13 12 11 10 9
```

**输出样例**

```text
25
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static final int[] ROW_OFFSET = {-1, 1, 0, 0};
    private static final int[] COLUMN_OFFSET = {0, 0, -1, 1};

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);
        int rowCount = scanner.nextInt();
        int columnCount = scanner.nextInt();
        int cellCount = rowCount * columnCount;
        int[] height = new int[cellCount];

        for (int cell = 0; cell < cellCount; cell++) {
            height[cell] = scanner.nextInt();
        }

        int[] memo = new int[cellCount];
        int[] cellStack = new int[cellCount];
        int[] directionStack = new int[cellCount];
        int answer = 0;

        for (int start = 0; start < cellCount; start++) {
            if (memo[start] == 0) {
                evaluate(start, rowCount, columnCount, height, memo,
                        cellStack, directionStack);
            }
            answer = Math.max(answer, memo[start]);
        }

        System.out.println(answer);
    }

    private static void evaluate(
            int start,
            int rowCount,
            int columnCount,
            int[] height,
            int[] memo,
            int[] cellStack,
            int[] directionStack
    ) {
        int top = 0;
        cellStack[0] = start;
        directionStack[0] = 0;

        while (top >= 0) {
            int cell = cellStack[top];
            int row = cell / columnCount;
            int column = cell % columnCount;

            if (directionStack[top] < 4) {
                int direction = directionStack[top]++;
                int nextRow = row + ROW_OFFSET[direction];
                int nextColumn = column + COLUMN_OFFSET[direction];

                if (nextRow < 0 || nextRow >= rowCount
                        || nextColumn < 0 || nextColumn >= columnCount) {
                    continue;
                }

                int nextCell = nextRow * columnCount + nextColumn;
                if (height[nextCell] < height[cell] && memo[nextCell] == 0) {
                    top++;
                    cellStack[top] = nextCell;
                    directionStack[top] = 0;
                }
            } else {
                int best = 1;
                for (int direction = 0; direction < 4; direction++) {
                    int nextRow = row + ROW_OFFSET[direction];
                    int nextColumn = column + COLUMN_OFFSET[direction];
                    if (nextRow < 0 || nextRow >= rowCount
                            || nextColumn < 0 || nextColumn >= columnCount) {
                        continue;
                    }

                    int nextCell = nextRow * columnCount + nextColumn;
                    if (height[nextCell] < height[cell]) {
                        best = Math.max(best, memo[nextCell] + 1);
                    }
                }
                memo[cell] = best;
                top--;
            }
        }
    }

}
```

### 时空复杂度

- 时间复杂度：$O(RC)$，每个格子的结果只计算一次，并且只检查四个方向。
- 空间复杂度：$O(RC)$，用于保存高度、记忆化结果与显式搜索栈。
