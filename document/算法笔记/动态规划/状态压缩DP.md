# 状态压缩 DP

当集合规模较小时，用整数二进制位表示集合，枚举状态与合法转移，解决覆盖、访问顺序和轮廓衔接问题。

## 集合状态

集合状态适合区分哪些元素已经被使用，但仅有集合可能不足以确定后续选择，常需额外记录终点等信息。

### 经过每个点一次的最短路

令 f[mask][j] 为访问集合恰好为 mask、终点为 j 的最小路程。去掉 j 后枚举前一个点 i，转移 f[mask without j][i]+w[i][j]；只初始化从起点出发的状态。时间 O(n²2ⁿ)，空间 O(n2ⁿ)。

- [AcWing 91. 最短Hamilton路径](https://www.acwing.com/problem/content/93/) （AcWing基础课）：固定从 0 出发并在 n-1 结束，最终取全体顶点已访问的对应状态。

## 轮廓状态

将相邻两行或两列之间的连接关系编码成掩码，只保留尚未与未来部分衔接完成的信息。

### 矩形铺满计数

按列扫描，前一列伸入与当前列伸出的水平骨牌不能重叠；剩余竖直空段的长度必须为偶数。预处理合法掩码与相邻列兼容关系，初始与结束的外部掩码均为 0。直接枚举掩码对为 O(m·4ⁿ)，预计算兼容关系可以减少实际转移。

- [AcWing 291. 蒙德里安的梦想](https://www.acwing.com/problem/content/293/) （AcWing基础课）：用较短边作为掩码宽度，枚举不重叠且剩余连续空位长度为偶数的连接状态。
