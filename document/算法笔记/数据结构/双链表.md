# 双链表

双链表为每个节点维护前驱和后继，适合在已知节点处完成常数时间的删除、插入和移动。通过哈希表定位节点后，还能支持缓存淘汰等按访问顺序调整的操作。

## 双向连接

设置首尾哨兵可以统一空链表、头部和尾部的边界。每次修改都要同时维护前驱的 next 和后继的 prev，查询任意位置仍需线性遍历。

### 数组模拟与两侧插入

设节点 x 插入在 a 和 b 之间，需要连接 a → x → b 及其反向连接；删除 x 时直接连接它的前驱与后继。数组下标代表插入编号，不能当作当前位置。单次操作 O(1)，总存储 O(n)。

- [AcWing 827. 双链表](https://www.acwing.com/problem/content/829/) （AcWing基础课）：维护左右指针，支持两端插入、指定节点左右插入和删除。

## 缓存淘汰

用哈希表把键映射到链表节点，访问后通过常数时间的摘除与插入维护顺序。哈希查询的复杂度按平均 O(1) 计算。

### 最近最少使用缓存

哈希表定位键，双链表按最近访问顺序排列。读取已有键、更新已有键时都移到最近使用端；插入超出容量时删除最久未使用端，并同步删除映射。每次 get、put 平均 O(1)，空间 O(capacity)。

- [LeetCode 146. LRU 缓存](https://leetcode.cn/problems/lru-cache/) （Hot100/面试150/CodeTop200）：哈希表定位节点，双链表维护最近访问顺序，淘汰最久未使用节点。

### 最不经常使用缓存

维护键到节点、频率到双链表的映射，并记录最小频率 minFreq。读取已有键、通过 put 更新已有键都算一次访问，将节点从频率 f 的链表移到 f+1 的最近使用端；如果 f==minFreq 且旧链表变空，就令 minFreq++。

容量已满时，从 minFreq 对应链表淘汰最久未使用的节点。插入新节点后将其频率和 minFreq 都设为 1；容量为 0 时直接返回。每次操作平均 O(1)，空间 O(capacity)。

- [LeetCode 460. LFU 缓存](https://leetcode.cn/problems/lfu-cache/) （CodeTop200）：按频率分桶，同频率节点按使用时间排列，以最小频率与最久未使用规则淘汰。
