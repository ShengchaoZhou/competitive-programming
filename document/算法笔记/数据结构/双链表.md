# 双链表

双链表用于维护可以向左右两个方向遍历、并能在已知节点两侧高效插入或删除元素的线性序列。

## [AcWing 827. 双链表](https://www.acwing.com/problem/content/829/)

### 题目描述

维护一个初始为空的双链表，并依次执行 $M$ 个操作，最后从左到右输出链表中的所有元素。

支持以下操作：

- `L x`：在链表最左端插入数 $x$。
- `R x`：在链表最右端插入数 $x$。
- `D k`：删除第 $k$ 个插入的节点。
- `IL k x`：在第 $k$ 个插入的节点左侧插入数 $x$。
- `IR k x`：在第 $k$ 个插入的节点右侧插入数 $x$。

这里的“第 $k$ 个插入的节点”按插入时间编号，与该节点当前位于链表中的位置无关。

**输入格式**

第一行包含整数 $M$，表示操作次数。

接下来 $M$ 行，每行包含一个上述操作命令。

**输出格式**

输出一行，按从左到右的顺序输出链表中的所有元素。

**数据范围**

- $1 \le M \le 10^5$
- 所有操作均保证合法。

**输入样例**

```text
10
R 7
D 1
L 3
IL 2 10
D 3
IL 2 7
L 8
R 9
IL 4 7
IR 2 2
```

**输出样例**

```text
8 7 7 3 2 9
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    private static int[] values;
    private static int[] left;
    private static int[] right;
    private static int index = 2;

    private static void addAfter(int node, int value) {
        values[index] = value;
        left[index] = node;
        right[index] = right[node];
        left[right[node]] = index;
        right[node] = index++;
    }

    private static void remove(int node) {
        right[left[node]] = right[node];
        left[right[node]] = left[node];
    }

    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int operationCount = scanner.nextInt();
        values = new int[operationCount + 2];
        left = new int[operationCount + 2];
        right = new int[operationCount + 2];

        right[0] = 1;
        left[1] = 0;

        for (int i = 0; i < operationCount; i++) {
            String operation = scanner.next();
            if (operation.equals("L")) {
                addAfter(0, scanner.nextInt());
            } else if (operation.equals("R")) {
                addAfter(left[1], scanner.nextInt());
            } else if (operation.equals("D")) {
                remove(scanner.nextInt() + 1);
            } else if (operation.equals("IL")) {
                int k = scanner.nextInt() + 1;
                addAfter(left[k], scanner.nextInt());
            } else {
                int k = scanner.nextInt() + 1;
                addAfter(k, scanner.nextInt());
            }
        }

        StringBuilder answer = new StringBuilder();
        for (int node = right[0]; node != 1; node = right[node]) {
            if (answer.length() > 0) {
                answer.append(' ');
            }
            answer.append(values[node]);
        }
        System.out.println(answer);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        String next() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            StringBuilder token = new StringBuilder();
            while (c > ' ') {
                token.append((char) c);
                c = read();
            }
            return token.toString();
        }

        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(M+L)$，每次操作为 $O(1)$，最后遍历长度为 $L$ 的链表。
- 空间复杂度：$O(M)$，用于保存至多 $M$ 个插入节点。
