# 哈希表

哈希表用于将键映射到存储位置，以接近常数时间完成集合查询，或把字符串前缀编码成哈希值以快速比较子串。

## [AcWing 840. 模拟散列表](https://www.acwing.com/problem/content/842/)

### 题目描述

维护一个整数集合，支持插入一个整数和查询一个整数是否已经存在于集合中。

**输入格式**

- 第一行包含整数 `N`，表示操作数量。
- 接下来 `N` 行，每行包含一条操作：
  - `I x`：将整数 `x` 插入集合；
  - `Q x`：询问整数 `x` 是否在集合中出现过。

**输出格式**

每个查询操作输出一行；若 `x` 存在则输出 `Yes`，否则输出 `No`。

**数据范围**

- $1 \le N \le 10^5$
- $-10^9 \le x \le 10^9$

**输入样例**

```text
5
I 1
I 2
I 3
Q 2
Q 5
```

**输出样例**

```text
Yes
No
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static final int MOD = 100003;
    private static final int[] head = new int[MOD];
    private static int[] value;
    private static int[] next;
    private static int index;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int operationCount = scanner.nextInt();

        Arrays.fill(head, -1);
        value = new int[operationCount];
        next = new int[operationCount];

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < operationCount; i++) {
            String operation = scanner.next();
            int x = scanner.nextInt();

            if (operation.charAt(0) == 'I') {
                insert(x);
            } else {
                answer.append(contains(x) ? "Yes" : "No").append('\n');
            }
        }

        System.out.print(answer);
    }

    private static void insert(int x) {
        int bucket = bucketOf(x);
        value[index] = x;
        next[index] = head[bucket];
        head[bucket] = index++;
    }

    private static boolean contains(int x) {
        int bucket = bucketOf(x);
        for (int i = head[bucket]; i != -1; i = next[i]) {
            if (value[i] == x) return true;
        }
        return false;
    }

    private static int bucketOf(int x) {
        return (x % MOD + MOD) % MOD;
    }

}
```

### 时空复杂度

- 时间复杂度：使用拉链法后，单次插入或查询的平均时间复杂度为 $O(1)$，最坏为 $O(N)$；全部操作的平均时间复杂度为 $O(N)$。
- 空间复杂度：$O(N)$。

## [AcWing 841. 字符串哈希](https://www.acwing.com/problem/content/843/)

### 题目描述

给定一个长度为 `N` 的字符串，再给出 `M` 组询问。每组询问包含两段子串的左右端点，需要判断这两段子串是否完全相同。

**输入格式**

- 第一行包含整数 `N` 和 `M`，分别表示字符串长度和询问数量。
- 第二行包含一个长度为 `N` 的字符串，字符串由大小写英文字母和数字组成。
- 接下来 `M` 行，每行包含四个整数 `l1 r1 l2 r2`，表示比较子串 `[l1, r1]` 与 `[l2, r2]`。下标从 `1` 开始。

**输出格式**

每组询问输出一行；若两段子串相同则输出 `Yes`，否则输出 `No`。

**数据范围**

- $1 \le N,M \le 10^5$

**输入样例**

```text
8 3
aabbaabb
1 3 5 7
1 3 6 8
1 2 1 2
```

**输出样例**

```text
Yes
No
Yes
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static final long BASE = 131L;
    private static long[] prefixHash;
    private static long[] power;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int queryCount = scanner.nextInt();
        String text = scanner.next();

        prefixHash = new long[n + 1];
        power = new long[n + 1];
        power[0] = 1;

        for (int i = 1; i <= n; i++) {
            prefixHash[i] = prefixHash[i - 1] * BASE + text.charAt(i - 1);
            power[i] = power[i - 1] * BASE;
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < queryCount; i++) {
            int left1 = scanner.nextInt();
            int right1 = scanner.nextInt();
            int left2 = scanner.nextInt();
            int right2 = scanner.nextInt();

            boolean sameLength = right1 - left1 == right2 - left2;
            boolean sameHash = hashOf(left1, right1) == hashOf(left2, right2);
            answer.append(sameLength && sameHash ? "Yes" : "No").append('\n');
        }

        System.out.print(answer);
    }

    private static long hashOf(int left, int right) {
        return prefixHash[right] - prefixHash[left - 1] * power[right - left + 1];
    }

}
```

### 时空复杂度

- 时间复杂度：预处理为 $O(N)$，每次询问为 $O(1)$，总时间复杂度为 $O(N+M)$。
- 空间复杂度：$O(N)$。
