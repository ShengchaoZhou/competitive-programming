# 堆

堆用于在动态集合中快速取得并删除最小值或最大值，配合位置映射还可以高效删除、修改指定的已插入元素。

## [AcWing 838. 堆排序](https://www.acwing.com/problem/content/840/)

### 题目描述

给定一个长度为 $n$ 的整数数列，请按从小到大的顺序输出其中最小的 $m$ 个数。

**输入格式**

- 第一行包含两个整数 $n$ 和 $m$。
- 第二行包含 $n$ 个整数，表示给定数列。

**输出格式**

在一行中输出 $m$ 个整数，依次为数列中最小的 $m$ 个数，数字之间用空格分隔。

**数据范围**

- $1\le m\le n\le 10^5$
- $1\le$ 数列中的元素 $\le 10^9$

**输入样例**

```text
5 3
4 5 1 3 2
```

**输出样例**

```text
1 2 3
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    private static int[] heap;
    private static int heapSize;

    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int n = scanner.nextInt();
        int outputCount = scanner.nextInt();

        heap = new int[n + 1];
        heapSize = n;
        for (int i = 1; i <= n; i++) {
            heap[i] = scanner.nextInt();
        }

        for (int i = heapSize / 2; i >= 1; i--) {
            down(i);
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < outputCount; i++) {
            if (i > 0) {
                answer.append(' ');
            }
            answer.append(heap[1]);
            heap[1] = heap[heapSize--];
            if (heapSize > 0) {
                down(1);
            }
        }

        System.out.println(answer);
    }

    private static void down(int index) {
        while (true) {
            int smallest = index;
            int leftChild = index * 2;
            int rightChild = leftChild + 1;

            if (leftChild <= heapSize && heap[leftChild] < heap[smallest]) {
                smallest = leftChild;
            }
            if (rightChild <= heapSize && heap[rightChild] < heap[smallest]) {
                smallest = rightChild;
            }
            if (smallest == index) {
                return;
            }

            int temp = heap[index];
            heap[index] = heap[smallest];
            heap[smallest] = temp;
            index = smallest;
        }
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：自底向上建堆为 $O(n)$，输出 $m$ 个数为 $O(m\log n)$，总计 $O(n+m\log n)$。
- 空间复杂度：$O(n)$，用于保存小根堆。

## [AcWing 839. 模拟堆](https://www.acwing.com/problem/content/841/)

### 题目描述

维护一个初始为空的整数集合，依次执行 $N$ 条指令。指令共有五种：

- `I x`：向集合中插入整数 $x$；
- `PM`：输出当前集合的最小值；
- `DM`：删除当前集合的最小值，数据保证此时最小值唯一；
- `D k`：删除第 $k$ 次插入的数；
- `C k x`：把第 $k$ 次插入的数修改为 $x$。

这里的 $k$ 按插入操作出现的先后顺序编号，与全部指令的行号无关。

**输入格式**

- 第一行包含整数 $N$，表示操作数量。
- 接下来 $N$ 行，每行包含一条 `I x`、`PM`、`DM`、`D k` 或 `C k x` 指令。

**输出格式**

对于每条 `PM` 指令输出一行，表示执行该指令时集合中的最小值。

**数据范围**

- $1\le N\le 10^5$
- $-10^9\le x\le 10^9$
- 所有指令均合法。

**输入样例**

```text
8
I -10
PM
I -10
D 1
C 2 8
I 6
PM
DM
```

**输出样例**

```text
-10
6
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    private static int[] heap;
    private static int[] insertionToHeap;
    private static int[] heapToInsertion;
    private static int heapSize;
    private static int insertionCount;

    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int operationCount = scanner.nextInt();

        heap = new int[operationCount + 1];
        insertionToHeap = new int[operationCount + 1];
        heapToInsertion = new int[operationCount + 1];

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < operationCount; i++) {
            String operation = scanner.next();

            if (operation.equals("I")) {
                int value = scanner.nextInt();
                insertionCount++;
                heapSize++;
                heap[heapSize] = value;
                insertionToHeap[insertionCount] = heapSize;
                heapToInsertion[heapSize] = insertionCount;
                up(heapSize);
            } else if (operation.equals("PM")) {
                answer.append(heap[1]).append('\n');
            } else if (operation.equals("DM")) {
                deleteAt(1);
            } else if (operation.equals("D")) {
                int insertionNumber = scanner.nextInt();
                deleteAt(insertionToHeap[insertionNumber]);
            } else {
                int insertionNumber = scanner.nextInt();
                int newValue = scanner.nextInt();
                int heapIndex = insertionToHeap[insertionNumber];
                heap[heapIndex] = newValue;
                up(heapIndex);
                down(heapIndex);
            }
        }

        System.out.print(answer);
    }

    private static void deleteAt(int heapIndex) {
        swapHeapNodes(heapIndex, heapSize);
        int removedInsertion = heapToInsertion[heapSize];
        insertionToHeap[removedInsertion] = 0;
        heapSize--;

        if (heapIndex <= heapSize) {
            up(heapIndex);
            down(heapIndex);
        }
    }

    private static void up(int index) {
        while (index > 1 && heap[index] < heap[index / 2]) {
            swapHeapNodes(index, index / 2);
            index /= 2;
        }
    }

    private static void down(int index) {
        while (true) {
            int smallest = index;
            int leftChild = index * 2;
            int rightChild = leftChild + 1;

            if (leftChild <= heapSize && heap[leftChild] < heap[smallest]) {
                smallest = leftChild;
            }
            if (rightChild <= heapSize && heap[rightChild] < heap[smallest]) {
                smallest = rightChild;
            }
            if (smallest == index) {
                return;
            }

            swapHeapNodes(index, smallest);
            index = smallest;
        }
    }

    private static void swapHeapNodes(int first, int second) {
        int value = heap[first];
        heap[first] = heap[second];
        heap[second] = value;

        int insertionNumber = heapToInsertion[first];
        heapToInsertion[first] = heapToInsertion[second];
        heapToInsertion[second] = insertionNumber;

        insertionToHeap[heapToInsertion[first]] = first;
        insertionToHeap[heapToInsertion[second]] = second;
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        private String next() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            StringBuilder token = new StringBuilder();
            while (c > ' ') {
                token.append((char) c);
                c = read();
            }
            return token.toString();
        }

        private int nextInt() throws IOException {
            return Integer.parseInt(next());
        }
    }
}
```

### 时空复杂度

- 时间复杂度：`PM` 为 $O(1)$；`I`、`DM`、`D`、`C` 均为 $O(\log N)$，全部操作最坏为 $O(N\log N)$。
- 空间复杂度：$O(N)$，用于保存堆以及插入编号与堆下标之间的双向映射。
