# 队列

队列用于处理元素按先进先出顺序到达和离开的线性序列。

## [AcWing 829. 模拟队列](https://www.acwing.com/problem/content/831/)

### 题目描述

维护一个初始为空的队列，并依次执行 $M$ 个操作。

支持以下操作：

- `push x`：把数 $x$ 插入队尾。
- `pop`：弹出队头元素。
- `empty`：判断队列是否为空。
- `query`：查询队头元素。

每个 `empty` 和 `query` 操作都需要输出查询结果。

**输入格式**

第一行包含整数 $M$，表示操作次数。

接下来 $M$ 行，每行包含一个上述操作命令。

**输出格式**

每个 `empty` 或 `query` 操作输出一行结果。

对于 `empty` 操作，队列为空时输出 `YES`，否则输出 `NO`；对于 `query` 操作，输出当前队头元素。

**数据范围**

- $1 \le M \le 10^5$
- $1 \le x \le 10^9$
- 所有操作均保证合法。

**输入样例**

```text
10
push 6
empty
query
pop
empty
push 3
push 4
pop
query
push 6
```

**输出样例**

```text
NO
6
YES
4
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int operationCount = scanner.nextInt();
        int[] queue = new int[operationCount];
        int head = 0;
        int tail = 0;
        StringBuilder answer = new StringBuilder();

        for (int i = 0; i < operationCount; i++) {
            String operation = scanner.next();
            if (operation.equals("push")) {
                queue[tail++] = scanner.nextInt();
            } else if (operation.equals("pop")) {
                head++;
            } else if (operation.equals("empty")) {
                answer.append(head == tail ? "YES" : "NO").append('\n');
            } else {
                answer.append(queue[head]).append('\n');
            }
        }

        System.out.print(answer);
    }

}
```

### 时空复杂度

- 时间复杂度：$O(M)$，每次队列操作均为 $O(1)$。
- 空间复杂度：$O(M)$，数组最多保存 $M$ 个入队元素。
