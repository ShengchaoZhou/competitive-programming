# 单调栈

单调栈用于在线性扫描中寻找每个元素某一侧距离最近且满足指定大小关系的元素。

## [AcWing 830. 单调栈](https://www.acwing.com/problem/content/832/)

### 题目描述

给定一个长度为 $N$ 的整数序列。对于序列中的每个数，找出它左侧距离它最近且严格小于它的数；如果不存在这样的数，则用 $-1$ 表示。

**输入格式**

第一行包含一个整数 $N$，表示序列长度。

第二行包含 $N$ 个整数，表示给定序列。

**输出格式**

输出一行 $N$ 个整数，第 $i$ 个整数表示第 $i$ 个数左侧最近的、严格小于它的数；不存在时输出 $-1$。

**数据范围**

- $1 \le N \le 10^5$
- $1 \le a_i \le 10^9$

**输入样例**

```text
5
3 4 2 7 5
```

**输出样例**

```text
-1 3 -1 2 2
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int n = scanner.nextInt();
        int[] stack = new int[n];
        int top = 0;
        StringBuilder answer = new StringBuilder();

        for (int i = 0; i < n; i++) {
            int value = scanner.nextInt();
            while (top > 0 && stack[top - 1] >= value) {
                top--;
            }

            if (i > 0) answer.append(' ');
            answer.append(top == 0 ? -1 : stack[top - 1]);
            stack[top++] = value;
        }

        System.out.println(answer);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) return -1;
            }
            return buffer[pointer++];
        }

        private int nextInt() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            int sign = 1;
            if (c == '-') {
                sign = -1;
                c = read();
            }

            int value = 0;
            while (c > ' ') {
                value = value * 10 + c - '0';
                c = read();
            }
            return value * sign;
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(N)$，每个数最多入栈一次、出栈一次。
- 空间复杂度：$O(N)$，用于保存单调栈和输出结果。
