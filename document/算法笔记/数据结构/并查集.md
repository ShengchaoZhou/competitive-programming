# 并查集

并查集维护动态合并的集合，适合连通性、集合大小和元素间相对关系。find 查询根节点，union 只合并不同的根；路径压缩配合按大小或秩合并，m 次操作总时间 O(mα(n))，存储 O(n)。

## 集合合并

初始时每个元素单独成集。路径压缩把查询路径连接到根；按大小合并时让小集合的根连接到大集合的根，减少树高。

### 连通性查询

判断 find(a) 与 find(b) 是否相同。合并前再次确认根不同，避免重复合并引起集合数量或统计值错误；该结构适合加边，不能直接支持任意删边。

- [AcWing 836. 合并集合](https://www.acwing.com/problem/content/838/) （AcWing基础课）

### 维护连通块大小

size 只在根节点保存有效值，合并两个不同集合时将大小相加；查询节点所在集合的大小必须先求根。

- [AcWing 837. 连通块中点的数量](https://www.acwing.com/problem/content/839/) （AcWing基础课）：合并连通块，同时支持是否连通和连通块点数的查询。

## 带权并查集

除父指针外，为每个节点维护到父节点的相对关系；路径压缩时把沿途关系累积成到根的关系。权值可以是距离、模关系或比例。

### 模关系与矛盾检测

食物链可令 d[x] = type[x]-type[parent[x]] (mod 3)，规定 type[x]-type[y] = 1 表示 x 吃 y。压缩后，若根相同，检查 d[x]-d[y] 是否等于给定关系 r；若把根 rx 接到 ry，则设 d[rx] = r-d[x]+d[y] (mod 3)。反向合并时相应取反，并把负余数归一化到 0..2。

- [AcWing 240. 食物链](https://www.acwing.com/problem/content/242/) （AcWing基础课）：先排除越界编号和自己吃自己的陈述；矛盾陈述不改变已有关系。
