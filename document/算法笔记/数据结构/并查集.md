# 并查集

并查集用于动态合并若干元素所属的集合，并高效判断两个元素是否属于同一集合，还可以在集合根节点上维护大小或元素间关系等附加信息。

## [AcWing 836. 合并集合](https://www.acwing.com/problem/content/838/)

### 题目描述

有 $n$ 个编号为 $1\sim n$ 的数，初始时每个数各自属于一个集合。接下来执行 $m$ 次操作：`M a b` 表示合并 $a$、$b$ 所在的集合，若它们已经在同一集合中则不做处理；`Q a b` 表示询问 $a$、$b$ 是否属于同一集合。

**输入格式**

- 第一行包含两个整数 $n$ 和 $m$，分别表示元素数量和操作数量。
- 接下来 $m$ 行，每行是 `M a b` 或 `Q a b`，其中 $a$、$b$ 均为元素编号。

**输出格式**

对于每个 `Q a b` 操作输出一行：若 $a$、$b$ 在同一集合中，输出 `Yes`，否则输出 `No`。

**数据范围**

- $1\le n,m\le 10^5$
- $1\le a,b\le n$

**输入样例**

```text
4 5
M 1 2
M 3 4
Q 1 2
Q 1 3
Q 3 4
```

**输出样例**

```text
Yes
No
Yes
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static int[] parent;
    private static int[] setSize;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int operationCount = scanner.nextInt();

        parent = new int[n + 1];
        setSize = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
            setSize[i] = 1;
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < operationCount; i++) {
            String operation = scanner.next();
            int a = scanner.nextInt();
            int b = scanner.nextInt();

            if (operation.charAt(0) == 'M') {
                union(a, b);
            } else {
                answer.append(find(a) == find(b) ? "Yes" : "No").append('\n');
            }
        }

        System.out.print(answer);
    }

    private static int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    private static void union(int a, int b) {
        int rootA = find(a);
        int rootB = find(b);
        if (rootA == rootB) {
            return;
        }

        if (setSize[rootA] < setSize[rootB]) {
            int temp = rootA;
            rootA = rootB;
            rootB = temp;
        }
        parent[rootB] = rootA;
        setSize[rootA] += setSize[rootB];
    }

}
```

### 时空复杂度

- 时间复杂度：初始化为 $O(n)$；使用路径压缩和按集合大小合并后，$m$ 次操作共为 $O(m\alpha(n))$，其中 $\alpha$ 是反阿克曼函数。
- 空间复杂度：$O(n)$，用于保存每个元素的父节点和集合大小。

## [AcWing 837. 连通块中点的数量](https://www.acwing.com/problem/content/839/)

### 题目描述

给定一个含有 $n$ 个点、初始没有边的无向图，点的编号为 $1\sim n$。需要依次完成 $m$ 个操作：`C a b` 在 $a$、$b$ 之间连边；`Q1 a b` 询问两点是否位于同一连通块；`Q2 a` 询问点 $a$ 所在连通块的点数。连边操作与查询操作中的两个点可以相同。

**输入格式**

- 第一行包含两个整数 $n$ 和 $m$，分别表示点数和操作数。
- 接下来 $m$ 行，每行是 `C a b`、`Q1 a b` 或 `Q2 a` 三种指令之一。

**输出格式**

- 对于每个 `Q1 a b`，若两点在同一连通块中则输出 `Yes`，否则输出 `No`。
- 对于每个 `Q2 a`，输出点 $a$ 所在连通块包含的点数。
- 每个查询结果占一行。

**数据范围**

- $1\le n,m\le 10^5$
- 操作中出现的点编号均在 $1\sim n$ 内。

**输入样例**

```text
5 5
C 1 2
Q1 1 2
Q2 1
C 2 5
Q2 5
```

**输出样例**

```text
Yes
2
3
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static int[] parent;
    private static int[] componentSize;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int n = scanner.nextInt();
        int operationCount = scanner.nextInt();

        parent = new int[n + 1];
        componentSize = new int[n + 1];
        for (int i = 1; i <= n; i++) {
            parent[i] = i;
            componentSize[i] = 1;
        }

        StringBuilder answer = new StringBuilder();
        for (int i = 0; i < operationCount; i++) {
            String operation = scanner.next();
            int a = scanner.nextInt();

            if (operation.equals("C")) {
                int b = scanner.nextInt();
                union(a, b);
            } else if (operation.equals("Q1")) {
                int b = scanner.nextInt();
                answer.append(find(a) == find(b) ? "Yes" : "No").append('\n');
            } else {
                answer.append(componentSize[find(a)]).append('\n');
            }
        }

        System.out.print(answer);
    }

    private static int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    private static void union(int a, int b) {
        int rootA = find(a);
        int rootB = find(b);
        if (rootA == rootB) {
            return;
        }

        if (componentSize[rootA] < componentSize[rootB]) {
            int temp = rootA;
            rootA = rootB;
            rootB = temp;
        }
        parent[rootB] = rootA;
        componentSize[rootA] += componentSize[rootB];
    }

}
```

### 时空复杂度

- 时间复杂度：初始化为 $O(n)$；路径压缩配合按连通块大小合并，$m$ 次操作共为 $O(m\alpha(n))$。
- 空间复杂度：$O(n)$，用于保存父节点和各连通块的点数。

## [AcWing 240. 食物链](https://www.acwing.com/problem/content/242/)

### 题目描述

动物分为 $A$、$B$、$C$ 三类，捕食关系构成环：$A$ 吃 $B$、$B$ 吃 $C$、$C$ 吃 $A$。现有 $N$ 只编号为 $1\sim N$ 的动物，但不知道每只动物的类别。有人依次给出 $K$ 句话：`1 X Y` 表示 $X$ 与 $Y$ 同类，`2 X Y` 表示 $X$ 吃 $Y$。

一句话出现以下任一情况就算假话：它与此前已经判定为真的话冲突；$X$ 或 $Y$ 的编号大于 $N$；或者它声称某只动物吃自己。假话不能成为判断后续话语的依据，请统计全部假话的数量。

**输入格式**

- 第一行包含两个整数 $N$ 和 $K$，分别表示动物数量和话语数量。
- 接下来 $K$ 行，每行包含三个正整数 $D$、$X$、$Y$。$D=1$ 表示 $X$、$Y$ 同类，$D=2$ 表示 $X$ 吃 $Y$。

**输出格式**

输出一个整数，表示 $K$ 句话中假话的总数。

**数据范围**

- $1\le N\le 50000$
- $0\le K\le 100000$
- $D\in\{1,2\}$，$X$、$Y$ 为正整数。

**输入样例**

```text
100 7
1 101 1
2 1 2
2 2 3
2 3 3
1 1 3
2 3 1
1 5 5
```

**输出样例**

```text
3
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static int[] parent;
    private static int[] setSize;
    private static int[] relationToParent;

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int animalCount = scanner.nextInt();
        int statementCount = scanner.nextInt();

        parent = new int[animalCount + 1];
        setSize = new int[animalCount + 1];
        relationToParent = new int[animalCount + 1];
        for (int i = 1; i <= animalCount; i++) {
            parent[i] = i;
            setSize[i] = 1;
        }

        int lieCount = 0;
        for (int i = 0; i < statementCount; i++) {
            int type = scanner.nextInt();
            int x = scanner.nextInt();
            int y = scanner.nextInt();

            if (x > animalCount || y > animalCount) {
                lieCount++;
                continue;
            }

            int rootX = find(x);
            int rootY = find(y);
            int requiredRelation = type == 1 ? 0 : 1;

            if (rootX == rootY) {
                if (mod3(relationToParent[x] - relationToParent[y]) != requiredRelation) {
                    lieCount++;
                }
            } else {
                union(rootX, rootY, x, y, requiredRelation);
            }
        }

        System.out.println(lieCount);
    }

    private static int find(int x) {
        if (parent[x] != x) {
            int oldParent = parent[x];
            parent[x] = find(oldParent);
            relationToParent[x] = mod3(relationToParent[x] + relationToParent[oldParent]);
        }
        return parent[x];
    }

    private static void union(int rootX, int rootY, int x, int y, int requiredRelation) {
        if (setSize[rootX] <= setSize[rootY]) {
            parent[rootX] = rootY;
            relationToParent[rootX] = mod3(
                    requiredRelation + relationToParent[y] - relationToParent[x]);
            setSize[rootY] += setSize[rootX];
        } else {
            parent[rootY] = rootX;
            relationToParent[rootY] = mod3(
                    relationToParent[x] - relationToParent[y] - requiredRelation);
            setSize[rootX] += setSize[rootY];
        }
    }

    private static int mod3(int value) {
        int remainder = value % 3;
        return remainder < 0 ? remainder + 3 : remainder;
    }

}
```

### 时空复杂度

- 时间复杂度：初始化为 $O(N)$；带权并查集使用路径压缩和按集合大小合并，处理 $K$ 句话共为 $O(K\alpha(N))$。
- 空间复杂度：$O(N)$，用于保存父节点、集合大小以及每个节点到父节点的模 $3$ 关系。
