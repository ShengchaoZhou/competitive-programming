# 栈

栈用于处理元素按后进先出顺序访问的问题，并可借助栈顶状态解析具有嵌套结构和运算优先级的表达式。

## [AcWing 828. 模拟栈](https://www.acwing.com/problem/content/830/)

### 题目描述

维护一个初始为空的栈，并依次执行 $M$ 个操作。

支持以下操作：

- `push x`：把数 $x$ 压入栈顶。
- `pop`：弹出栈顶元素。
- `empty`：判断栈是否为空。
- `query`：查询栈顶元素。

每个 `empty` 和 `query` 操作都需要输出查询结果。

**输入格式**

第一行包含整数 $M$，表示操作次数。

接下来 $M$ 行，每行包含一个上述操作命令。

**输出格式**

每个 `empty` 或 `query` 操作输出一行结果。

对于 `empty` 操作，栈为空时输出 `YES`，否则输出 `NO`；对于 `query` 操作，输出当前栈顶元素。

**数据范围**

- $1 \le M \le 10^5$
- $1 \le x \le 10^9$
- 所有操作均保证合法。

**输入样例**

```text
10
push 5
query
push 6
pop
query
pop
empty
push 4
query
empty
```

**输出样例**

```text
5
5
YES
4
NO
```

### 参考 Java 解法

```java
import java.io.BufferedInputStream;
import java.io.IOException;

public class Main {
    public static void main(String[] args) throws Exception {
        FastScanner scanner = new FastScanner();
        int operationCount = scanner.nextInt();
        int[] stack = new int[operationCount];
        int top = 0;
        StringBuilder answer = new StringBuilder();

        for (int i = 0; i < operationCount; i++) {
            String operation = scanner.next();
            if (operation.equals("push")) {
                stack[top++] = scanner.nextInt();
            } else if (operation.equals("pop")) {
                top--;
            } else if (operation.equals("empty")) {
                answer.append(top == 0 ? "YES" : "NO").append('\n');
            } else {
                answer.append(stack[top - 1]).append('\n');
            }
        }

        System.out.print(answer);
    }

    private static class FastScanner {
        private final BufferedInputStream input = new BufferedInputStream(System.in);
        private final byte[] buffer = new byte[1 << 16];
        private int pointer;
        private int length;

        private int read() throws IOException {
            if (pointer >= length) {
                length = input.read(buffer);
                pointer = 0;
                if (length == -1) {
                    return -1;
                }
            }
            return buffer[pointer++];
        }

        String next() throws IOException {
            int c;
            do {
                c = read();
            } while (c <= ' ' && c != -1);

            StringBuilder token = new StringBuilder();
            while (c > ' ') {
                token.append((char) c);
                c = read();
            }
            return token.toString();
        }

        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }
    }
}
```

### 时空复杂度

- 时间复杂度：$O(M)$，每次栈操作均为 $O(1)$。
- 空间复杂度：$O(M)$，数组最多保存 $M$ 个栈元素。

## [AcWing 3302. 表达式求值](https://www.acwing.com/problem/content/3305/)

### 题目描述

给定一个合法的中缀表达式，其中只包含正整数、括号以及 `+`、`-`、`*`、`/` 四种运算符，请计算表达式的值。

减号只表示二元减法，不会作为负号使用。除法采用向 $0$ 取整：例如 $5/3=1$，$5/(1-4)=-1$。表达式计算过程中的数值和最终结果均不超过 $2^{31}-1$。

**输入格式**

输入一行，为给定表达式。

**输出格式**

输出一行，包含表达式的计算结果。

**数据范围**

- 表达式长度不超过 $10^5$。
- 表达式合法，其中所有数字均为正整数。

**输入样例**

```text
(2+2)*(1+1)
```

**输出样例**

```text
8
```

### 参考 Java 解法

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;

public class Main {
    private static long[] numbers;
    private static char[] operators;
    private static int numberTop;
    private static int operatorTop;

    private static int priority(char operator) {
        return operator == '+' || operator == '-' ? 1 : 2;
    }

    private static void evaluateTop() {
        long right = numbers[--numberTop];
        long left = numbers[--numberTop];
        char operator = operators[--operatorTop];

        if (operator == '+') {
            numbers[numberTop++] = left + right;
        } else if (operator == '-') {
            numbers[numberTop++] = left - right;
        } else if (operator == '*') {
            numbers[numberTop++] = left * right;
        } else {
            numbers[numberTop++] = left / right;
        }
    }

    public static void main(String[] args) throws Exception {
        BufferedReader reader = new BufferedReader(new InputStreamReader(System.in));
        String expression = reader.readLine().trim();
        int length = expression.length();
        numbers = new long[length + 1];
        operators = new char[length + 1];

        for (int i = 0; i < length; ) {
            char current = expression.charAt(i);
            if (Character.isDigit(current)) {
                long value = 0;
                while (i < length && Character.isDigit(expression.charAt(i))) {
                    value = value * 10 + expression.charAt(i) - '0';
                    i++;
                }
                numbers[numberTop++] = value;
            } else if (current == '(') {
                operators[operatorTop++] = current;
                i++;
            } else if (current == ')') {
                while (operators[operatorTop - 1] != '(') {
                    evaluateTop();
                }
                operatorTop--;
                i++;
            } else {
                while (operatorTop > 0
                        && operators[operatorTop - 1] != '('
                        && priority(operators[operatorTop - 1]) >= priority(current)) {
                    evaluateTop();
                }
                operators[operatorTop++] = current;
                i++;
            }
        }

        while (operatorTop > 0) {
            evaluateTop();
        }
        System.out.println(numbers[0]);
    }
}
```

### 时空复杂度

- 时间复杂度：$O(n)$，其中 $n$ 为表达式长度，每个数字和运算符只会入栈、出栈常数次。
- 空间复杂度：$O(n)$，用于保存数字栈和运算符栈。
