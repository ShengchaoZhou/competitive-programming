# 单链表

单链表用于维护只能沿一个方向遍历、但需要在已知节点后高效插入或删除元素的线性序列。

## [AcWing 826. 单链表](https://www.acwing.com/problem/content/828/)

### 题目描述

维护一个初始为空的单链表，并依次执行 $M$ 个操作，最后从头到尾输出链表中的所有元素。

支持以下操作：

- `H x`：把数 $x$ 插入链表头部。
- `D k`：删除第 $k$ 个插入的节点后面的节点；当 $k=0$ 时，删除当前头节点。
- `I k x`：把数 $x$ 插入第 $k$ 个插入的节点之后，其中 $k>0$。

这里的“第 $k$ 个插入的节点”按插入时间编号，与该节点当前位于链表中的位置无关。

**输入格式**

第一行包含整数 $M$，表示操作次数。

接下来 $M$ 行，每行包含一个上述操作命令。

**输出格式**

输出一行，按从头到尾的顺序输出链表中的所有元素。

**数据范围**

- $1 \le M \le 10^5$
- 所有操作均保证合法。

**输入样例**

```text
10
H 9
I 1 1
D 1
D 0
H 6
I 3 6
I 4 5
I 4 5
I 3 4
D 6
```

**输出样例**

```text
6 4 6 5
```

### 参考 Java 解法

```java
import java.util.*;

public class Main {
    private static int[] values;
    private static int[] next;
    private static int head = -1;
    private static int index;

    private static void addToHead(int value) {
        values[index] = value;
        next[index] = head;
        head = index++;
    }

    private static void addAfter(int node, int value) {
        values[index] = value;
        next[index] = next[node];
        next[node] = index++;
    }

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int operationCount = scanner.nextInt();
        values = new int[operationCount + 1];
        next = new int[operationCount + 1];

        for (int i = 0; i < operationCount; i++) {
            String operation = scanner.next();
            if (operation.equals("H")) {
                addToHead(scanner.nextInt());
            } else if (operation.equals("D")) {
                int k = scanner.nextInt();
                if (k == 0) {
                    head = next[head];
                } else {
                    int node = k - 1;
                    next[node] = next[next[node]];
                }
            } else {
                int k = scanner.nextInt();
                int value = scanner.nextInt();
                addAfter(k - 1, value);
            }
        }

        StringBuilder answer = new StringBuilder();
        for (int node = head; node != -1; node = next[node]) {
            if (answer.length() > 0) {
                answer.append(' ');
            }
            answer.append(values[node]);
        }
        System.out.println(answer);
    }

}
```

### 时空复杂度

- 时间复杂度：$O(M+L)$，每次操作为 $O(1)$，最后遍历长度为 $L$ 的链表。
- 空间复杂度：$O(M)$，用于保存至多 $M$ 个插入节点。
